## 사용 전 확인

- 이 ZIP은 R57/R58 실험 코드를 기존 PC 자료에서 **한 번 읽어 비교하기 위한 독립 패키지**입니다.
- 기존 Windows Core 5분 작업, 수집/파서, 저장 DB, 운영 Git 소스, 스케줄러, 사이트 게시를 **변경하지 않습니다**.
- **실행을 지금 당장 요구하지 않습니다.** R45의 실제 21거래일 저장본과 검토 완료한 기업 목록, 사용자 제공 참조 132/100 목록이 없으면 정상적으로 `WAITING_INPUTS`를 보고합니다. 이를 장애나 Core 실패로 해석하지 마세요.
- 필요한 두 참조 목록을 이 패키지가 임의로 만들지 않습니다.

## 실행 방법

1. ZIP을 **다운로드 폴더 등 `E:\ZGmini\data`와 별개인 폴더에 압축 해제**합니다.
2. ZIP 안의 `MARKET_CALENDAR_R59_R43_READONLY.cmd`를 **그 자리에서** 실행합니다. CMD 파일만 떼어 이동하지 마세요.
3. 실행하면 같은 폴더에 **`MARKET_CALENDAR_R59_READONLY_RESULT.txt` 파일 한 개**가 생성됩니다. 같은 위치에서 다시 실행하면 이 결과 파일을 갱신하므로, 이전 결과를 보존하려면 먼저 별도로 복사하세요.
4. PC 데이터 경로는 현재 승인된 `E:\ZGmini\data\pc-writer`, Node는 `E:\ZGmini\runtime\node.exe`를 사용합니다. 해당 경로가 없으면 C:에 대체 저장소를 만들지 않고 중단합니다.
