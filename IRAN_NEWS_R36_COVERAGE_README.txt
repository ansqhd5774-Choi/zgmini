R36: Seven-source private article coverage snapshot (READ-ONLY).

1. Extract the entire ZIP into a new folder on the approved Windows PC.
2. Run IRAN_NEWS_R36_COVERAGE_READONLY.cmd using CMD.
3. Upload the generated timestamped IRAN_NEWS_R36_SOURCE_COVERAGE_*.txt.

The report lists source-by-source 30-day stored candidates, one latest
original title/date/URL per source, and the latest separately stored R29
scheduled status. It also distinguishes retained historical IAEA metadata.

Important distinctions:
- R35's one-shot private candidate cache may be newer than the R29 status.
  This is expected and is not proof of a later normal scheduled cycle.
- A single snapshot cannot verify two distinct regular scheduled cycles.
- This is a private collection audit, NOT a public display or rights approval.
- No publisher requests, scheduled job starts, code installs, score writes,
  public cache changes, D1 writes, data purges or task modifications occur.
- Subsequent READ-ONLY snapshots may be taken only after a separate normal
  R13 cycle; keep the earlier timestamped result to compare them.
- If source files or data identity drift, the audit stops and reports it.
