# R54: 경기소비재·산업재 병렬 재측정 (공식 보고서 주소 기반)

R53 로그 분석: 두 주제는 실제 병렬이었으나, Google의 JS-required 응답과 Bing의 0-link 검색으로 신규 링크를 확보하지 못했다. R53에서 경기소비재의 무발견은 '해당 보고서가 존재하지 않는다'는 뜻이 아니다.

## 실행

1. 이 ZIP을 적당한 Windows 경로에 압축 해제한다.
2. `R54_TOPIC03_04_ANCHOR.cmd`를 더블클릭한다. Windows CMD, Node.js 필요. 로컬 Ollama `gemma3:4b` 사용.
3. 생성된 `R54_TOPIC03_04_ANCHOR_RESULT.txt`, `.json`, `_HISTORY.ndjson`를 대화에 첨부한다.

## R53과 다른 점

- 2026-10-27에 **공식 출판사 공개 페이지의 URL만 확인한** 6개 주소를 초기 주소로 사용한다. CAGR 숫자를 소스 코드에 넣지 않는다.
- 매 실행 시 **출판사 원문을 새로 GET**하여 추출·감사·모델 분류한다. 저장값 재사용 없음.
- 검색엔진의 JS 필수/0건 경로는 이번 **재측정에서 요청하지 않음**. 최초 URL 목록은 수동 검증 기준이며 자동 신규 발견 기능의 정상화로 간주하지 않는다.
- ③과 ④는 동시에 시작하되 로컬 Ollama 호출은 공유 큐로 순차 처리한다. 1회 워밍업+3회 측정.
- BRI HTTP 요청 0건. 결제·차단우회·운영 데이터 수정·배포·주문 없음.
- **승용차는 경기소비재 일부**, **산업기계·공작기계는 산업재 일부**. GICS 섹터 전체 CAGR은 NULL 유지. 다른 하위시장을 섞어 평균하지 않는다.
