STAGE04 R82 - 21-topic validation (2026-10-29)

1. Extract all files from STAGE04_R82_21_TOPICS_VALIDATION_20261029.zip
   into one folder, keeping all nine .mjs and the .cmd next to each other.
2. On Windows, double-click STAGE04_R82_21_TOPICS_VALIDATE.cmd.
3. The default original R77 folder is:
   %USERPROFILE%\Desktop\ZGMINI_R77_OLLAMA_OFFICIAL_SITEMAP_WINDOWS_20261028
   If the original is somewhere else, run in CMD:
   STAGE04_R82_21_TOPICS_VALIDATE.cmd "C:\full\path\to\R77\folder"
4. The CMD copies R77 to a NEW R82 folder on the Desktop. R77 and
   previous R78-R81 outputs are not modified.
5. Node.js and Ollama must be running/configured as they were for R81.
6. Upload the following paths printed by the CMD at completion:
   SEND_LAUNCH_LOG
   SEND_TESTS_LOG
   SEND_RESULT_JSON
   SEND_RESULT_TXT
   SEND_EXECUTION_LOG

Coverage target: all original 21 topics, minimum two verified independent
publishers per calculated mean. A mean is the arithmetic average of valid
publisher forecasts; no prior CAGR is imported and no investment score is
changed. If coverage is below 21, the CMD reports INCOMPLETE and retains the
evidence needed for diagnosis. It does not invent missing growth estimates.

R82 adjustments are narrowly scoped to: fresh official R63 report URL checks,
exact autonomous vehicles/cybersecurity market-title equivalences, strictly
proven metadata year/historic CAGR label mismatches, and independently proven
Precedence forecast-period label variations. The numerical source checks are
not removed.
