# R50 — Stage04 topic02 커뮤니케이션 (3 active publishers)

1. Extract this ZIP to a Windows **Desktop** folder.
2. Double-click `R50_TOPIC02_COMMUNICATION.cmd`. This uses ordinary CMD, Node.js, and the existing `gemma3:4b` local Ollama instance. No PowerShell or installation.
3. Wait for the one warmup and three measured passes. The screen shows `RESULT=0` if the script ran to its research-only finish state (a partial data result is still possible).
4. Send back **`R50_TOPIC02_COMMUNICATION_RESULT.txt`**. Detailed JSON is optional.
5. On later voluntary runs in this same folder, send `R50_TOPIC02_COMMUNICATION_RESULT_HISTORY.ndjson` when you want to compare the **actual** collected data and runtimes across dates. Running again does not guarantee a changed CAGR or availability; there is **no background scheduled collection**.

BRI is not contacted. Missing rates are NULL. The other three publisher reports currently describe telecom markets, which **do not cover the GICS Communication Services media/entertainment businesses**. The runner preserves those official publisher observations under their own scope, and leaves the full sector score/average NULL until source compatibility is approved. No site, investment-score, DB, or deployment effect.
