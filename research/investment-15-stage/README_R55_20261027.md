# R55 — TBRC 승용차 보고서 역사적 CAGR 혼입 원인 재검증

## 실행

1. ZIP을 압축 해제한다.
2. `R55_TOPIC03_TBRC_METADATA.cmd`를 Windows CMD에서 실행한다. Node.js 및 이미 설치된 로컬 Ollama `gemma3:4b` 필요.
3. 완료 후 `R55_TOPIC03_TBRC_METADATA_RESULT.txt`, `.json`, `_HISTORY.ndjson`를 대화에 첨부한다.

## R54에서 발견한 핵심

- ③ 승용차 TBRC 보고서의 미래 수치(2026–2030)는 본문 7.4%와 계산상 부합하지만, 하단 전망표에는 이전 1년의 성장률 6.4%가 기입된 것으로 보인다.
- 기존 R29/R31의 **양쪽 시계열 산술 일치가 필요한** 보수적인 분류 옵션을 활성화했다. 확인 없이 출판사 숫자를 수정하거나 보정하지 않는다.
- R55는 이 **한 개 URL**만 워밍업 1회+측정 3회 최신 조회한다. 다른 5개 보고서의 재수집과 검색엔진 호출 없음.
- 결괏값은 **경기소비재 전체가 아닌 승용차 하위시장** 자료다. 섹터 CAGR `NULL` 유지.
- BRI·유료 서비스·403 회피·기존 사이트 DB/산식/스케줄러/배포/주문 변경 **없음**.
