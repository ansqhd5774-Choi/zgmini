# R49 topic01 — Three active publishers, BRI excluded

Run on the user's Windows PC:

1. Extract all ZIP contents into a **desktop folder** without changing relative folder names.
2. Double-click `R49_TOPIC01_THREE_MEDIA.cmd` (ordinary Windows CMD; installed Node.js required).
3. Wait for four passes (warmup + three measured) to finish; this is not an installation or scheduled task.
4. Send `R49_TOPIC01_INFORMATION_TECHNOLOGY_RESULT.txt` from the same directory. JSON is an optional detailed diagnostic.

BRI is deliberately not contacted. The other three official publisher sources continue running independently with the existing Ollama model. Missing and non-comparable CAGR entries remain `NULL`; this script never publishes a growth-rate score. A `PARTIAL` gate is expected if no comparable direct reports are discovered.

No elevated privileges, PowerShell, WSL, payment, Git writes, DB writes, or deploys.
