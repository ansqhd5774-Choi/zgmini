## 2. 대상 집합과 등록 상태

1. 성장률 연구 집합은 **GICS 기준 11개 섹터 + 10개 테마 = 21개 항목**이다. 11개 섹터라는 분류는 MSCI/S&P의 GICS 분류를 따른다.
2. 21개 항목은 **성장률 조사 범위**이며, 자동으로 21개 모두 투자 가능하거나 다음 단계의 선정 완료 상태가 되는 것은 아니다.
3. 테마 공탐 API에 10개 테마가 표시된다는 사실만으로 모두 Stage03 승인 테마라고 추론하지 않는다. 기존 R67 당시에는 **Stage03 승인 테마 9개와 별도 연구 대상인 10번째 우주·위성 테마**를 구분했다. 확정 시점의 Stage03 등록·승인 원장을 다시 읽어 어떤 테마가 실제 편입 대상인지 검증한다. 새로운 승인 이력이 확인되면 이력과 함께 반영한다.
4. 선정 후보에서 투자 범위가 실제 종목까지 내려갈 때는 사용자가 정한 **미국 정규 상장 범위**, OTC 제외 등의 선행 규칙을 따른다. 테마 선정만으로 비허용 종목을 승인하지 않는다.
5. ETF 공탐은 기존 별도 산식·유효 ETF 선정 기준을 그대로 사용한다. 이 문서가 ETF 개수나 F 산식을 새로 고정하지 않는다.

## 3. 성장률 공식 출처·수집·검증 규정

### 3.1 허용 매체 및 독립성

- 공식 발행사: **The Business Research Company(TBRC), SkyQuest, Precedence Research**.
- **Business Research Insights(BRI)**: R49에서 확인된 HTTP 403 접근 문제 때문에 현재 자동 수집 허용 목록에서 제외. 사용자가 별도 승인하기 전 이를 우회하거나 4번째 유효 출처처럼 세지 않는다.
- 서로 다른 문서여도 **같은 발행사라면 유효 매체 1개**로만 집계한다. 동일 조사 원문을 재인용한 기사·리셀러·수집 대행 페이지를 독립 발행사로 세지 않는다.
- 발행사별 CAGR, 시장명, 원문 URL, 예상 기간, 기준연도, 보고서 발행/조회 시각, 출처 근거, 파서·Ollama 모델 버전, 검증 사유를 각 셀에 보존한다.

### 3.2 유효성 검증과 오차 처리

- 숫자가 원본 공식 자료에 실제로 있는지, 연도와 전망기간이 맞는지, 시장 정의·지역 범위가 무엇인지, 출처 내부 숫자가 모순되지 않는지 결정론적 코드가 검증한다.
- **발행사마다 전망치가 다르다는 사실은 배제 사유가 아니다.** 예컨대 A사 3%, B사 4%, C사 5%라면 각 수치가 검증 가능한 동등·근접한 시장 정의의 CAGR일 때 유효 3건 평균은 4%다.
- 출처 **그 자체의 산식·표와 본문 사이의 모순**은 출처 내부 충돌 상태로 격리한다. 모델이 원문을 잘못 읽은 경우는 모델 추출 오류로 별도 기록한다. 근거 불일치가 해결되기 전 임의로 평균에 넣지 않는다.
- 지역(글로벌/미국), 시장 규모(전체 GICS/하위 서비스), 정의, 전망 시작·종료 연도에 차이가 있으면 **SCOPE/PERIOD 경고와 비교 가능 여부**를 기록한다. 시장 정의가 실질적으로 상충할 때만 해당 셀을 재검토하며, 전망 수치의 크기가 다르다는 이유만으로 실패 처리하지 않는다.
- 한 섹터의 좁은 하위 시장 보고서를 해당 GICS 섹터 **전체 실측 성장률**인 것처럼 부르지 않는다. \`research_scope=SUBMARKET_PROXY\`와 원래 시장명을 보존한다.

### 3.3 최소 2개 유효 출처 평균 — 승인 규칙

항목 i의 서로 다른 공식 발행사에서 검증 완료한 CAGR을 \`c_{i,p}\`, 유효 발행사 수를 \`n_i\`라고 할 때:

\`\`\`text
n_i = COUNT(DISTINCT publisher WITH verified FORECAST_CAGR)
CAGR_mean_i = SUM(c_{i,p}) / n_i   IF n_i >= 2
CAGR_mean_i = NULL                  IF n_i < 2
\`\`\`

- **각 섹터·테마마다 유효 매체 2개 이상이면 성장률 평균을 집계한다.** 3개 중 1개가 누락되어도 그 항목은 2개 평균으로 정상 집계할 수 있다.
- 집계된 숫자는 실제 산업의 실현 성장률이 아닌 **발행사 전망 CAGR 평균**이라고 정확히 명시한다.
- 전체 63개 매체×주제 셀을 100% 확보해야 하는 것은 아니다. **대략 5개 내외의 개별 셀 누락은, 각 항목마다 독립된 유효 출처 2개 이상이라는 조건을 충족하면 전체 집계 실패로 판정하지 않는다.**
- 한 항목에서 유효한 출처가 1개뿐이면 그 항목만 \`NULL/NEED_MORE_SOURCES\`이고, 다른 20개 항목의 정상 산출을 막지 않는다.
- 결측, 수집 실패, 권한 실패, 검증 미확정은 점수 0 또는 성장률 0%가 아니다. 추정 대체·오래된 원장 자동 보간·수동 입력으로 충족한 척하지 않는다.
- 각 평균 옆에 \`n_i\`·매체명·개별 수치·결측 사유·경고를 반드시 함께 출력한다.

## 4. 공탐·성장률·실적의 역할 분리

### 4.1 시장의 두 지표

- \`market_score\`와 \`market_fear_greed\`는 별도 필드로 유지한다. 두 개가 서로 일부 요인을 공유하더라도 *두 값의 존재와 시점*은 반드시 독립적으로 보고한다.
- 두 지표의 결합 가중치 또는 둘 중 하나를 Stage04 필터로 삼는 수식은 **기존 승인 규정이 확인되지 않으면 새로 정하지 않는다**.
- 시장이 부정적이라는 이유만으로 실질 고성장 테마를 삭제하는 규칙은 승인되지 않았다.

### 4.2 섹터·테마 공탐

- 섹터 \`sector_fear_greed\`와 테마 \`theme_fear_greed\`는 각 대상의 **시장 심리/가격·수급 위치(F)** 정보다.
- 데이터 관측일, 소스 지연, 잠정치 여부, ETF 커버리지·산식 버전을 별도 추적한다. 24/48시간 지연이나 하루 누락을 0점으로 간주하지 않는다.
- 구버전 공탐을 최신 관측값으로 위장하여 최종 점수에 합치지 않는다.
- \`F\`가 결측이면 \`F=NULL\`로 표시하며 성장률 데이터까지 삭제하지 않는다.

### 4.3 전망 성장률과 실제 성장의 분리

| 기호/영역 | 뜻 | 취급 |
|---|---|---|
| \`CAGR_mean\` | 공식 리서치 발행사 **전망 CAGR 평균** | n≥2인 경우 연구용 비교 가능 |
| \`G_actual\` | 실측 산업 성장/실현 YoY·성장 가속도 | 관측 범위와 기간을 따로 표시. 전망 CAGR으로 대신하지 않음 |
| \`F\` | 섹터/테마 공탐 심리 | 원본 0–100점과 시각 |
| \`MONETIZATION\` | 매출·마진·현금흐름 등 사업화 지표 | 관측 가능한 근거와 결측 분리 |
| \`D\` / \`M\` / 최종 순위 | 성장과 시장심리의 격차, 합성 매력점수, 투자 우선순위 | **R67 연구 시뮬레이션과 운영 승인 산식을 구분** |

R67의 비교용 실험은 \`G_forecast_percentile\`이라는 *전망 CAGR 내 코호트 순위*를 F와 비교하는 형태로, 같은 코호트의 오름차순 중간순위 \`r_i\`, 크기 \`N\`에 대해
\`G_forecast_percentile_i = 100 * (r_i - 0.5) / N\`,
\`D_research_i = G_forecast_percentile_i - F_i\`를 사용했다.
이는 실제 \`G_actual\`도 아니고 **운영용 최종 투자매력 산식도 아니다.** R67에서 시도한 60:40/70:30 후보 배합은 승인된 가중치가 아니다. R68의 승인 상태를 따라 \`investment_attractiveness_formula_approved=false\`, \`M=NULL\`, \`screening_rank=NULL\`을 유지한다. \`M=100-F\` 같은 대체 수식도 금지한다.

## 5. 최종 테마 선정 절차 — Stage04의 필수 결과

테마 선정이 누락되지 않도록 각 테마별로 아래 절차·상태·근거를 모두 남긴다.

1. **후보 자격 확인:** Stage03 테마 등록·승인 원장과 일치 여부 확인. 연구 대상이지만 Stage03 미승인인 경우 별도 \`RESEARCH_ONLY\` 표시. 자동으로 승인된 후보에 추가하지 않는다.
2. **자료 충족 확인:** CAGR 발행사 2개 이상의 유효 평균을 확인. 1개 이하인 경우 추가 조사를 표시하되 *성장성이 0이라고 판정하거나 영구 제외하지 않는다*.
3. **시장·심리 위치 확인:** 전체 시장 점수와 전체 시장 공탐, 해당 섹터 공탐, 해당 테마 공탐을 각기 시점·출처와 함께 비교한다. 오래된 공탐은 경고하고 임의 채우지 않는다.
4. **성장 전망과 실현 분리:** 해당 섹터 CAGR 평균, 테마 CAGR 평균, 실제 산업 성장 여부, 매출·마진·FCF 사업화 지표를 별개 열로 비교한다. 성장 전망만으로 실적 입증 완료라고 선언하지 않는다.
5. **검증 경고·반론 정리:** 시장 정의 불일치, 전망 연도 차이, 특정 발행사 실패, 섹터 하위시장 대리치, 과열/침체 심리, 실현 성장 결측 등의 확인 가능 근거를 열거한다.
6. **후보 제시:** 코드는 자료 충족 테마를 **비교 가능한 연구 후보 목록**으로 제시하고, 관측과 판단을 구분한다. 수치의 크기만으로 임의 탈락·자격 박탈하거나 상위 K개를 자동 선정하지 않는다.
7. **최종 사용자 확정:** 사용자에게 후보·비교표·미승인 수식 상태를 보고하고, 명시적 승인으로 테마 및 적용 규칙·버전을 확정한다. **승인되지 않은 임계값, 순위, 가중치, 편입 숫자를 프로그램이 스스로 발명하지 않는다.**
8. **다음 단계 전달:** 확정 여부와 승인 증거를 검증한 후에만 \`FINAL_CONFIRMED\`를 다음 단계의 확정 입력으로 전달한다. 미확정 목록은 별도 \`UNRANKED_REVIEW\`로 유지한다. 실주문은 계속 \`NO_TRADE\`.

### 5.1 권장 보고 상태(인터페이스 명칭 제안, 기존 런타임 변경 아님)

## 6. 최종 점수/선정 규칙 승인 Gate (미확정 항목을 임의 확정 금지)

사용자가 아직 최종 승인하지 않은 아래 내용은 \`PENDING_USER_APPROVAL\`이다.

1. 전체 시장 점수와 전체 시장 F를 테마 선택에 합성할지, 별도 위험 컨텍스트로만 둘지.
2. 섹터 F와 테마 F의 상대 가중치 및 서로 다른 공탐 관측시각의 허용 범위.
3. 섹터 CAGR과 테마 CAGR을 직접 비교할지, 각 코호트(11개/10개) 내 순위점수로 정규화할지.
4. 전망 CAGR, 실현 산업 성장, 수익화 지표의 상대 가중치, 점수 합성 여부 및 결측 처리에 따른 선정 자격.
5. 최종 \`M\` 계산식·컷오프·선정 개수·동점 처리·선정 재평가 주기.
6. 연구-only 10번째 우주·위성 테마의 Stage03 승인 여부(현행 등록 원장 기준 별도 검증).
7. 자동 선정·자동 배포·다음 단계 승격에 요구되는 사용자 승인 기록 형식.

**사용자가 이 문서를 브랜치에 저장하라고 지시한 것 자체는 위 숫자 산식·매매·운영 배포 승인으로 해석하지 않는다.** 다만 **테마 최종 선정이라는 출력 단계의 존재, 성장률 2매체 평균, 누락 허용, 시장·섹터·테마 공탐과 두 성장률의 필수 비교, 결측을 0으로 치지 않는 규정은 보존되는 명시적 기준**이다.

## 7. R81/R82 및 재현·검증 규약

- R81/R82와 이전 R63/R67 계열의 기록은 **실측/연구 증거**로서 원본을 보존하고 별도 실행 결과를 연결한다. R82에서 보고된 21/21 대상 평균 가능·총 63셀 중 58개 유효/5개 누락은 **특정 실행 결과**이지 미래 모든 실행에 자동 적용되는 상수/성공 보장이 아니다.
- 최종 21행 요약표는 기본적으로: \`섹터/테마 ID | Stage03 승인 | 매체별 3개 CAGR | n | CAGR 평균 | scope/period | 전체 시장 점수 | 전체 시장 F | 섹터 F | 테마 F | 실제 산업 성장 | 사업화 | 경고 | 선정 상태\`를 빠짐없이 지원한다. 전체 시장 지표는 상위 공통 컨텍스트로 표시할 수 있지만 값과 시점 자체는 누락하지 않는다.
- **조건부 검증 항목**:
  1. 11섹터 + 10테마 21개 연구 주제 정합성.
  2. 각 주제에 대해 유효 발행사 \`n>=2\`인 경우에만 평균, \`n<2\`이면 NULL.
  3. 다른 발행사의 숫자가 다르다는 이유만으로 제외/실패 처리 없음.
  4. 출처 내부 모순·모델 오답·403·기간/시장 범위 경고가 각각 구분됨.
  5. 매체 셀 5개 결측에도 21개 항목 각각 n≥2면 평균 산출 지속.
  6. 시장 점수와 전체 시장 공탐이 둘 다 구조화 결과에 있음.
  7. 섹터 공탐·테마 공탐과 두 종류 CAGR 평균 모두 구조화 결과에 있음.
  8. 전망 CAGR이 실현 성장의 대체물이 아님.
  9. 공탐 결측·잠정·24/48시간 지연과 오래된 기록을 현재 최신치로 위장하지 않음.
  10. Stage03 승인 테마와 연구 테마를 혼동하지 않음.
  11. R67 실험식 D 또는 60:40/70:30의 자동 승인 없음; 최종 M·rank는 승인 전 NULL.
  12. 테마 확정 승인 이력이 없으면 \`FINAL_CONFIRMED\`·다음 단계 최종 확정 승격 없음.
- 위 체크리스트는 **향후 구현 시 테스트가 갖추어야 할 수락 기준**이다. 본 문서 작성만으로 실제 테스트가 PASS했다거나 Windows CMD·Ollama 실측·배포 완료라고 표시하지 않는다.
