# AI 자동 투자 봇 · 04단계 공식기관 실시간 입력 R10

기준: 2026-10-25, 읽기 전용 개발 브랜치 검증. 기존 ZGMINI 운영·ETF·산식·DB·스케줄러·주문은 변경하지 않는다.

## 사용자 재확인한 설계 원칙

**기관·매체를 사전에 지정하고, 실행 시 실제 공식 원문을 조회해 값을 추출·검산·산출한다.**
GitHub를 방대한 과거 원자료 저장소로 사용하거나 저장된 수치를 최신 자료로 재사용하지 않는다.
허용되는 커밋은 조회·검산 코드, 테스트, 자료 원본 링크, 관측/조사 시각, 최소 검증 결과와 문서뿐이다.
원천 접근 실패·내용 변경 시 기존 수치를 반환하는 fallback을 만들지 않는다.

## 신규 연결: 데이터센터·전력 — IEA

| 항목 | 실제 확인한 값 |
|---|---|
| 지정 원천 | IEA, *Key Questions on Energy and AI (2026)*, [Executive summary](https://www.iea.org/reports/key-questions-on-energy-and-ai/executive-summary) |
| 조회 | 공식 HTML GET 200 / 원문 문구를 매 실행 동적 파싱 / 원문 미저장 |

| 공식 발표 전년 대비 증가율 | **+17%**, 반올림 공개 수치로 별도 표시 |

IEA 공식문서 문맥은 수요의 2025년 증가율과 2025년 연간 총량을 구분한다. `485 / 1.17`을 정밀한 2024년 공식 수치로 간주하지 않는다.
현재 2026 보고서 URL을 지정해 매번 새로 확인하되, 다음 연차 보고서가 나오면 URL 및 계측정의를 다시 검토해야 한다.

## 검증 결과

- 공식 사이트: 헤더/본문 실제 HTTPS GET **200**, 보고서 식별·2025 `485 TWh`·2025 `17%` 파서 통과.
- 통합 봇 실행: `INVESTMENT_BOT_STAGE04_INPUT_GATE_R10`, `LIVE_INPUT_PARTIAL_INDUSTRY_UNRANKED`.
- 기존 테마 공탐 F **9/9 실시간 조회**, 지정 산업 원천 **6/9 실시간 조회**: FedNow, Eurostat, FDA CDER, CPUC, IFR, IEA.
- 자동 테스트 **33/33 PASS** (기존 28개 + 신규 IEA 4개 + IEA 원천 503 회귀 1개). 5개 테스트 파일.
- IEA 원천 실패 시 `industryRawTwh=NULL`, `industryReportedRoundedGrowthPct=NULL` 확인; 이전 관측값 대신 채우지 않음.
- Windows CMD 실사용자 PC 검증 **미실행**. 로컬 Node 개발 및 HTTPS 통합 검증만 완료.
- 투자 성장 점수 `G`, 괴리 `D`, 매력도 `M`, 정량 순위는 여전히 **미승인 `NULL`**. 실제 주문 **OFF**, 주문 요청 없음.
- 미연결 3개: **IAEA PRIS(원전·SMR)**, **SIPRI(방산, 상업적 사용권 미확인)**, **ENISA(사이버보안, 조사 모집단 비교 문제)**. 자료 부족은 테마 실패가 아님.
