1. 압축 파일을 **Desktop 폴더**에 해제합니다. `E:`나 `%TEMP%`로 옮길 필요가 없습니다.
2. 사용자 PC에서 **Node.js**와 Ollama `gemma3:4b`가 이미 설치·가동 중인지 확인합니다.
3. `R45_TOPIC01_INFORMATION_TECHNOLOGY.cmd`를 더블클릭합니다. PowerShell/WSL은 사용하지 않습니다.
4. 작업이 끝나면 **CMD와 같은 폴더**의 `R45_TOPIC01_INFORMATION_TECHNOLOGY_RESULT.txt` 파일을 보내주십시오. JSON은 필요하면 추가로 제공합니다.
