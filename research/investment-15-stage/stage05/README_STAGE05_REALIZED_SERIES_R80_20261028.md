# R80 — 기존 04단계 실측 산업 시계열의 성장·가속도 연구 정규화

- 작업 브랜치: `codex/investment-15-stage-m2-r25-20261025` 단독. 새 브랜치·기존 운영 점수·사이트·DB·주문·스케줄러는 변경하지 않음.
- 목적: R78 5단계 `E=M4`가 `NULL`인 이유 중 **04단계 실측 시계열 정규화 미연결**을 보완하는, 투자 점수와 분리된 공식 원천 기반 개발 도구.

## 구현

- `stage05-industry-series-research.mjs`:
  - 지정 공식 원천 하나의 동일 지표·지역·단위·연속 관측을 확인한 후 연간 YoY 또는 분기 같은 분기 YoY, 직전 YoY 대비 가속도 산출.
  - 현재를 제외한 과거 성장률/가속도 각각의 midrank 백분위 `P(v) = 100 × (과거에서 v 미만 수 + 같은 값 수/2) / 과거 수` 재현.
  - 04단계 R2 연구 제안 `G1 = g>0 ? 50+P(g)/2 : P(g)/2`, `G2 = a>0 ? 50+P(a)/2 : P(a)/2`, `G=.6G1+.4G2` 연구 표시.
  - 원천 ID 불일치·기간 누락·미래 발표·검증 누락·분모 0·자료 부족 시 계산 차단. 원자료 결측을 0으로 채우지 않음.
- 04단계 기존 `fda-cder-official-readonly.mjs`가 **기존 공식 2025 FDA CDER 연차보고서 전체 PDF를 라이브 SHA256 검증**할 때만 R80 FDA 신약 승인 연구 시계열을 활성화. 출처가 바뀌면 비교 실패 처리. 04단계 기존 파일·검증 산식 자체는 수정하지 않음.
- `stage05-fusion-readonly.mjs --audit-fda-growth-live [--output-dir 기존경로]`: **명시 실행 시에만** 기존 FDA PDF 1회 GET, 검증된 고정 2016~2025 연간 자료 연구 정규화. JSON 로그는 `STAGE05_R80_FDA_PREVIEW_*.json` 고유 이름으로 새로 생성, 덮어쓰기 없음.
- Windows 기본 R79 CMD는 변경하지 않았다. `STAGE05_R80_FDA_READONLY.cmd`를 별도로 제공하며, 그 파일이 위치한 폴더에 R80 감사 JSON을 생성한다. `STAGE05_FUSION_READONLY.cmd --audit-fda-growth-live` 옵션 실행도 가능하다(기본은 stdout만 출력).

## 개발 재현: 2025 FDA CDER 신규 신약 승인 건수

기존 R17/R2에서 지정하고 FDA 2025 보고서로 검산한 연차 시계열: 2016년 22건, 2017년 46건, 2018년 59건, 2019년 48건, 2020년 53건, 2021년 50건, 2022년 37건, 2023년 54건, 2024년 50건, 2025년 46건.

| 항목 | 개발 환경 역사 데이터 검산 |
|---|---:|
| 2025 신약 승인 건수 | 46건 |
| 2025 YoY | **-8.00%** |
| 2025 YoY 가속도 | **약 -0.592593%p** |
| 이전 성장률 비교 표본 | 8개 |
| 이전 가속도 비교 표본 | 7개 |
| G1 연구 | 12.500000 |
| G2 연구 | 35.714286 |
| G 연구 | 21.785714 |
| **공식 04단계 G/D/M4** | **NULL** |
| **05단계 E/T/S5 및 순위** | **NULL** |

**절대 해석 경계:** 위 G 연구 21.785714점은 바이오·신약 산업 성장의 확정 점수가 아니다. **FDA 신규 승인 건수**라는 미국 규제 산출물의 *자체 과거 대비 상대 점수*이며, 세계 바이오 시장 매출·보급·수익률·상용화를 대표하지 않는다. 2025 고정 보고서의 2026년 현재 전체 바이오 성장 및 04단계 매력 점수 운영 승인을 뜻하지 않는다. 라이브 PDF SHA256 검증은 사용자 PC에서 별도 수행되어야 한다.

## 검증

- R80 연구용 백분위/동일 기관 연속 표본/미래 관측 배제/원문 해시·판본/분기 YoY/프록시 범위/공식 M4 NULL: **8/8 개발 테스트 PASS**.
- R78 11/11 + R79 9/9 + R80 8/8 = **총 28/28 개발 테스트 PASS**. 외부 네트워크·사용자 Windows PC 실측과 구별.
- 1~3단계 가격 RS·Trend 자료는 여전히 미확인이고, 04단계 다른 8개 테마의 실측 G 정규화·범위 승인은 별도 과제다.
