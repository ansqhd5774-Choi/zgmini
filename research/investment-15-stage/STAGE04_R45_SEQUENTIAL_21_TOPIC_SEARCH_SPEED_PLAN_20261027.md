## 1. 개정 이유와 이미 확인한 근거

1. ChatGPT의 일반 웹 검색과 사용자 PC의 로컬 Ollama 연계 검색기는 **발견 경로가 다르다**. Ollama 자체가 외부 웹을 검색하는 것이 아니라 PC 수집기가 찾아 전달한 후보만 해석한다. 검색기가 놓친 공식 보고서는 모델이 발견할 수 없다.
2. R35 매트릭스는 21×4=84칸의 과거 **잠정 연구 기준표**다. 기존 URL과 CAGR은 새 실행에서 다시 조회할 **단서**로만 활용하고, 최신 자료의 대체값·자동 합격값으로 쓰지 않는다.
3. 사용자 제공 R44 `R44_FULL_21_NO_CREDIT_RESULT.txt`는 전체 21행을 마쳤으나, 기관별 발견 경로·시장 범위 누락을 드러냈다. TBRC 공식 색인 약 26,023 URL, SkyQuest 약 22,447 URL, Precedence 약 26 URL, BRI HTTP 403으로 나타났으며, **공식 사이트맵 = 일반 웹 검색 결과 전체**가 아니다. 셀당 보고서 최대 6개 검사로 미검사 후보가 남았고, 직접 후보 13건은 R35의 12건과 독립적인 신규 13건이 아니다.
4. R44의 `DIRECT_PROVISIONAL`·`PROXY_ONLY`·`INDEX_ACCESS_BLOCKED`는 최종 산업 CAGR 확정이 아니다. 특히 정보기술·에너지 등 GICS 섹터와 세계 시장조사 보고서의 시장 범위가 다를 수 있다.

### 검색 경로와 실패 처리

- 한 기관에서 답을 찾았더라도 다른 3개 기관은 생략하지 않는다. 네 기관의 시장 전망 수치는 독립 조사 후 **동일 비교 범위일 때만** 평균 후보가 된다.
- 공식 사이트맵·카탈로그는 **후보 발견 수단 중 하나**다. 인덱스가 작거나 403이라도 무료 검색엔진에서 공식 도메인을 재검색하고, 직접 찾은 공식 URL에서 허용되는 공개 범위만 확인한다.
- BRI 등 403에 대해 인증 우회·브라우저 차단 회피·유료 도구 사용을 하지 않는다. 명시적 차단 뒤 동일 요청 무한 재시도 금지. 이용 약관/robots/재사용권 확인이 안 되면 **개인 연구 증거**에만 한정하고 ZGMINI 공개 반영 금지.
- '해당 기관에 보고서가 없다'는 판정은 여러 허용 경로와 동의어 탐색을 기록한 다음에만 사용한다. 제한 때문에 탐색을 끝냈으면 `SEARCH_INCOMPLETE`로 구분한다.
- 하위시장 프록시를 전체 산업 전망치로 자동 대체하지 않는다. 시장 범위·예측 기간이 다른 기관 수치는 섞지 않으며 원문의 명시 숫자만 쓴다.
- 일괄 `MAX_REPORT_PAGES_PER_CELL=6`을 그대로 결론 근거로 삼지 않는다. 1차 항목에서 **후보 목록과 미검사 건수**를 보고, 검색 중단 기준을 증거로 조정한다. 무제한 크롤링이나 비용 발생은 허용하지 않는다.

## 3. 반복 속도 비교 계약

- 1차 예열 회차는 모델 적재 및 공식 인덱스 최초 구축 영향을 구별하기 위해 **본 측정 통계에서 제외**하되 속도와 호출 내역은 남긴다.
- 측정 **3회 전부** 동일 검색 규칙·모델명·출력 스키마·네트워크 정책을 사용한다. 공식 원문은 각 실행 시 새로 확인한다. 실행 간 결과값 복사·저장 원문 재사용으로 속도를 부풀리지 않는다.
- 기관별 `검색→공식 후보 열기→Ollama 검증` 시간을 나누고, 전체 1개 항목 소요시간과 각 기관 시간을 함께 기록한다. 빈 검색·HTTP 차단으로 나온 빠른 응답은 **성공 속도**에서 제외한다.
- 반복에서 공식 보고서 URL/발행 판본이 유지되면 추출 CAGR·연도·scope가 동일한지 확인한다. 공식 자료가 변경됐다면 실제 변경으로 표기하고 정합성 비교를 별도 수행한다.
- 속도 안정성 **제안 기준**: 정상 완료한 측정 3회의 `TOTAL_MS`가 중앙값 대비 각각 ±25% 범위, 계획하지 않은 재시도 0회. 기관 외부 지연이나 최초 적재 등의 원인으로 편차가 크면 `UNSTABLE`로 기록하여 원인 조치 후 **3회 전체 재측정**한다. 이 ±25%는 1번 주제에서 실측 후 사용자와 조정 가능한 운영 시험 기준이며, '항상 동일한 밀리초'를 보장하지 않는다.
- 통과는 수치 추출 성공률만으로 판정하지 않는다. **4기관 독립 조사 시도 4/4, 검색 완료 범위, 출처 품질, 미검사 후보, Ollama 일치성, 반복 속도**를 함께 확인한다.
- 한 기관이 계속 차단되면 그 기관은 `PARTIAL/SOURCE_BLOCKED`로 남긴다. 같은 차단이 3회 반복됐다는 이유로 수집 성공 `PASS`로 승격하지 않는다. 무근거 자동 평균 또는 운영 연결 금지.
- 결과 파일은 Windows CMD 파일과 **같은 폴더**에 `R45_TOPIC_XX_RESULT.txt`(사람 확인용)와 필요 최소 `json`을 만든다. 중간 상태도 누적 저장하고 최종 `FINISHED`/실패를 구분한다. 로그에 토큰·키·원문 전체·개인 경로·대규모 원자료를 넣지 않는다.
