# 04단계 R18 — 공통 자료원 우선 계약·실측 결측 보고 (2026-10-25)

상태: **개발 브랜치 검증 / 연구 전용 / 매매 없음 / 운영점수 미승인**.

## 결론

- 04단계는 이미 통과한 **9개 테마의 실제 산업 수요 성장**과 ZGMINI 공포·탐욕 F를 비교한다. 기업별 Finviz/공시 탐색은 06~10단계이며 04단계에서 수행하지 않는다.
- F는 9개 전부 **동일한 단일 매체** `https://zgmini.kr/api/theme-fear-greed`로 조회한다. API의 관측일, 확정/잠정 상태, 기존 산식을 그대로 보존한다.
- 실제 산업 수요 X, 성장률 이력, 가속도 이력을 9개 테마별 **같은 출처·같은 지표 정의로 모두 제공하는 자료원은 현재 확인하지 못했다**. 자료원 부재가 증명된 것은 아니지만, 없는 수치를 0이나 ETF 상승률로 대체하지 않는다.
- 따라서 **G1/G2/G/D/M/공식 매력도 순위 전부 NULL**. 기존 03단계 후보를 탈락시키지 않는다.

## 실측 공통성 검사

| 고정 기관 후보 | 지원하는 공통 지표 | 9개 테마와의 불일치 |
|---|---|---|
| OECD STAN 2025 | ISIC Rev.4 표준산업별 연간 산출·부가가치 | 로봇·자동화, SMR, 자율주행, 사이버보안 등 **독립 테마 수요 X**가 동일 정의로 분리됐는지 입증하지 못함 |
| 미국 BEA | 미국 NAICS 산업별 총산출·부가가치 | 국가 범위가 미국이고 세부 테마는 여러 기존 산업에 걸침 |
| 미국 Census QSS | 선택된 미국 서비스업 매출 | 선택된 서비스업에 국한해 제조 로봇·SMR 등 9개를 포괄하지 못함 |

검증 근거:

1. [OECD STAN 2025 통계 설명](https://data-explorer.oecd.org/vis?df%5Bag%5D=OECD.STI.PIE&df%5Bid%5D=DSD_STAN%40DF_STAN_2025) — ISIC 기반 분류로 산업별 산출·부가가치 제공.
2. [BEA 산업통계 공식 안내](https://www.bea.gov/industry/industry-economic-accounts-information-guide) — NAICS 기반 총산출·부가가치의 범위와 정의.
3. [미국 Census QSS 조사 범위](https://www.census.gov/services/qss/about_the_survey.html) — 선택된 서비스 업종·NAICS 범위 명시.
4. [UN ISIC 분류 소개](https://unstats.un.org/unsd/classifications/Econ/isic/4) — 표준 업종 분류 목적·구조.

위 후보들의 **수집 API 접근성·데이터별 라이선스·9개 테마 직접 시계열 존재를 별도로 통과시킨 이력은 없음**. 직접 수요를 확인하지 못한 공급원을 “확정 통합”으로 선언하지 않는다.

## 9개 테마별 종전 자료의 처리

| 테마 | 기존 분야별 실측·프록시 | R18 처리 |
|---|---|---|
| 로봇·자동화 | IFR 세계 산업용 로봇 설치량 | 이력 보존; 공통 산업자료 X 불충족 |
| 클라우드·SaaS | Eurostat EU 클라우드 보급률 | 이력 보존; SaaS 전체 시장 매출 아님 |
| 자율주행 | CPUC 캘리포니아 특정 사업자 상용 운행 | 이력 보존; 전 세계 산업 수요 아님 |
| 원전·SMR | IAEA PRIS 시도(접근 실패) | 공통 X 없음; 원전 전체와 SMR 시장 분리 필요 |
| 방산 | SIPRI 세계 국방비(권리 미검증) | 공통 X 없음; 재배포·파생 권리 확인 전 사용 금지 |
| 핀테크 | FedNow 일부 결제망 거래량 | 이력 보존; 전체 핀테크 시장 아님 |
| 사이버보안 | ENISA IT 예산 중 보안 지출 비율 | 이력 보존; 연간 산업 매출 성장률 아님 |
| 바이오·신약 | FDA CDER 신규 신약 승인 건수 | 이력 보존; 승인 건수 ≠ 시장 매출 |
| 데이터센터·전력 | IEA 데이터센터 전기 수요(추정치) | 이력 보존; 전체 테마 매출 아님 |

**R17 독립 원문조사는 취소/삭제하지 않는다.** 단, R18 자동 실행은 이 9개 다른 출처를 다시 방문하지 않는다.

## ZGMINI 추가가 필요한 항목 (사용자 보고·별도 승인 대상)

1. **테마별 직접 산업 수요 관측값 `X[t]`와 동일 정의의 전년·과거 이력**: 현재 9/9 공통 기관에서 검증되지 않음.
2. 원천 기관·원문 URL·단위·국가 범위·공표일·관측일·잠정/확정·재배포 권리·원문 해시·시계열 정의 버전의 **통합 메타데이터**.
3. 업종·지역·표본이 다른 프록시를 직접 실물 성장으로 오인하지 않도록 하는 `DIRECT / PROXY_SCOPE_LIMITED / NULL` 구분.
4. 산업 X 이력이 검증된 후에만 계산되는 **기존 초안 G1/G2/G/D/M**. 새 정규화·가중치는 사용자 승인 전 실행하지 않음.

구현 방향: **새로운 04단계 전용 ZGMINI 읽기 API/산업자료 등록 기능을 별도 승인받아 구축**. 기존 F API/ETF 계산은 유지. 원천에서 숫자를 실제로 확보할 수 있어야 등록 가능하며, ZGMINI 내부 API 추가만으로 산업 실측 자료가 저절로 생기지는 않음. 이 단계에서 D1/스케줄러/DB/산식은 변경하지 않음.

## 반영 범위와 실행

- `stage04/common-source-gate-readonly.mjs`: 런타임에 **ZGMINI F 1회 GET**, 무승인 산업 공통성 상태와 결측만 보고. 티커별/테마별 소스 자동 교체 금지.
- `stage04/STAGE04_BOT_READONLY.cmd`: 새 R18 공통 자료원 사전 검사기로 변경 (Windows CMD 전용).
- `stage04/common-source-gate-r18.test.mjs`: 공통 호출 1회, F 장애 시 보존값 오인 방지, 출처 리다이렉트 차단, 9개에 고정하지 않는 동적 후보 목록, 매매 차단을 검증.
- PC 자동 설치·실행/운영 반영 안 함. 사용자 PC에서 별도 승인된 파일 배치와 CMD 실행이 필요함.

**실질 결과**: 04단계 기술·자료 계약 보완까지 진행. 04단계 산업 실측 성장에 기초한 정량 선정·순위는 **공통 자료원 미확보로 사용자 보고 및 승인 대기**.

**실제 라이브 호출 구분:** 현재 클라우드 실행환경에서는 `zgmini.kr` DNS `EAI_AGAIN`으로 API GET이 실패했다(샌드박스 권한 밖 재시도 후에도 동일). 이는 사이트 장애 확정이 아니며, 사용자 Windows PC의 별도 실측값으로 주장하지 않는다. 단위/계약 테스트의 F 9/9는 **가짜 응답 검증값**이고 R17의 과거 F 9/9를 R18 현재 라이브 결과로 재사용하지 않는다.
