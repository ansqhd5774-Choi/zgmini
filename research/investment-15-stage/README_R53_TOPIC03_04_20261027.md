# R53 — ③ 경기소비재 + ④ 산업재 동시 조사

2026-10-27. **실행용 CMD 1개**, 독립 주제 2개.

1. ZIP을 Windows **바탕화면**에 압축 해제한다.
2. R53_TOPIC03_04_PARALLEL.cmd를 더블클릭한다. 기존 Node.js와 Ollama gemma3:4b를 사용한다. PowerShell, WSL, 별도 설치는 없다.
3. 두 주제 조사 파이프라인을 동시에 시작하지만, Ollama 모델의 작업은 하나의 큐에서 차례대로 실행한다. 준비 1회 + 본측정 3회가 끝날 때까지 기다린다.
4. 완료 후 R53_TOPIC03_04_PARALLEL_RESULT.txt를 ChatGPT에 전달한다. 오류 발생 시에도 같은 TXT 파일을 전달한다. 상세 JSON은 선택 사항이다.
5. 향후 재측정은 같은 폴더에서 CMD를 실행해야 R53_TOPIC03_04_PARALLEL_RESULT_HISTORY.ndjson에 기록이 누적된다. 백그라운드 자동 실행 기능은 없다.

## 이 실험이 확인할 것

- 실제 두 주제의 조사 시간이 겹쳤는가 (TOPIC_OVERLAP_MS, PARALLEL_OBSERVED).
- 각 주제별 네트워크/검색/검산/모델 결과를 따로 기록하고, 동시에 실행했을 때의 처리시간 변동을 관찰한다.
- 기존 R50처럼 기관별 발표 시장 CAGR과 **GICS 섹터 전체 성장률을 분리한다**. 특히 산업기계 보고서가 산업재 전체를 대표한다고 추정하지 않는다.
- 기존 주소는 숫자 아닌 **출처 탐색 단서**다. 실측은 각 PC 실행 중 공식 사이트를 다시 조회한다.
- BRI는 이용자 승인된 403 제외 매체다. 재시도·우회하지 않는다.
- 경기소비재에서 원본 매트릭스에 공식 보고서 URL이 없었다는 것은 수치가 존재하지 않는다는 뜻이 아니다. 공식 목록과 두 검색 엔진에서 3가지 동의어로 확인한다.

한쪽이 NULL이어도 다른 쪽 수집 결과를 보존하며, 둘을 평균하거나 서로 보충하지 않는다. 이번 R53은 **연구 전용**이며 실제 투자 점수, 배포, 저장 DB, 스케줄러, API 또는 유료 서비스에 영향을 주지 않는다.
