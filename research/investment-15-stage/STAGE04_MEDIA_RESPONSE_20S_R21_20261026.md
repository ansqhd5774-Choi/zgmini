# 04단계 R21 — 공식 매체 조회 20초 강제 제한

2026-10-26 KST · 연구 전용, `NO_TRADE`, 운영 서비스·공식 G/D/M 산식 변경 없음.

## 사용자 승인 실행 규칙

1. 각 테마 산업자료 조회 **20,000ms 이내**. 매체의 HTTP 연결·응답 본문 수신·파싱까지 포함. 성공이라도 20초 이후 응답을 채택하지 않는다.
2. **테마별 직렬 GET 금지**. 한 매체의 전체 지표 카탈로그/배치 응답을 공유하고, N=9/100/1,000 테마는 로컬에서 각각 매핑한다. 동일 배치가 20초 안에 끝나면 모든 테마의 네트워크 대기 시간도 20초 이내다. 매체가 배치/공통 API를 제공하지 않으면 확장성 심사에서 제외한다.
3. `SOURCE_TIMEOUT`, HTTP 실패, DNS 실패, 응답 본문 파싱 실패, 데이터 형식 불일치 시 **해당 매체는 이번 검사에서 정보 미제공**. 같은 실행에서 재시도 0회, 대체 매체 자동 전환 0회. 미제공 테마는 `SOURCE_NOT_PROVIDING_DATA`와 NULL로 처리하며 기존 저장값을 현재값으로 가장하지 않는다.
4. **매체가 응답했다**와 **G1/G2 계산에 필요한 해당 테마 직접 산업 통계를 제공했다**는 서로 다른 상태다. HTTP 200·카탈로그 존재로 전체 테마 실측 PASS 처리하지 않는다. 자동 수집·공개 가공권(S3)은 별도로 확인한다.
5. 조회 실패로 ETF 테마 자체를 삭제·투자 부적격으로 분류하지 않는다. 자료 미제공 판정은 **매체**에 속한다.

## 구현

- `stage04/provider-deadline-r21-readonly.mjs`: 응답 본문까지 포함한 일괄 요청 `Promise.race` 타이머/AbortController, 최대 20,000ms 하드 제한, 재시도/도메인 전환 없음. **단일 매체 배치 호출 함수**로 테마 개수에 따른 네트워크 호출 증가를 막는다.
- `stage04/common-source-gate-readonly.mjs`: 기존 F 15,000ms 제한을 본문 파싱까지 확대; 제안형 산업 통합 API는 20,000ms 이내 일괄 조회. 실패하면 해당 매체의 모든 테마를 `SOURCE_NOT_PROVIDING_DATA`로 구분, 이전처럼 `G1/G2/G/D/M`은 NULL. **제안형 산업 API는 현재 운영에 존재하지 않으므로 기본 실행에서 호출하지 않는다.**
- `stage04/provider-deadline-r21.test.mjs`: 무응답 연결·멈춘 JSON 본문·N=1,000·한 매체 한 번 조회·재시도 0/전환 0/점수 NULL 테스트.
