## R45 증거

1. 4회 완료. 본측정 8,697 / 9,385 / 8,752ms. 중앙값 8,752ms, 중앙값 대비 최대 편차 7.2%. 하지만 모든 매체에 대해 Google/Bing 신규 후보가 0건이므로 **성공 검색 기준으로 이 속도를 합격 처리하지 않는다**.
2. TBRC 미래 CAGR **오선정**: 7.5%는 2025→2026년 역사적 1년 성장률; 출판사 동일 원문의 2026→2030년 전망은 8.3%. R45 `SOURCE_AUDIT=CONSISTENT`이면서 선택값 7.5인 모순은 **감사 결과와 선택 후보를 숫자로 묶지 않은 결함**.
3. BRI 과거 URL 새 GET HTTP 403. 의미는 `SOURCE_BLOCKED`, 보고서 부재나 0%가 아니다.
4. SkyQuest `IT Services Market`은 정보기술 전체 시장이 아니라 하위시장. 프록시 제외가 타당하다.
5. Precedence 전체 정보기술 시장과 직접 일치하는 보고서 확보 실패. 연구 미완성이다.
6. Google 요청 HTTP 200이어도 JS 요구 페이지일 수 있다. Bing 보고서 링크는 `/ck/a?u=a1<base64url>`로 감싼 형태가 확인된다. 엔진별 수신 상태·공식 링크 결과를 별도 기록한다.

## R46 실행 순서·완료 게이트

1. **원문 선택 수정**: 기존 R29 감사 모듈 재사용, 전망 본문/속성표/역산이 일치할 때만 미래 후보를 Ollama에 제공하고, 모델이 고른 숫자·기간이 감사값과 다르면 보류한다. 경계조건 7.5(역사) / 8.3(전망) 회귀시험.
2. **공식 발견 경로 확장**: TBRC / BRI / SkyQuest / Precedence 공식 산업 카탈로그를 각각 조회. 원문 403/429의 무한 재시도 금지. Google JS/제한 표시, Bing 안전한 redirect URL 해제, 결과 URL은 정확한 발행사 HTTPS 호스트만 허용.
3. **중복·하위시장 관리**: 보고서 제목과 마지막 경로가 정확히 전체 시장을 나타내는지 먼저 검증. 하위시장 프록시는 원문 평균과 Ollama 검증 대상에서 제외. 공식 목록/검색에서 발견했지만 검사 안 한 후보도 건수로 남긴다.
4. **Windows 실측**: 사용자 CMD로 정보기술 1개 항목만 **예열 1회 + 측정 3회** 실행. 공식 카탈로그/일반 검색/보고서/모델 시간을 나눠 로그. 403 이후 건너뛴 회차는 속도 합격 표본이 아님.
5. **게이트**: 전체 기술 실행 속도 ±25%가 안정적이어도 탐색·원문·예측기간 검증 실패 또는 기관 차단이면 `PARTIAL` 유지. 01의 미해결 경로와 시장 범위/이용권을 명시적으로 정리하거나 사용자 승인 전 02 진행 금지.
