## 실제 14개 R4 점수의 필수 검산

`scripts/iran-progress/fourteen-day-local-audit-r4.mjs`:
- 사용자가 승인한 `E:\ZGmini\data\iran-progress-r13\iran.sqlite`를 **SQLite readOnly** 모드로 연다.
- 2026-10-05 ~ 2026-10-18 각 날짜 1행 총 14행.
- 당시까지 **검증 시점이 도달한 최신 사건 revision**만 열람. 나중에 검증된 10월 8일 사건을 10월 8일 당시 검증 완료로 소급하지 않는다.
- 미국–이란, 이란–이스라엘, 후티·예멘, LINKED를 분리 집계; 기사 보도·조건부 제3국 참전은 직접 공격으로 환산 금지.
- 별도 `r4-shadow-verified-asof-v1:YYYY-MM-DD` checkpoint가 **실제로 저장·검증된 날짜만** R4 후보를 계산한다. 없는 날짜는 `r4Score:null` 유지.
- 여태 사용한 R3 가감점이나 분석가 18점을 PC 검증 결과에 섞지 않음.
- DB 쓰기/Provider/Ollama/D1/스케줄러 작업 없음. `%TEMP%\ZGMINI_IRAN_R4_14DAY_READONLY_AUDIT.txt` 한 개에 집계 로그만 저장.

사용자 PC에서 **현재 허용된 최신 소스가 확보됐을 때만**:
```cmd
scripts\iran-progress\r4-fourteen-day-audit.cmd
```
실행 전에 E:가 실제 운영 저장소인지 확인. 존재하지 않으면 생성하지 않고 중단. 데이터 수집이나 게시·재실행 안 함.
