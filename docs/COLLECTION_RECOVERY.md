# 수집 복구

Core PCE는 FRED·BEA의 고정 실패 분류와 HTTP 상태를 PC 진단 입력에 저장한다. 인증정보·URL·공급자 오류 본문은 기록하지 않는다. 네트워크·429·5xx에만 2초 후 1회 재시도하며 정상 원자료·출력은 실패 시 보존한다. BEA PCE 요청은 최대 45초 대기한다.

Alpaca는 기존 PC core 주기에 연결한다. 무료 IEX·일봉·split 조정 자료만 사용한다. 20시간 성공 캐시, 실패 1시간 대기, 요청 간 1초, 실행당 120요청 상한이다. 기존 55개 종목 그룹의 마지막 저장 날짜 이후만 수집하며 과거 group 파일은 수정하지 않는다. 증분 파일 저장·재조회가 모두 성공한 뒤 체크포인트와 성공 보고를 갱신한다. 수집 성공은 가격 조정·시장 전체 커버리지 검증 완료를 뜻하지 않는다.

2026-10-11 실응답: FRED 200 정상, BEA 시간 초과 후 재확인 503, Alpaca 55그룹·55요청 저장 검증 성공. BEA 외부 장애는 정상으로 위장하지 않는다.
