# P0 — 미국 공포탐욕 페이지 디자인 변경 시 원본 연결 보존

2026-10-26 · 대상: `/fear-greed/usa/`

## 절대 금지

1. 기존 대시보드 차트·점수·게이지와 비슷하게 생긴 독립 HTML/Canvas/SVG를 만들어 실제 연결 화면인 것처럼 제시하거나 게시하지 않는다.
2. 실제 데이터와 별도로 하드코딩한 숫자, 원시값, 비교값, 이력, 날짜, 상태, 그래프 경로를 만들지 않는다.
3. API, 저장 자료, 산식, 자동 갱신, 기간 선택, 툴팁, 전일 및 기간 대비 값, 확정·결측 구분을 외형 변경을 이유로 교체하거나 끊지 않는다.
4. 기존 SEO 본문·메타데이터·연결 링크·교육 자료를 디자인 편의상 삭제하거나 숨기지 않는다.
5. 별도 미리보기를 실제 사이트에 적용된 결과나 배포 준비가 끝난 결과로 오인하게 보고하지 않는다.

## 실제 연결 경로

- 페이지: `app/fear-greed/usa/page.tsx`
- 원본 데이터 연결: `app/fear-greed/usa/cnn-panel.tsx`의 `useStoredIndex("/api/fear-greed")`
- 점수/게이지/전일·기간 비교: 실제 `FearGreedCardShell` → `MarketScoreOrb`
- 기간 선택과 차트: `MarketPeriodControls` → `MarketFearGreedChart`
- 7개 구성요소 분석: 동일 `cnn-panel.tsx`의 `factorRows` → `FactorAnalysisR2`
- SEO: `page.tsx` 메타데이터, `DetailReadingGuide`, `InvestorIntentGuide`, `DetailInvestorNotes`와 기존 링크

## 변경 전·후 필수 검증

1. 화면의 모든 점수·구성요소·원시값·날짜가 기존 API로부터 그대로 전달되는지 확인한다.
2. 기간 선택 1W/1M/3M/6M/1Y, 실제 이력 차트, 툴팁, 전일·기간 비교가 기존과 동일하게 작동하는지 확인한다.
3. 결측 시 임의값을 만들지 않고 `—` / 미확인 상태를 유지한다.
4. PC 및 모바일에서 7개 구성요소의 클릭·펼침, 표의 터치 영역, 글자 줄바꿈을 확인한다.
5. 미국 페이지 변경이 한국 페이지와 메인 대시보드에 영향을 주지 않는지 확인한다.
6. SEO 문구·메타데이터·정규 URL·내부 링크가 유지되는지 확인한다.
7. 연결 또는 작동 검증이 끝나기 전에는 배포 완료나 실시간 연결 완료라고 보고하지 않는다.

**원칙:** 기존 연결을 가진 컴포넌트를 재사용하면서 레이아웃만 조정한다. 실제 실행 환경 검증 없이 독립 시안을 운영 페이지로 대체하지 않는다.
