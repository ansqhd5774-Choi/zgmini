# 신규 혁신 테마: 이력 부족 시 적응형 ETF 점수 R2 (비공개 연구안)

> 2026-10-25 사용자 승인: 신규 테마는 `기존 R188 기준 OR 적응형 R2 기준`으로
> 판정한다. 기존 통과한 **9개 테마의 자격·가격·산식·가중치·과거 점수는
> 재검증하거나 재계산하지 않는다.** 신규 ETF 2개의 이력이 서로 다를 때
> 70:30에서 50:50으로 수렴하는 R3 페어 비중 규칙을 적용한다.

## 목적 및 경계

- `628 거래일`은 R188 방식으로 **과거 252개 점수를 빠짐없이 재현**하는 데 필요한 총 관측 길이이지, 새로운 ETF 자체를 배제하기 위한 문턱이 아니다.
- ETF만 사용한다. 개별 종목 가격·SEC 자료·추정 과거 종가·보간 데이터는 사용하지 않는다.
- 기존 공개 테마의 R188 산식·가중치·스케줄러·저장소·feed·DB는 **일절 변경하지 않는다**. R2는 격리된 후보 연구 코드다.
- 이 OR 기준은 **새로 조사하는 테마만** 적용한다. 첫 번째 경로를 통과하면 두 번째 경로를 중복 평가하지 않는다.
- 신규 테마의 R188 경로는 628개 실제 공통 거래일과 과거 252개 R188 점수의 완전 재현을 요구한다. 실패 시 R2 경로를 확인한다. 각 ETF에서 실제 40거래일 이상의 일별 계산 요건과 SPY 대비강도 원자료가 준비되면 R2 계산 경로에 진입한다. 어느 쪽도 불충분하면 후보에서 삭제하지 않고 결측 상태로 감시한다.
- 미국 SPY 실제 관측 거래일을 차트의 공통 기준으로 삼고, 해당 ETF가 아직 존재하지 않았거나 관측 누락이면 `score:null`로 남긴다. 1년은 **최대 252개 실제 거래일의 화면 범위**이며 252개 점수를 억지로 채우지 않는다.

## 단계별 실제 관측 지표

| 실제 ETF 관측 거래일 | 계산 가능한 지표 및 조건 | 점수 표시 |
|---|---|---|
| 1~39 | 20일 수익률·대비강도·변동성의 20개 정규화 표본 부족 | `null`, 추적 후보로 유지 |
| 40~79 | `r20`, `rs20`, `rv20`, `dsv20`부터 사용 | 잠정 적응형 |
| 80~81 | `r60`, `rs60` 조건 충족 시 추가 | 잠정 적응형 |
| 82~143 | `dd63` 추가 | 잠정 적응형 |
| 144~ | `m125`, `rs125`도 차례로 조건 충족 시 추가 | 잠정 적응형 |
| 377~ | 전 지표가 각각 252개 정규화 표본을 확보 | **해당 일자 점수는 R188과 정확히 일치** |
| 628~ | 최근 **252일 전체** R188 점수와 정확히 일치 | 완전 1년 호환 |

위 단계는 중간 결측이 없는 거래일 연속 관측의 예다. 일별 가격 누락 또는 SPY 결측 시 해당 지표의 계산 시점은 늦어지며 값을 만들지 않는다.

## 산식과 투명성

- 축 가중치: 추세 40% · SPY 대비강도 20% · 변동성 40% (**R188 그대로**).
- 기존 개별 지표 가중치 그대로: 추세 `m125 50 / r60 30 / r20 20`; 대비강도 `rs20 25 / rs60 45 / rs125 30`; 변동성 `rv20 40 / dsv20 35 / dd63 25`.
- 각 지표는 **실제 존재하는** 최근 최대 252개 정규화 관측값의 중간순위 백분위(midrank)를 사용한다. 최소 20개 실제 지표 관측값이 필요하다.
- 축 안에서 조건을 충족한 지표만 사용하고 **그 지표들의 기존 가중치를 합계 100%로 재정규화**한다. 예: 20일 추세만 있으면 추세축 100%를 `r20`으로 산출. 세 축 중 하나라도 사용할 지표가 없으면 점수를 만들지 않는다.
- 역방향 지표는 종전처럼 `rv20`/`dsv20`만 적용. 페어 후보는 **양쪽 ETF 점수가 모두 있을 때만** 아래 R3 가변 비중으로 결합한다. 한쪽 데이터 부족을 다른 ETF 단독 점수로 대체하지 않는다.
- 매일 `ADAPTIVE_PROVISIONAL` 또는 `R188_COMPATIBLE`과 사용 지표/백분위 표본수를 기록한다. 잠정과 최종을 섞어 숨기지 않는다.

## 신규 테마 ETF 페어 가중치 R3 — 승인 기준

- 위의 **세 축 40/20/40과 내부 지표 비중은 각 ETF마다 그대로**다. 다음 비중은 서로 다른 ETF의 최종 점수를 결합할 때만 사용한다.
- 두 ETF 모두 해당 날짜에 실제 점수가 있어야 한다. 누락 시 페어 점수 `null`; 한쪽 100% 대체 금지.
- 날짜별 ETF 유효 관측 거래일 수를 각각 `N_A`, `N_B`로 기록한다. R188의 모든 9개 지표가 252개 실제 백분위 표본을 확보하여 `R188_COMPATIBLE`이면 해당 ETF의 성숙도를 **377일**로 취급한다. 아직 적응형 잠정이면 `min(N,376)`까지만 인정한다.
- 성숙도 `M_A`, `M_B`가 정해지면 아래 **대칭·연속식**으로 계산한다. 두 ETF의 성숙도가 같으면 50:50, 한쪽 377일 이상이고 다른 쪽 40일이면 70:30이다.

  `W_A = clip(0.50 + 0.20 * (M_A - M_B) / 337, 0.30, 0.70)`

  `W_B = 1 - W_A`

  `PAIR_SCORE = W_A * ETF_A_SCORE + W_B * ETF_B_SCORE`

| A 성숙도 | B 성숙도 | A 비중 | B 비중 |
|---:|---:|---:|---:|
| 377+ | 40 | 70.0% | 30.0% |
| 377+ | 120 | 65.3% | 34.7% |
| 377+ | 252 | 57.4% | 42.6% |
| 377+ | 377+ | 50.0% | 50.0% |
| 120 | 120 | 50.0% | 50.0% |

- 각 과거 날짜에 **그 날짜의 실제 N과 지표 상태**로 가중치를 재계산한다. 현재 비중을 과거 차트 전체에 소급 적용하지 않는다.
- `70:30`은 신생 표본의 불확실성에 대한 **사용자 승인 운영 규칙**이다. 통계적으로 추정된 최적 투자 비중이나 ETF 매수 비율이라고 주장하지 않는다.
- 기존 9개 공개 테마의 50:50·R188·이력·스케줄러·D1에는 이 규칙을 절대 소급 적용하지 않는다.
- 독립 코드: `theme-optional-pair-weight-r3.mjs`; 우주·위성 비공개 감사: `theme-space-satellite-adaptive-r2.mjs`. 신규 적용은 공개/권리 승인까지 연구 격리를 유지한다.

## 실제 자료 흐름

`GetMarketHistory 1시간봉 -> E:\ZGmini\data\themes\space-satellite\raw\ + SHA256 manifest -> 검증 -> NY 15시 봉(조기폐장 12시) -> 일별 실제 종가 프록시 -> 개별 ETF 적응형 점수 -> 비공개 2개 페어 후보 비교`

검증 중인 **비확정** 후보: `UFO + ROKT`, `UFO + ARKX` (SPY 대비).

- 제공사의 허용범위 확인 전 점수·원자료 공개/배포 금지. 기존 배포 게이트·Cloudflare·D1 미연결 유지.

- 원자료는 E:에 보존하되 사용자 확인 로그는 `.cmd` 파일과 **동일한 디렉터리**에 기록한다. `pause`로 창 종료를 방지한다.
