# 자산 버블 R10 운영 연결

## Alpaca 사용 금지 — 2026-11-10 사용자 확정

- **R10 자산버블의 Alpaca Basic IEX 수집·신규 계산 입력·공개 점수/차트 게시 사용을 제외한다.** 기존 R10 Core 보조 수집 호출은 중지하고, 역사적 `asset-r10-alpaca` 파일·checkpoint·검산 자료는 삭제하지 않는다.
- 기존 `breadth-research`·`alpaca-pit-validation`·`alpaca-collected-audit`는 Alpaca 계보의 **과거 연구/감사 증거 전용**이며, 새 R10 B(시장폭 괴리) 점수의 생산 입력으로 다시 사용할 수 없다.
- 현재 B의 승인된 대체 원천이 없다. B를 0으로 만들거나, 나머지 85%를 100%로 재가중하거나, 구 분기를 최신 분기로 보간하지 않는다. **대체 소스와 이용권 및 데이터 품질이 승인되기 전 신규 R10 6요소 RELEASE/게시를 차단한다.** 실패 시 이전 저장 결과는 원장·복구 증거로 보존하며 새 결과로 재게시하지 않는다.
- R10 외 별도 기능(미국 등락 R17, 섹터 잠정 지표 등)의 Alpaca 사용 정책은 이 지시로 임의 변경하지 않는다. 단, 해당 기능의 공급자 공개 권한 문제는 각 담당 업무에서 독립 판단한다.
- GitHub 브랜치 수정은 운영 PC 승인 source 교체나 Production 게시 수정이 아니다. 기존 공개 R10의 계보·화면 조정은 운영 승인·배포 및 실제 검증을 거쳐야 한다.

사용자가 승인한 미확인 자료의 임시 사용과 최신 완료 분기 표시를 운영 경로에 연결한다. 독립 가격 조정 검증, 과거 발표 시점, 자료 이용 근거를 확보 완료로 표시하지 않는다. 이 경로는 현재 개정 자료 참고 지표이며 당시 시점 백테스트가 아니다.

## 계산

기존 R10 가중치 V/P/H/F/B/L = 30/20/15/10/15/10% 유지. B는 12개월 수익률과 200일 이동평균 참여율의 expanding midrank, 최소 252개 관측, 세 월말 점수 평균이다. 모든 구성요소가 있는 동일 분기의 점수만 산출한다. 원가격 변경·임의 재가중치·현재 미완성 분기 보간은 없다. R9 계산 모듈은 변경하지 않는다.

## 게시

`build-asset-r10-release.mjs`는 저장 macro/SP500/B/가격 검증 자료만 읽고 실게시 결과 파일을 만든다. 조건부 검산 보고서나 가정된 verification flag를 읽지 않는다. 기본 엄격 게시 조건은 유지하며 명시적인 USER_APPROVED_CURRENT_VINTAGE_UNVERIFIED_SOURCES 정책과 설명을 가진 결과에만 승인된 참고 경로를 적용한다. 숫자 범위와 6요소 가중합 검사는 동일하다.

PC Writer는 매 주기 저장 자료로 재계산하고 기존 projection checkpoint의 단조 증가 시점을 보존한다. R10 결과 hash가 바뀌면 새로 저장한다. 계산 실패 시 마지막 정상 게시 파일을 보존하며 원자료 시점은 payload에 별도로 남긴다. Cloudflare에는 원자료 없이 공개 결과만 게시한다. UI는 완료 분기·진단 분기·현재 개정 이력·독립 검증 미완료를 표시한다.
