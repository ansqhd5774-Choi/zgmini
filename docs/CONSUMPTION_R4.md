# 소비 R4 승인 계약

사용자 확정: 실질 PCE 최근 3개월 연율 70% + 전년 대비 30%. 각 증가율 g는 clip(50+10g,0,100)으로 변환한다. 최근 3개월 연율은 100*((X[t]/X[t-3])^4-1), 전년 대비는 100*(X[t]/X[t-12]-1)이다. 추가 민감도·이동평균·가속도 가중치는 없다. 50점은 정체 기준이며 역사적 중립 백분위나 확률이 아니다.

월간 BEA 실질 PCE(FRED PCEC96)를 PC에서 수집하고 기존 market_input_batches_v1에 consumption-r4 키로 별도 저장·재조회한다. 계산은 저장 데이터만 사용한다. 최소 24개월 입력으로 12개월 점수를 생성한다. 날짜는 월 첫날의 관측월 식별자다. 발표일을 관측일로 간주하지 않는다. 현재 수정 자료를 사용하는 이력은 CURRENT_VINTAGE_ONLY / lookAheadSafe=false다.

핵심 입력의 13개월 연속성이 부족하면 해당 월은 PARTIAL/null이다. null은 0으로 대체하거나 이전 R3 점수로 대체하지 않는다. 중복 월은 오류다. 수집은 일 1회 이내 캐시, 무료 FRED 공개 CSV 1요청이며 실패 시 기존 저장 자료를 덮어쓰지 않는다. 수집 후 7일 경과하면 미갱신 상태로 점수를 보류한다.

R3 후보 점수 테이블·원자료·기존 점수 이력은 삭제하거나 재작성하지 않는다. R4 차트에는 R4 계산만 포함한다. 종합 점수의 소비 영역 기존 비중 7%는 유지한다. 전환 전 종합 점수의 저장 이력은 당시 버전을 보존한다.

가속도는 앞선 3개월 연율과의 차이로 설명만 한다. 1인당 소비·상품/서비스·소득·저축·연체·소매판매는 보조 검증 대상이며 R4 점수 입력에 포함하지 않는다. 보조 값은 검증된 자료가 없으면 미확인으로 남긴다.

검증은 단위검사, 저장된 실데이터 계산, 당시 발표자료 검증, 원격 게시 read-back, PC/모바일 렌더링을 구분한다. 동일 PCE와 방향이 맞는 것만으로 독립적인 경제적 검증을 통과했다고 선언하지 않는다.
