# 경기침체 저장 데이터 자동 표시

- 기존 PC core 주기에서 공식 BLS/BEA/Fed/Census 캘린더를 6시간 간격으로 순차 조회한다. 소스당 1회, 15초 제한, 즉시 재시도 없음. 별도 scheduler나 유료 API를 추가하지 않는다.
- 원본을 기존 로컬 feed 저장소에 저장한 뒤 파싱한다. 공개 API는 저장 결과만 읽고 Provider를 호출하지 않는다. 기존 writer의 output 동기화가 `release-calendar`도 전달한다.
- 조회 실패는 이전 이벤트를 보존하면서 `SOURCE_FAILED`로 남긴다. 실패·48시간 초과·미수집을 공식 일정 미정으로 표현하지 않는다. 규칙적 발표 주기는 확정된 다음 발표일과 구분한다.
- 보조지표 이력은 기존 DOL state claims, RATE_R3 입력(rateR2), CMDI raw HY, NFCICREDIT에서 읽는다. 현재 관측일·원값 일치가 필수다. 정규화 점수를 원자료로 대체하지 않는다.
- 4주 claims 이력은 51개 이상 지역, 연속 4주가 확인된 경우만 사용한다. 미연결·출처 불일치·2점 미만은 별도로 표시한다.
- 승인 R13 산식, 7개 요소 비중, 기존 점수와 핵심 이력은 변경하지 않는다. UNRATE 결측으로 멈춘 Sahm Gap은 임의 보간하거나 다른 Sahm 산식으로 교체하지 않고 관측 지연을 표시한다.
- 개발 후보 5개는 수집 계약이 없는 상태를 유지하며 자동 연동 완료로 간주하지 않는다.

검증: 별도 메모리 DB 수집 테스트, 저장 SQLite read-only 검산, 기존 builder와 점수·핵심 이력 동등성, PC/모바일 렌더링을 구분한다. 운영 활성화는 실제 배포 SHA와 PC 승인 source가 일치한 뒤 확인한다.
