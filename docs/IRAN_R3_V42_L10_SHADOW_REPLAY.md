# ZGMINI Iran R3 V42 — 2차 분류 변경 후보의 기존 산식 재생 (미적용)

2026-10-19 V37/V38 V3/V40 PC 원장 증거를 근거로 하는 **연구용** V42.

## 현재 확인된 사실
- 실제 운영 R3 참고 점수 **36.3**, PC SQLite–공개 API 일치, 자동 작업 연동 확인. R4 실증 점수가 아니다.
- 기사 발표일 기준 11개 R3 보도 신호: 군사 공격 3/경고 5, 해상 차질 3. 군사 영역 4점·해상 영역 20점.
- 10/18 Al Jazeera L10 동일 URL의 다른 저장 제목 버전 2개: 03:00Z 이전 버전 불채택, 09:00Z 최신 버전 채택. **현재 분류·원장 경로는 일치**하나 liveblog 우산 제목을 IRAN 공격 주체로 오인할 위험이 발견됨.
- H01 중복 가능성 보류: 관련 저장 원문은 다른 기사 발표일에 있음. 실제 같은 사건인지 미확정.

## V42 계산 원리와 한계
- 기존 R3 `buildReferenceFlowR3` 함수와 **원본 30/25/20/15/10% 및 단계 가감점 그대로** 사용.
- V41 `reviewR3HeadlineV41`이 `REVIEW_REQUIRED`로 분류한 **여러 사건 결합 라이브블로그**만 임시 보류한 후보와 기존 저장 분류를 비교.
- 기존 저장 원장의 점수, 사건 개수, 모든 영역 점수가 동일한지 먼저 대조. **하나라도 다르면 후보 점수를 내지 않음**.
- 11개 보도 형태에 대한 연구 fixture 결과: 현재 36.3/11건 → L10 하나 보류 시 **가상 38.7/10건**, 차이 +2.4. **가상값이지 운영 실제 점수·새로운 사건 확정치가 아니다.** 실제 PC 저장 레저 재계산 결과를 별도로 검증하기 전 적용 금지.
- H01 미해결 중복 건은 그대로 보류, 점수에 새로 넣지 않음. L05 해상 충돌 보도는 이번 후보 계산에서 제거하지 않음.
- V42 계산 차트는 원래와 같이 **기사 발표일 기준 사후 재구성**이며 실제 과거 공개 점수 변경 기록이 아님. 소급 덮어쓰기 금지.
