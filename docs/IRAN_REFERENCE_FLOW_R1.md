# 이란 보도 흐름 참고 점수 R1

사용자 승인: 정확한 종전 확률보다 확전·완화 방향을 읽는 가벼운 1차 모델을 먼저 제공한다.

- 임시 기준점: 2026-09-09, 각 영역 50. 관측된 종전 수준이 아니며, 미포착 영역도 기준점에서 시작한다.
- 외교 30%, 휴전 25%, 군사 20%, 해상 15%, 핵 10%. 기존 공식 종전 판정과 별도 결과다.
- Ollama의 원문 구간 분류를 재사용한다. 모델·프롬프트 평가 PASS, 원문 해시, 이용 조건 기록을 확인하고 고정 문장 규칙만 점수를 변경한다.
- 공격 -25, 휴전 위반 -30, 협상 결렬 -20, 휴전 합의 +25, 협상 진행 +15, 통항 방해 -20, 통항 재개 +20, 핵 합의·사찰 재개 +20을 해당 영역에 적용한다. 각 영역 범위는 0~100이다.
- 같은 날 같은 규칙은 한 번만 적용한다. 실제 사건 수를 의미하지 않으며, 중복 보도 영향 제한을 위한 1차 규칙이다.
- 계산 기준점은 고정한다. 차트만 최근 14일로 자르므로 날짜가 지났다는 이유로 점수가 50으로 초기화되지 않는다.
- 기사 발표일 기준 재구성이다. 공격 피해가 과거 사건을 언급한 경우도 보도 신호이며, 새로운 공격 발생을 인증하지 않는다. 변화가 반영된 날짜만 기록한다.
- 수집 실패·24시간 넘은 공급원 확인은 이전 유효 점수를 보존하고 갱신 지연으로 표시한다. 새 점수를 만들지 않는다.
- API는 D1 저장 자료만 읽는다. 원문 전체와 AI 원시 응답은 공개하지 않는다.

실행: `node scripts/iran-progress/reference-flow.mjs --preview` 또는 승인된 게시 단계에서 `--publish`.

6시간 수집 작업은 `run-reference-flow.mjs --collector=<기존 collect-r14.mjs 절대 경로>`로 기존 수집기 실행 후 게시한다. 수집기와 게시기는 기존 SQLite lease를 각각 사용한다.

초기 저장 자료 검산: 기사 24건·후보 64개에서 2026-10-01 협상 진행 +4.5, 2026-10-02 공격 피해 언급 -5.0, 종합 49.5. 사건 발생일의 실제 순서와 일치한다고 주장하지 않는다. 향후 보도 방향이 어긋나면 근거와 규칙을 수정하고 방법론 버전을 올린다.
