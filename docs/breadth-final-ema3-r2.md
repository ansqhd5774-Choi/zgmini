# 수급·폭 최종 EMA3 R2

2026-10-10. 단기 변동을 줄이는 승인 작업. 원래 네 입력과 비중(30/20/30/20), 종합시장 비중 8%는 유지한다.

## 산식

원래 4요인 합성점수를 R이라 하면 최종 점수는 `F[t] = 0.5 R[t] + 0.5 F[t-1]`이다. 최초 유효 관측 및 거래일 누락 뒤에는 `F[t] = R[t]`로 시작한다. 현재 숫자, 차트, 종합시장 계산에는 동일한 F를 사용한다. 상세 네 항목은 원래 입력값이다. 방법론은 `B1-R5-STORED-BREADTH-4FACTOR-EMA3-R2`이다.

일별 변동 제한·보간·가짜 관측은 사용하지 않는다. 최종 EMA3는 단기 잡음을 줄이는 대신 반응 지연이 생긴다. 지속적인 계단형 변화는 첫 거래일 50%, 둘째 75% 반영한다. 당일 방향 일치는 지연이 없다는 뜻이 아니다.

## 실제 원자료 복구

누락/98% 미달 날짜 7일: 2026-03-26, 03-27, 09-24, 09-25, 09-28, 09-29, 10-01. 같은 공급자의 직접 다운로드 파일로 3,511행을 복구했다. 3월은 각 498/503, 나머지는 각 503/503이다. 기존 운영 구성종목을 보존했다. 새로 필요한 구성은 앞뒤 기존 운영 snapshot의 구성 전체 일치를 확인했다.

3월 수정 자료판과 기존 가격·거래량이 달라 혼합하지 않았다. 원래 946행과 전체 DB 백업을 보존했고, 같은 자료판에 없는 기존 8행은 원본 archive에 남겼다. 정상 날짜는 전체 행 해시가 복구 전후 동일하다. 감사 이력은 INSERT 2,573 / UPDATE 938로 검산했다. 원자료 revision 차이의 정확한 공급자 원인은 확인되지 않았다.

최신 2026-10-08은 기존 primary collector 3요청으로 502/503(99.80%) 수집했다. 과거 파일의 `timestamp`와 최근 파일의 `date` schema 차이를 수정했다. 실제 11파일 parser 재생은 네트워크 요청 없이 통과했다.
