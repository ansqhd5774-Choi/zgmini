# R11 정정 — ETF 구성은 데이터 수집·검증 가능성으로 결정하며 **2종 제한 없음**

- 날짜: 2026-10-25. 사용자 최신 직접 지시를 반영한 신규 테마 작업 기준.
- 범위: 신규 우주·위성 테마와 동일 구조의 향후 **신규** ETF 테마. 기존 운영 9개는 산식·재선정·D1·스케줄러·공개 차트 변경 대상 아님.
- 상태: `USER_COUNT_RULE_CONFIRMED / R11_RESEARCH_GATE_IMPLEMENTED / FINAL_BASKET_NOT_SELECTED / RIGHTS_NOT_VERIFIED / NO_PUBLICATION`.
- **정정 이유:** R9에 실데이터가 검증된 UFO·NASA **2종은 당시의 감사 대상**이었을 뿐, 최초 또는 최종 조합의 개수 제한이 아니었다. R10에서 “2종 최종 선택”, “2종을 중심으로 편입 우선순위”처럼 읽힐 수 있는 문구는 이 R11로 교정한다.

## 1. 선정 기준: **수집 가능한 모든 적격 ETF** — 숫자로 자르지 않는다

1. 해당 테마와 관련된 ETF 후보를 먼저 나열한다. 신규 ETF라도 삭제하지 않고 관측 전 후보로 유지한다.
2. 각 후보의 데이터 공급원 약관 및 **무료 접근 가능 구간**을 확인한다. 미국 ETF라는 이유만으로 모두 현재 공급된다고 가정하지 않는다.
3. 공급원 무료 **카탈로그**에서 ETF 기호와 구간 존재를 먼저 확인한다. 카탈로그 등재는 **실제 요청 기간의 가격 수집 성공을 증명하지 않는다**.
4. 실제 원본 수집·SHA·관측일·SPY 공통 거래일 N 및 해당 날짜 R2/R188 점수를 검증한다. 원가격 결측이나 ETF 상장 전 점수 생성 금지.
5. **검증되어 이용 가능한 ETF는 전부 포함 대상으로 평가**한다. `take(2)`, `slice(0,3)`, 상위 2종 고정, “최대 3종” 등 금지. 구성 개수는 1개, 2개, 4개, 9개 또는 그 이상일 수 있으며 특정 숫자 충족을 위해 후보를 억지 추가/제외하지 않는다.
6. 발행사의 AUM·호가 스프레드·공통 보유기업 비율은 **위험·중복 알림**. 명시적 탈락 기준이 승인되지 않은 이상 중복 하한 54.30%p, AUM 소형, 짧은 상장기간 **그 자체만으로 자동 제외하는 필터로 만들지 않는다**.
7. 상장 40거래일 미만·수집 지연·원봉 누락 ETF도 후보로 계속 보존한다. **점수 산출 가능 여부**는 승인 R2 `N>=40` 및 세부지표 충족 등 별도 판단이다. “데이터 수집 후보”와 “오늘 점수 가능 ETF”는 혼동 금지.
8. **개수와 무관한 합성 점수 방법의 별도 검증 필요:** R4-A 비공개 합성기는 현재 `N>=2` 입력에만 정의되어 있고, 이는 **선정 제한이 아니며** 1종 단독 테마 점수 표출 규칙은 별도 확인 사항이다. 기존 R4/승인 R3/R9의 SHA-pinned 실측 재현 경로는 손상시키지 않는다.

- **일부 미검증 = 불가능/탈락이 아니다.** 모든 후보를 유지하고 실제 수집 가능 여부만 조사한다. 데이터가 적합하다고 확인된 개수만큼 동적으로 포함 검토한다.
- R9 `UFO+NASA` 점수 **39.95701** 및 실측 R9 105개 날짜는 **당시 두 ETF에 한정된 비공개 검산값**이며, 제3·제4 ETF가 수집 가능한 경우 최종 가변 구성의 점수로 오인하지 않는다.
- `rightsVerified=false`, `finalBasketSelected=false`, `publicationAuthorized=false`. 카탈로그 확인이나 발행사 공시만으로 이를 `true`로 변경하지 않는다.

## 3. 비파괴·무과금 R11 구현

- `scripts/pc-writer/theme-space-satellite-r11-universe.mjs` 순수 함수 `classifyEtfDataAvailability`:
  - 입력 ETF 배열 **0/1/2/3/4/5/9/10/25/100 모두 길이 그대로** 처리.
  - `CATALOG_CHECK_NEEDED`, `CATALOG_LISTED_NEEDS_RAW_AUDIT`, `RAW_UNDER_40`, `RAW_NEEDS_SCORE_AUDIT`, `PRIVATE_SCORE_READY` 등을 구별.
  - `SCORE_PASS`에는 실제 N≥40 및 R2가 부여한 유효 상태 입력이 필수. **별도 실제 PC 원본 검산 증거 없이 임의 상태를 PASS로 보고하지 않는다**. 본 함수는 보고된 감사 결과 분류기지 독립 SHA 검증기 자체는 아니다.
  - ETF를 2개만 자르는 연산 없고 보유기업 중복·AUM을 탈락 함수로 사용하지 않는다.
  - 네트워크, 파일·DB·D1·Provider, Scheduler, 공개 API 접근·수정 **0**.
- `tests/theme-space-satellite-r11-universe.test.mjs`:
  - 수집·점수 감사 통과 후보를 1~100개까지 임의 감축하지 않는 테스트.
  - 9종 전원 후보로 유지하되 R9 실측 UFO/NASA만 별도 표시.
  - 카탈로그 LISTED와 실제 RAW/SCORE PASS 구별, N39 점수 생성·허위 R2 상태·중복 티커 차단.
- 로컬 R11/R10/R4/R9 **4개 Node 테스트 파일 PASS**. 기존 R9 비공개 PC 검증 숫자·파일·SHA·산식은 변경하지 않았다.

## 4. 공급원 자료의 실제 한계와 다음 게이트

- [GetMarketHistory 공식 API](https://getmarkethistory.com/docs/api/reference)는 **무료·무계정 카탈로그** `/api/v1/symbols` 및 1시간봉 샘플을 문서화하고, `X-Data-Through`가 실제 해당 기호의 최신 제공시점임을 설명한다. 개별 9종 모두 카탈로그를 이미 실제 조회했다고 주장하지 않는다.
- [공급원 Coverage](https://getmarkethistory.com/docs/coverage)는 미국 ETF 대상 데이터셋이라도 **백필 중**, 하루 장 마감 대비 대체로 **48시간 지연**, 실제 카탈로그에 있는 기호만 제공한다고 명시한다. 따라서 갱신 지연을 시장 당일값으로 가장하지 않는다.
- [공급원 약관 5절](https://getmarkethistory.com/docs/terms): 합법 수집 데이터의 내부 저장/연구 허용; 원봉 bulk 재배포 금지, 원본을 대량 복원할 수 없는 파생 지표는 조건부 배포 가능. 파생 게시 권리·해당 데이터셋 경로는 별도 최종 점검해야 한다.
- **실제 다음 작업:** ① 9종 무료 카탈로그·실제 사용 가능 시점 확인 → ② 기존 raw manifest의 UFO/NASA/ARKX/ROKT 재호출 없이 대조 → ③ 미수집 후보 중 무료로 수집 가능한 ETF만 개별 제한 수집/실측 → ④ 모인 **모든 점수 가용 ETF**로 당시 날짜별 가변 합성 검산 및 승인 → ⑤ 라이선스/갱신/공개 승인. 9종 일괄 원가격 수집이나 거액 데이터의 브랜치 저장은 금지.
