# 스태그플레이션 최신 발표 조합 R1

## 목적과 공개 위치

먼저 발표된 산업생산·고용·기대인플레이션·유가 정보를 공통 관측월이 완성되기 전에 제공한다. 기존 S2.1 동일기간 평가와 13개 월별 이력은 유지한다. 대시보드 보조 문구와 상세 페이지 별도 잠정 카드에서 제공하며, 종합 시장 점수나 확정 위험 점수에 합산하지 않는다.

## 산식

S2.1의 원자료 8종, 10개 신호, 120개월 참조, 4개 영역 비중과 결합식, 13:1:1 평활 가중치를 유지한다. 각 원자료의 실제 최신 관측월을 기준으로 증가율과 과거 참조를 계산한다. 모든 자료의 최신 월이 같으면 원래 S2.1 점수와 동일해야 한다.

명시적인 변경은 월 정렬 방식이다. S2.1은 공통 월을 사용하지만 이 별도 모델은 자료별 최신 발표 관측월을 사용한다. 따라서 **특정 월의 완성 점수나 미발표 값의 예측은 아니다.** 시점 차이가 있는 입력 조합으로 생기는 한계를 카드에 표시한다.

- 결측값 생성·전기값을 새 월로 복사·가중치 재배분 없음.
- 8종 및 모든 증가율·참조 입력이 필요하다. 관측 월이 계산월보다 3개월을 초과해 뒤처지면 허용하지 않는다(계산월-3개월 경계 포함).
- 미래 관측, 중복 월, 잘못된 값, 부족한 참조 이력은 PARTIAL, score=null.
- 현재 개정치 데이터 기반이다. 과거 당시 이용 가능한 발표본을 재현한 성과나 위기 예측 검증으로 표현하지 않는다.

## 저장·API

- 방법론: `STAGFLATION_LATEST_PUBLISHED_R1`
- 평가 방식: `LATEST_PUBLISHED_INPUTS_NOT_COMMON_MONTH_OR_FORECAST`
- D1 별도 키: `detail:stagflation-risk:latest-published-r1`
- API: `/api/stagflation-risk-provisional`
- PC 설정 opt-in: `latestStagflationPublication=true`

PC 저장 원자료만 계산하며 신규 Provider 호출은 없다. API는 저장된 결과만 읽는다. 실제 계산 관측만 최대 370개 저장하며, 점수·입력 월·영역 평가가 같으면 관측점을 추가하지 않는다. 원자료 배열과 해시는 공개하지 않는다. 확정 관측월이 최신 조합을 따라잡으면 잠정 카드를 숨긴다.

원격 쓰기는 기존 테이블의 독립 키에서 이전 세대 CAS와 단일 read-back으로 확인한다. timeout을 이유로 쓰기를 반복하지 않는다. 이 기능 실패는 기존 월별 점수·차트·다른 게시물을 교체하지 않는다.
