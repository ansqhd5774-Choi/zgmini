# R38 — 이란 뉴스 2단계 키워드 규칙 (2026-10-28)

## 사용자 확정 규칙

- 1차: 이란, 후티, 사우디, 예맨(예멘) 중 **하나 이상**.
- 2차: 전쟁, 합의, 휴전, 협상, 진전 중 **하나 이상**.
- 통과: **1차 OR 그룹과 2차 OR 그룹이 각각 참**.
- 원문 영문 기사는 대응 표현(Iran/Iranian, Houthis, Saudi, Yemen;
  war, agreement/deal, ceasefire/truce, negotiation/talks, progress)을 인식한다.
- 기사 제목과 실제 원문 본문을 합쳐 판정한다. 중요도·긍부정·추정 의미·추가 사건 분류는
  뉴스의 관련성 통과 조건이 아니다.

## 관련성과 무관한 무결성 제약

- URL 출처 확인, 원문 페이지 접근, 제목·최초 발행일 확인은 **데이터 무결성 검사**이며
  추가 관련성 필터가 아니다. 본문 존재는 확인하되 종전 200자 최소 길이를 요구하지 않는다.
- 기존 PC 30일 보관, 공개 화면 14일 표시, 라이선스·공개 승인 계약은 이 작업에서 변경하지 않았다.
- R3/R5 점수, 예약 작업, PC 데이터, D1 공개 데이터 모두 변경하지 않았다.
- 기존 R36 검사기는 **R35 설치 파일 SHA 전용**이라 R38 수정본을 검사하면
  `R36_INSTALLED_R35_IDENTITY_DRIFT`가 정상적으로 발생한다. 구 버전 검사 PASS로 보고하지 않는다.
