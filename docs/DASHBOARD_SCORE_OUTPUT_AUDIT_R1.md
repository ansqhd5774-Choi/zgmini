## 2. 실제 수치·구간 불일치: 경제지표 홈 ↔ 지형도

경제 카드와 지형도는 동일한 공개 `/api/market-score`의 12개 `READY` 영역 점수를 읽는다. 홈 카드의 색/게이지는 `25/40/60/75`, 상태 문구는 우선 `domain.state`(없을 때 같은 25/40/60/75 분기)를 사용한다. 지형도는 자체 `25/45/55/75` 5개 구간과 **취약/주의/중립/양호/우수** 문구를 사용한다. `design-qa.md`에는 5개 밴드의 승인 원본 폭 `25/20/10/20/25` 보존 기록이 있다.

| 항목 | 공개 점수 | 홈 표시·상태 | 지형도 상태 | 검증 결과 |
| --- | ---: | --- | --- | --- |
| 금리 | 15.8 | 16 · 위험 | 취약 | 의미 유사·문구 상이 |
| 유가·원자재 | 15.9 | 16 · 위험 | 취약 | 의미 유사·문구 상이 |
| 소비 | 37.3 | 37 · 주의 | 주의 | 상태 일치 |
| 자금흐름 | 38.0 | 38 · 주의 | 주의 | 상태 일치 |
| 달러·환율 | 38.8 | 39 · 주의 | 주의 | 상태 일치 |
| **고용** | **42.7** | **43 · 중립** | **주의** | **서로 다른 상태 판정: 실제 문제** |

| 채권·신용 | 68.7 | 69 · 양호 | 양호 | 상태 일치 |
| 기업실적 | 76.5 | 76 · 안정 | 우수 | 의미 유사·문구 상이 |

- **실제 구간 충돌 2/12개**: 고용 42.7, 경기 59.1. 금리·원자재·기업실적 3개는 의미가 가까운 명칭 차이이며 동일 심각도의 수치 판정 오류로 계산하지 않는다.
- **중복 반올림 주의**: 기업실적의 원점수는 공개 응답에서 약 `76.4521`; 홈 `Math.round(raw)=76`, 지형도 `raw.toFixed(1)=76.5`가 동시에 맞다. 화면의 `76.5`를 다시 정수 반올림해 `77`을 기대하는 이중 반올림은 현재 승인 표시 구현을 오해한 것이다.
- 고용 개별 상세 화면도 `42.7점 · 중립`을 표시하므로 **지형도만 홈·개별 상세와 다른 판정**이다. 색상도 구간 차이에 따라 다르다.
- 경제 지형도에서 `25/45/55/75`를 일방적으로 `25/40/60/75`로 교체하면 사용자 승인된 5밴드 지형도 폭이 바뀐다. 반대로 홈/상세/서버 상태를 `25/45/55/75`로 바꾸면 기존 공개 상태 계약의 의미가 바뀐다. **한쪽을 선택하는 새로운 정본 승인을 먼저 확인한다.**

## 3. 위험지표 잠정·확정 점수 차이: 의도된 별도 계열

- 같은 시각 홈 `스태그플레이션 위험 73`, 위험 목록 `70.4`를 관측했다. 이는 정수/소수점 단독 문제가 아니다.
- 홈은 `selectDashboardRiskDisplay`가 엄격한 `READY + PROVISIONAL + 방법론·관측·이력 일치` 조건을 충족하면 최신 발표 기반 **잠정** 점수를 선택하고, 위험 목록은 기존 **확정** 저장 점수를 사용한다. 기존 R50 테스트는 이 우선순위와 교차 방법론 화살표 미표시를 보호한다.
- 홈 DOM에는 `data-score-source=provisional` 소스 표시가 있지만 텍스트로 잠정을 설명하는 표식은 없다. 이 차이를 단순 값 불일치로 판정하여 확정값으로 덮어쓰면 기존 승인 기능을 훼손한다. **잠정 표식 신설 여부는 카드 공간·원본 UI 의도를 확인한 뒤 별도 최소 변경으로 결정**한다.

## 4. 반드시 유지할 표시 계약·별도 사항

- 종합점수 표시 민감도/클램프, 각 데이터 `READY` 검증, 0과 결측 `—` 구분, raw 단위, 경제/위험과 공포탐욕의 서로 다른 정책, 관측/게시일 구분은 변경 금지.
- `docs/SCORE_ARROW_24H.md`: 소수 첫째 자리 실제 공개 점수 변경 시 24시간 화살표. 정수 카드값이 같아도 소수 첫째 자리가 바뀐 경우 화살표가 뜨는 것이 곧 버그는 아니다.
- `docs/LIVE_SCORE_MOTION.md`: 실제 표시 점수 변경 때만 강조. CSS reduced-motion 구현은 별도 브라우저 환경 검증 전까지 추정 버그로 확정하지 않는다.
- 섹터·테마 홈의 ‘준비 중’과 별도 페이지 READY 차이는 관측됐지만, 입력 제공 및 UI 소유범위 확인 전에 이 범위의 점수를 조작하거나 임의 치환하지 않는다.
- 개인 고용 상세 화면에서 이력 마지막 관측값과 현재값이 다른 것은 차트의 관측/평가 기준 차이를 명시한 운영 표시다. 단순 날짜 차이만으로 차트 점을 조작하지 않는다.
