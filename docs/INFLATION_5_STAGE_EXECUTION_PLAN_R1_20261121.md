## 실행 원칙

1. 독립 읽기·코드 작업은 병행하고, 동일 운영 파일·DB·Writer 설치처럼 실제로 겹치는 쓰기만 기존 lease/정규 승인 경로로 직렬화한다.
2. 2단계 D1 접근 제한은 그 조회만 `AUTOMATION_BLOCKED`로 관리한다. Census 원자료 복구 및 R2 기존 날짜 결함 수정까지 일괄 중단하지 않는다.
3. 현재 설치 SHA와 이전 정상본 CAS·정확 변경 파일 SHA-256·승인 효과·백업·롤백·사후 실제 증거를 확인한다. PR·CI·문서 자체를 운영 적용으로 간주하지 않는다.
4. 0, null, missing, stale, 관측일, 원천 저장일, 게시 저장일을 구분한다. 과거 유효 이력·원본/해시·기존 19종·4축, 승인 산식·가중치·공개 계약을 보존한다.
5. 신규 Controller 작업은 진단 보조 수단이며 완료 목표가 아니다. 이미 설치된 operation을 중복 설치하지 않고, 새 고유 Census A는 해당 operation의 실제 설치가 확인된 후에만 발행한다.
6. 단계별 완료는 [진행기록서](INFLATION_5_STAGE_PROGRESS_LOG_R1_20261121.md)에 실제 증거로만 기록한다. 완료 단계 수를 전체 작업량 퍼센트로 환산하지 않는다.
