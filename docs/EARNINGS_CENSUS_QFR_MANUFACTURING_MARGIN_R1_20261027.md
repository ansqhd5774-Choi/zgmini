## 1. 왜 이 지표인가

기존 BLS 생산자물가·단위노동비용은 비용압력의 간접 지표이고, BEA/FRED 단위이익은 기업 이익의 다른 정의다. Census QFR은 미국 표본 법인의 실제 매출과 세후이익 집계를 제공한다. 이 두 값을 같은 보고 분기·같은 집계 범위에서 나누면 **미국 제조업 집계 세후이익률**을 만들 수 있다. 이는 실적 상황을 이해하는 정보성 수치이지, 기존 실적 침체 위험 점수의 자동 입력이 아니다.

- Census 공식 프로그램: https://www.census.gov/econ/qfr/
- 직접 ZIP 다운로드: https://www.census.gov/econ_getzippedfile/?programCode=QFR
- 제공 원자료 목록: https://www.census.gov/econ_datasets/
- 공식 Census 데이터 API 대체 경로: https://api.census.gov/data/timeseries/eits/qfr.html. **이 API의 예시 문서에는 API 키 필수라고 명시**되므로, 이번 R1의 무키 공식 ZIP 소스를 사용한다.

ZIP 안 `QFR-mf.csv`와 `/README`가 포함돼 있으며, README는 **Census 귀속과 프로그램 이름을 표시할 것**과 **원래 수치 정밀도를 임의로 바꾸지 말 것**을 요구한다. 현재 자료의 `DATA UPDATED ON`은 `Tuesday, 08-Sep-26 09:05:38 EDT`. 다운로드 시점에 제공된 당시 최신 실측 분기는 2026-Q2이다.
