# 이란 14일 차트 — 잠정 18점 역산 시안 / 실제 R4 재구성 분리

## 기존 문제
2026-10-18 공개 R3=36.7. R3의 임시 기준점 50에서 뉴스 가감점을 누적했고,
첫 기사 변화 이전(10/05–10/11)까지 차트 함수가 초기 50을 7번 복제했다.
이는 당시 실제 전황이 50점이라는 근거가 아니다.

## 1. 잠정 18점에서 계산한 역산 시안 — 실제 R4 점수 아님

| 날짜 | R3 저장값 | 18점 기준 역산 시안 |
|---|---:|---:|
| 10/12 | 48.1 | 29.4 |
| 10/13 | 47.3 | 28.6 |
| 10/14 | 43.4 | 24.7 |
| 10/15 | 41.0 | 22.3 |
| 10/16 | 39.5 | 20.8 |
| 10/17 | 39.1 | 20.4 |
| 10/18 | 36.7 | 18.0 |
| 10/05–10/11 | 기존 50 반복 | null (근거 없음) |

단, 18.0은 분석가 잠정 추정, 변동폭은 R3 기사 보도일 기준 가감값이므로 위 값은 모델을 검증한 역사적 진실이 아니다. 예멘 실제 전면전 상황과 점수대가 모순되는지도 추가 검증한다.

구현: lib/iran-progress/retrospective-backcast-r4.mjs — buildProvisionalR4AnchorBackcast.
출력 상태 ILLUSTRATIVE_ONLY, productionReady=false, cannotPublish=true.

## 2. 실제 R4 14일 과거 재구성

rebuildVerifiedR4DailyHistory는 각 날짜마다 검증된 미국–이란/이란–이스라엘/예멘 후티 전선과 군사·휴전·해상·핵 자료를 해당 날짜 asOf 시점의 전체 R4 산식으로 다시 계산한다.
실제 과거 R4 점수에는 분석가 추정 18점이나 R3 50점/뉴스 변화치를 사용하지 않는다.
입력 미존재/검증 실패 날짜는 null, 날짜별 관측 사실과 발표일을 구분한다.

## 3. 기존 공개 R3 차트의 UI 수정만

lib/iran-progress/chart-history.mjs에 hidePreEventCarry 옵션을 추가하고 R3 view에만 적용한다.
10/05–10/11의 임시 기준 50 선을 제거한다. R1/R2, R3 점수, D1/API, 키, TTL, 스케줄, 기존 과거 저장 점수는 변경하지 않는다.
SVG 채우기 시작점은 14일 축 처음이 아니라 실제 첫 보도 변화일부터 시작한다.
