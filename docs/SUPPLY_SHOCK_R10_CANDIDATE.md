# 공급 충격 R10 검증용 실행 명세

상태: CANDIDATE / 운영 R9 변경 없음. 기준 source: 8ecda8fc027c73503b817f02c2d10d922f7298b9.

## 계약

월간 안전점수 S=100-(0.35G+0.25E+0.15O+0.15P+0.10I).
각 영역은 위험점수이며 가중치는 후보 설계값이다. 확률이나 인과적으로 식별된 공급 충격으로 해석하지 않는다.
5개 평가 영역은 서로 독립이라는 가정을 하지 않는다.
운영 R9 저장 이력, 수집 스케줄, 공개 projection, UI, 원격 DB는 변경하지 않는다.

## 검증용 계산 규칙

아래 세부 선택은 검증용 초안이며 운영 확정값이 아니다. 계산 전 실제 입력의 단위와 정의를 확인한다.

* G: 100×표준정규누적함수(GSCPI). 실제 역사적 백분위가 아니라 단조 변환이다.
* E: 미국 석유 공급 제약. SPR 제외 원유 재고, 미국 원유 생산, 원유 정제 투입량의 세 잔차 위험점수를 각각 1/3로 결합한다. 재고는 월 마지막 주, 유량은 해당 월 관측 주들의 평균으로 집계한다. 주간 월 경계 배분 방식은 별도 민감도 비교한다.
* E 통제: 로그 수준을 종속변수로 하며 월 더미, 선형 시간 추세, 자기 시차 1개월, 석유제품 공급량(수요 대용), 순원유수입을 설명변수로 사용한다. 순수입은 수입-수출이며 로그 변환하지 않는다. 음의 잔차가 위험 증가 방향이다. 수요·수입 통제가 신호를 지우는지 통제 없는 비교도 기록한다.
* O: WTI 월간 로그 변화의 양의 예측 오차와 휘발유 월간 로그 변화의 양의 잔차를 각각 1/2로 결합한다. WTI 모형은 자기 변화 시차와 실제 석유제품 공급량 변화, 휘발유 모형은 자기 변화 시차·월 더미·당월 WTI 변화로 설명한다. 잔차는 공급 원인 확정값이 아니다.
* P: SF Fed의 `Supply-driven Inflation (core, m/m)` 열을 사용한다. 파일 단위는 공식 설명과 대조해 월간 연율 기여도임을 검증한다. ambiguous 열은 사용하지 않는다. 헤드라인 월간 및 근원 전년 대비를 비교 후보로 별도 평가한다.
* I: 산업생산 월간 로그 변화에서 실제 개인소비지출(PCEC96) 월간 로그 변화, 자기 변화 시차 1개월로 설명한 잔차의 음수 방향을 사용한다. 수요 대용 입력이 없으면 I는 null이다. INDPRO 전체와 제조업 별도 지수는 중복 진단용 비교이며 승인 없이 교체하지 않는다.

회귀는 대상월 이전의 최근 120개 유효 월을 사용한다. 최소 120개 미만, 필수 시차 누락, 상수 변수·설계행렬 특이성은 계산 불가 사유로 기록한다. 검증용 OLS를 사용하며 자동 변수 삭제나 임의 정규화 변경으로 성공 처리하지 않는다.
대상월의 설명변수는 해당 월이 공통 평가 가능해진 시점에 공개된 값만 사용한다. 이는 사후 월간 평가이고 실시간 예측이 아니다.

G 외 영역의 연속 잔차 및 P 기여도는 위험 증가 방향으로 맞춘 후, 대상월 이전 최대 240개월의 유효 값과 비교한다. 최소 60개를 요구한다. 위험 백분위=100×(작은 값 개수+동률 개수/2)/표본수. 검증 초안에서는 잔차를 먼저 0으로 잘라 동률을 늘리지 않는다. 따라서 역사적 중앙 위험은 약 50이며 무충격을 100점으로 보장하지 않는다.
회귀 예열 120개월+잔차 백분위 예열 60개월+표시 이력을 고려해 최소 약 16년 이상 원자료를 목표로 확보한다. 공통 자료 시작 시점에 따라 실제 READY 시작월을 계산한다.

## 저장·날짜·결측

원본 파일/응답→격리된 연구 저장→파싱→계산 순서. 운영 DB에는 연구 원자료를 쓰지 않는다.
source URL, SHA256, collectedAt, 관측일, 단위, historyMode를 저장한다. collectedAt을 발표일로 대체하지 않는다.
현재 수정본으로 재구성한 이력은 CURRENT_VINTAGE_ONLY / lookAheadSafe=false다. 당시 발표본 검증과 분리한다.
공통 기준월은 모든 필수 입력이 있는 최신 월이며, 최신 개별 관측월도 함께 기록한다. 중간 결측 월을 보간하지 않는다.
5개 영역 중 하나라도 미검증이면 PARTIAL/null. 원인이 자료 부족인지 수집 실패인지 계산 실패인지 구분한다.

가중합·방향·범위·0/결측·월 경계·역사적 미래 입력 차단 검사를 수행한다.
