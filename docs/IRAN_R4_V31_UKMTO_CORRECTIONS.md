# ZGMINI Iran R4 — V31 UKMTO 공개 색인 보완 (2026-10-19)

## 목적과 증거 등급

V29 PC 실측: 출처 4,257행, 미분류 3,671행 중 3,661행 동일한 미확인 상태 토큰/10필드 스키마. 미분류에 사건 ID·발생일·공격 주체 검증·28일 관측 근거가 없으므로 개별 공격 수로 취급하지 않는다.

V30 Draft PR #436의 **10개 선별 경보**에 이어, V31은 **14개 공식 공개 색인 행**을 추가 검토한다. 이 중 **11개 번호는 V30 표본에 없었고**, #174·#175·#176 **3개는 V30 사실관계 보강**이다. 이는 새로 발생하거나 독립적으로 확인된 공격 사건 14개가 아니다.

공식 참고: [UKMTO Recent Incidents](https://www.ukmto.org/recent-incidents), [UKMTO 홈페이지 색인](https://www.ukmto.org/). 웹 검토일은 10/19이며 당시 PC가 보유한 원문 시점을 증명하지 않는다.
