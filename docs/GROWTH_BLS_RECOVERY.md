# 경기 BLS 503 진단 및 복구

## 2026-10-26 KST 확인
- 00:15 경기 FORWARD 수집에서 Census 4회와 연준 2회는 HTTP 200, BLS 1회는 HTTP 503. 로컬 quota guarded=0.
- 등록 키를 포함한 같은 5개 CES 계열 요청도 HTTP 503, JSON 없음. API 첫 화면 HTTP 503, title `The BLS website is busy`. 원격 BLS 서비스 비가용은 확인했지만 내부 장애 사유나 복구 시각은 확인하지 못했다.
- 기존 forward 요청에는 등록 키가 누락되고 일시 오류 재시도가 없었다. 키 누락을 503 원인으로 단정하지 않는다.

## 보완
- forward/chart가 같은 BLS 요청 모듈 사용. `BLS_API_KEY` 또는 `BLS_REGISTRATION_KEY`를 메모리에서 JSON POST에 연결. 키/응답 원문은 오류·로그에 노출하지 않는다.
- 429/500/502/503/504와 통신 실패만 최대 2회 요청. 기본 2초 대기. Retry-After가 10초를 초과하면 즉시 종료해 다음 기존 정규 작업에 맡긴다. client 오류·논리 오류·빈 응답·quota guard·진단 요청 상한은 임의 재시도하지 않는다.
- 모든 요청 계열의 월간 숫자 자료를 확인하며 0은 허용한다. 실패·일부 계열 누락은 기존 입력·점수의 정상 자료를 대체하지 않는다. 원자료 저장과 공개 게시 보호는 유지한다.
- 수집 보고와 한글 경고 기록에 BLS HTTP/시도 횟수를 남긴다. 같은 경고의 중복 창은 방지하고 실제 성공 시에만 해제한다.
- 계열·변환·산식·가중치·TTL·관측일·스키마·대체 공급원 변경 없음. BLS 자체 장애 제거 또는 영구 무장애를 보장하지 않는다.
