## 삭제 범위와 실패 처리

1. 공급자 다운로드 구현, 무료 공개 파생 경로, MarketParquet 잠정치 계산·공개 sidecar와 공통 등록의 예약 의존성을 제거한다. 과거 import와 저장 key 식별용 이름만 남은 호환 진입점은 실행 시 `PROVIDER_REMOVED_MARKETPARQUET_PUBLICATION_DENIED`를 반환하며 재시도 대상이 아니다.
2. 공통 quota의 허용 공급자에서 제외한다. observe/enforce 모드와 관계없이 해당 호스트 요청은 실제 fetch 전에 거부한다. 다른 공급처로 자동 fallback하지 않는다.
3. MarketParquet 입력이 필요한 잠정치는 **미제공**이다. 확정치로 바꾸어 표시하거나 GMH와 혼합하거나 이전 값을 최신으로 위장하지 않는다. 해당 잠정치 부재를 GMH 수집·비공개 계산·독립 테마 전체의 대기 조건으로 만들지 않는다.
4. GMH의 실제 제공 날짜와 권리 조건으로 가능한 확정 경로를 유지한다. 산식·ETF 구성·가중치·정규화·과거 점수를 임의 변경하지 않는다. 24시간 잠정치 제공을 현재 지원 기능으로 약속하지 않는다. Alpaca 등 새 공급처도 임의 추가하지 않는다.
5. 과거 운영 데이터·DB·D1·실행 결과는 삭제하지 않는다. `marketparquet-r167`처럼 이름만 남은 폴더 안에도 GMH 원자료·실행기가 있으므로 폴더 전체를 삭제하거나 이동하지 않는다. 파일명·key·폴더명이 남아 있다는 이유만으로 사용 중이라고 판단하지 않고 실제 실행·입력 의존성을 확인한다.
6. main 소스 변경과 PC 설치·예약 정리는 별개다. PC의 실제 사용 중인 소스·예약은 정규 유지보수 경로에서 정확한 범위를 확인해 적용하고 결과를 회수한다. main 병합만으로 PC 정리 완료라고 보고하지 않는다.

## 지침 충돌 해결

- 이 결정은 과거의 ‘MarketParquet 24시간 잠정치’, ‘무료 가이드 기반 공개 가능’, ‘기존 7개 파일 재사용’ 설계보다 우선한다. 과거 문서는 실행 근거가 아닌 당시 증거로만 보존한다.
- 새 작업은 삭제된 경로를 복원하거나 같은 권리를 재문의하지 않는다. 유료 결제·다른 API 도입을 자동 다음 단계로 만들지 않는다.

- 삭제된 API의 성공·fallback·무료 공개를 요구하던 전용 테스트는 사용 중단 계약 검사로 교체한다. 순수 산식의 과거 fixture 검산은 보존하되 그 통과를 현재 공급자 사용권이나 운영 활성화로 해석하지 않는다. 무관한 기존 검사 실패를 감추거나 실패를 PASS로 바꾸지 않는다.
