===============================================================================
9. Cafe24 DNS Cutover
===============================================================================
R5 기준 DOMAIN/DNS AUTHORITY는 Cafe24.

Gate PASS 후에만:
1. zgmini.kr 현재 DNS live 조회.
2. 기존 record 전체 중 cutover 관련 record와 rollback 값 기록.
3. Cloudflare 측 custom domain/target 준비.
4. Cafe24 DNS에서 승인된 hostname만 Cloudflare target으로 전환.
5. unrelated DNS/mail/verification record 수정 금지.
6. DNS propagation 확인.
7. HTTPS certificate 정상 확인.

이 작업은 사용자의 현재 "배포작업을 최종 완료까지 진행" 지시 범위로 진행하되,
Cloudflare Cutover Gate가 전부 PASS하기 전에는 절대 실행하지 않는다.
