# 공급 충격 R10 운영 전환

2026-10-10: 승인된 후보를 PC 수집·계산과 공개 진단 화면에 연결했다. 기존 후보·비교·민감도 문서의 '운영 미실행'은 해당 연구 단계 기록이다.

최종 안전점수: `100-(0.35G+0.25E+0.15O+0.15P+0.10I)`. 기본값은 수요 통제 포함, 주 종료월 집계, 근원 공급 주도 월간 PCE다. 실질 소비 입력은 장기 DPCERA3M086SBEA 지수를 사용한다. 높은 점수는 낮은 관측 위험이며 확률이나 인과적 공급 식별 결과가 아니다.

공식 공개 파일 10개를 하루 한 번 저장하고 실패 후 6시간 동안 재시도를 보류한다. 별도 유료 API나 인증키는 추가하지 않는다. 계산은 저장 자료만 읽는다. 수집 실패는 이전 입력을 보존하며 7일 이상 오래된 입력, 필수 자료 부재, 계산 실패는 새 점수 게시를 막고 이전 공개 결과를 보존한다.

대시보드와 상세 페이지는 같은 저장된 R10 projection을 사용한다. 상세 페이지에 공통 기준월과 5개 평가 영역을 표시한다. 최근 1년 표시는 시작점 포함 13개 월간 점수를 사용한다. 현재 수정본 이력(CURRENT_VINTAGE_ONLY)이므로 당시 발표본 검증과 구분한다.

기존 R9 원자료·저장 이력과 종합 시장 12영역 산식은 보존한다. 공개 supplyShock 진단 projection만 R10으로 전환한다.

실행 증거:
- 공식 자료 저장 및 재조회: COLLECTED / storageVerified=true.
- PC 저장 자료 계산: READY, 공통월 2026-08, 점수 35.858212274614715, 차트 13개 월.
- 전체 PC dry-run: DRY_RUN_PASS, 계산 providerCalls=0, 수집 상태 25/25 정상.
- 후보·운영·기존 수집/자산 검사 22개 통과. 추가 배포 계약 회귀 15개 통과.
- Vite 후보 prerender 빌드 통과. 공식 배포 빌드는 main 브랜치 전용이므로 작업 브랜치에서 미실행.

배포와 Production Runtime 검증은 별도로 기록한다. 자료 이용 조건의 미확인 부분과 당시 발표본 검증은 후속 항목이며 위 로컬 실행 증거를 운영 배포 완료로 해석하지 않는다.
