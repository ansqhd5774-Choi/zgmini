# 이란 보도 흐름 R2 — 1차 구현 계약

사용자 승인: 2026-10-15. R1 원장·checkpoint·공개 key를 변경하지 않는다.
R2는 별도 key `public:iran-progress:reference-flow:r2`, 별도 classifier/queue를 사용한다.
산식 가중치는 외교30 / 휴전25 / 군사20 / 해상15 / 핵10%로 유지한다.
기준점50은 미관측 영역의 시작점이며 확률이 아니다. 표시 배율은1이다.
시간 경과만으로 중립 복귀하지 않는다. 날짜는 기사 발표일, 차트는14일이다.

## 사건 단계별 영역 가감점

|영역|긍정|부정|
|---|---|---|
|외교|협상 의향+2, 협상안 접수+3, 중재 회동+4, 협상 개최+8|협상안 거부−4, 결렬−10|
|휴전|서명+12, 실제 발효+15|위반−15|
|군사|철수+8|경고−2, 추가 배치−4, 실제 공격−12|
|해상|호르무즈 통항 재개+10|피해·통항 중단−10|
|핵|서명+10, 사찰 재개+12|사찰 중단−12|

모든 수치는 영역 점수의 변화다. 영역을0~100으로 제한한 뒤 가중합한다.
동일 날짜의 변화는 합산 후 제한하므로 기사 처리 순서에 의존하지 않는다.
의향은 실제 합의·이행으로 취급하지 않는다. 미래·조건·부정·복수 단계가 섞인
제목은 자동 확정하지 않고 제외 사유를 저장한다. 단일 출처는 계속
`SINGLE_SOURCE_REPORT`, `eventVerified:false`이며 출처가 공식 기관이어도 같다.

## 수집·재분석·중복

기존 Tasnim에 영국 정부 및 IAEA 공식 공개 피드를 추가한다.
일본 외교부의 기존 본문 adapter는 보존하며 R2 연결은 별도 검증 대상이다.
UKMTO는 출처 허용 대상이나 동적 목록의 파서 검증 전 수집원으로 활성화하지 않는다.
RSS 제목·링크·발표일과 기존 보관 metadata만 처리하며 유료 본문을 우회하지 않는다.
classifier 버전 또는 내용 hash가 바뀌면 제외 기사도 재분석한다.
주기적 metadata 확인은24시간 단위, 실패 재시도는1시간 이후, 호출당 기사 수는 제한한다.
같은 날짜·규칙·정규화 제목은 출처가 달라도1회만 반영한다.
서로 다른 제목의 의미상 동일 사건을 자동 판별했다고 주장하지 않는다.
그 경우 검토 후보로 남기며 무근거한 사건 ID를 만들어 확정하지 않는다.

## 운영 상태와 전환

정상 갱신, 신규 기사 없음, 분석 완료/점수 동일, 발견 지연, 분석 실패를 분리한다.
전체 발견 실패 시 마지막 유효 점수를 유지하고 checkedAt을 성공처럼 갱신하지 않는다.
일부 출처 실패도 출처별 상태와 마지막 성공 시각을 보존한다.
R2 저장 자료 비교 → 독립 공개 계약 검사 → PC 실제 실행 → 게시 readback →
API/화면 검증 후에만 R2를 우선 노출한다. 준비 전 R1을 계속 제공한다.
R1 과거 표시값을 R2 관측치로 이어 붙이지 않는다.

## 확인한 원천

- IAEA 공식 피드 목록: https://www.iaea.org/feeds
- IAEA Top News: https://www.iaea.org/feeds/topnews
- IAEA DG Statements: https://www.iaea.org/feeds/dgstatements
- 기존 외교부 수집 adapter의 실제 URL을 재사용한다.

수집 성공은 보도 내용의 사실 확인이나 전체 사건 포괄을 뜻하지 않는다.

## 실행

읽기 전용 기존 자료 재분석:
`node scripts/iran-progress/reference-flow-r2.mjs --replay <기존 DB> <새 보고서.json>`

별도 SQLite 복사본에서 제한된 실제 수집·재분석:
`node scripts/iran-progress/shadow-r2.mjs <기존 DB> <새 shadow DB> 4`

shadow 목적지는 새 파일이어야 한다. 기존 운영 DB·R1 checkpoint·스케줄·공개 점수는
변경하지 않는다. 출력의 `productionReady:false`는 운영 전환 미완료를 뜻한다.
이 단계의 replay는 보관된 news metadata 범위만 비교하며 기존 전체 공식 원장과
동일한 입력 집합의 성능 비교가 아니다. 입력 범위가 다른 점수를 정확도 개선으로 해석하지 않는다.

## 2026-10-15 1차 검증 기록

- R2 신규 검사와 관련 R1 회귀 검사27개 통과.
- 운영 SQLite 읽기 전용 backup의 별도 shadow DB에서 실제 발견 시험 수행.
- 영국 정부, IAEA Top News, IAEA DG Statements: 피드 응답·파싱 성공.
  이는 해당 기간의 유효 이란 사건 확보나 전체 본문 분석 성공을 의미하지 않는다.
- Tasnim: DNS 조회 `EAI_AGAIN`. 제한된 기사4건 분석도 실패.
  예외는 출처별 지연/분석 실패로 기록하며 마지막 성공 시각·저장 신호를 유지한다.
- 운영 DB, R1 checkpoint, 스케줄, 공개 API·UI 변경 없음. 배포·운영 전환 미실시.
- 남은 필수 항목: 동일 사건의 다른 제목 검토, 공식 원장 연결,
  R2 공개 계약/API·화면 연결, 새 자료 분석 성공 및 게시 readback 검증.

현재 파일은 운영 전환이 끝난 구현이 아니라 독립 검증 가능한 R2 수집·계산 기반이다.
