## 1. 확인된 소스 구조

- `scripts/iran-progress/continuous-news-r3.mjs`의 7개 R3 피드는 기존 **점수 원장**에서 사용한다. UI 표시 허용 목록과 혼동하지 않는다.
- 1차 표시 후보는 **GOV.UK의 OGL 적용을 확인한 개별 기사**만 허용한다. 모든 GOV.UK 관련 외부 콘텐츠가 일괄 OGL이라는 뜻은 아니다.
- GDELT 결과는 기사 후보 발견에 활용하더라도 원문 기사 표제·요약·사진의 공개 허가는 원 언론사별로 재검증해야 한다.
- BBC, Al Jazeera, Tasnim, IAEA, UN의 기존 R3 저장 데이터는 이 정책 변경으로 삭제하거나 수집 중단하지 않는다.

## 2. 아직 확인해야 할 것

1. 실제 PC에서 GOV.UK Atom 피드 응답의 상태·형식·개별 기사 `publishedAt` 타임스탬프를 읽기 전용 확인한다.
2. 기사별 Crown/OGL 적용 여부, 제3자 제공 내용/이미지 여부를 검토한다. 확인된 후보에만 `rightsVerified`와 정책 영수증을 부여한다.
3. 사이트의 한국어 자체 작성 요약을 실제 기사 내용과 대조한다. 무단 번역·원문 자동 전재는 허용하지 않는다.
4. GOV.UK 최신 기사가 0건이면 정상 0건으로 표시한다. 부족한 건수를 채우기 위해 권한 미확인 매체를 포함하지 않는다.

## 3. 구현의 안전 경계

기초 모듈은 GOV.UK OGL 개별 기사 확인 플래그와 정책 URL이 없으면 레코드를 반환하지 않는다. 14일 공개/30일 PC 표시 전용 보관은 기사 **발행 시각의 KST 날짜**를 사용한다. 이 구현은 기존 SQLite R3/R5 원장을 정리하거나 점수 산식에 영향을 미치지 않는다.

**현재 결과:** 정책·정적 로직 검증만 확인. 실제 라이선스 개별 판정, PC 원자료 처리, D1 게시, 사이트 공개는 미실행.
