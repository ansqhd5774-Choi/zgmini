# 우주·위성 테마 R27 — 기존 9개 불변, 승인된 4종 AUM 바스켓 연결

- 기준일: 2026-10-26
- 현재 선택: **UFO·NASA·WARP·ROKT**, 상한 없는 추후 추가 허용.
- ETF 개별점수: 기존과 동일한 T40/R20/V40; 단기 실가격 ETF만 승인된 적응형 R2로 계산.
- 유효 ETF 3종 이상: 사용자 승인 `AUMᵢ / ΣAUM`; 2종은 기존 장기/단기 혼합 또는 두 장기 50:50.
- 데이터: 기존 PC에 SHA 검증된 실가격·공유 SPY와 발행사 날짜별 AUM 증거를 **읽기만** 함. 신규 AUM API 없음.
- `theme-space-satellite-approved-r27.mjs`는 **비공개 점수 감사**이며 수집·배포·D1·작업 스케줄을 건드리지 않음.

## 검증

- 사용자 실 PC가 확인한 2026-10-23 ETF 4종 개별 점수 및 AUM으로 **44.65075** 재현.
- 결측 시 0점/직전 점수로 채우지 않음. 1개 ETF만 남으면 바스켓 점수 없음.
- 기존 9개 등록부·산식·원자료·D1 key·스케줄러·Reader 변경 0.
- 252일 미만 상장 ETF에 대해 628일 이력을 요구하지 않음. 252는 표시 기간.
- 과거 차트에 현재 AUM을 적용한 R27 preview가 있는 경우, 그 차트는 **현 구성비 고정 소급 비교**임을 명시함. 해당 날짜의 역사적 AUM 비중을 확인한 차트나 실제 투자 성과로 표현하지 않음.

## 운영 연결 상태

1. R27 **개별 ETF→현재 바스켓 점수** 비공개 계산 완료. 외부 제공자 신규 요청·권리/API 키 변경 없음.
2. 실제 PC 새 원자료 관측일·정규 반복 수집·승인된 252일 공개 이력 연결은 별도 구현/실행 기록으로 확인할 것.
3. 새 D1 feed key와 Reader 공개 경로는 아직 추가하지 않았음. GitHub 파일이나 CI 성공을 공개 완료로 보고하지 않음.
4. 기존 9개 정상 운영과 새 테마 후보의 결측/지연은 분리. 후보가 실패하더라도 기존 9개를 막지 않음.
