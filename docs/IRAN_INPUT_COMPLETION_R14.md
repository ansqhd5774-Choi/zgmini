## 실제 입력 감사

`node scripts/iran-progress/input-audit-r14.mjs`는 SQLite를 read-only로 열고 동일 시점의 checkpoint/source/event revision을 읽는다. 계산·검증·게시 기록은 생성하지 않는다. 실제 산식으로 부족한 영역을 확인하며 AIS 일별 검증은 운영 runner와 동일한 rowHash 대조를 사용한다. 숫자 0과 입력 부재를 구분한다.

실제 저장소에는 verified-input과 ais-verification checkpoint가 모두 없다. IRN_ISR/IRN_USA 관계 입력, 3축 군사 coverage, 해상 coverage, 핵 입력, 공식 항행 제한 입력이 없다. 중요한 사건 2개는 보류 상태다. 따라서 모든 영역 D/C/M/H/N이 PENDING인 이유는 다운로드 실패만이 아니라 검증된 입력 생성 경로의 미완성이다.

## 실행 경계와 후속 결정

산식·가중치·DB 스키마·기존 수집 작업·Production은 변경하지 않았다. 읽기/저장/검토 후보만으로 VERIFIED를 만들어서는 안 된다. 정확히 식별되지 않은 상위 AIS 원천 권한과 과거 일별 품질이 현 공개 문서에서 계속 확보되지 않는 경우, 문의하지 않는 사용자 조건에서는 이 경로를 그대로 완성한다고 보장할 수 없다. 새로운 허용 공급원 또는 검증 계약 변경은 별도 근거·승인 대상이다.

사건 전체 관측과 공식 제한 단계도 실제 증거로 확보해야 한다. 불명 사건을 임의 제외하거나 0으로 채우지 않는다. 기존 산식으로 끝까지 해소되지 않는 항목만 새 방법론의 점수 범위/신뢰도 제안 대상으로 한정한다. 현재 점수 공개 및 Production 완료는 미완료다.
