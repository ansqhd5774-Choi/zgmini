# 미국 등락 지수 — 사용자 승인 미확보 보합 기준 및 신규 1년 프리뷰 R21

기준일: 2026-11-01. 작업 브랜치: `codex/us-breadth-public-r1-20261031`.

## 승인한 계산 규칙

- 장중 잠정치 = Alpaca IEX 약 503종목 / 15분 갱신 / 미관측은 미관측. 잠정치에 확정치 98% 규칙이나 방향 일치율 게이트 없음.
- **새 전체시장 확정치 R2** = MarketParquet `stock_daily`의 당일 유효 주식 전부 (현재 실측 약 6,500종목). 당일 종가가 전일보다 높으면 상승, 낮으면 하락, 같으면 실제 보합.
- **현재 거래일에 종목은 있지만 전일 가격 행이 없는 경우** 사용자 최신 승인대로 보합 간주. 간주된 수(`imputedUnchangedCount`)와 실제 비교 가능한 수(`observedComparableCount`) 및 그 비율(`sourcePairCoverage`)은 총 보합 수와 별도 보존. 비교 가능한 소스 비율이 98% 미만이어도 신규 R2 계산 후보를 거부하지 않는다.
- 원자료의 날짜 오류, 중복 종목, 0/음수/NaN 가격, 손상 파일 등은 보합으로 가장하지 않고 계산을 거부한다. 데이터 출처·무결성·양 거래일 원장 요구는 유지한다.
- 기존 **503개 확정치 R1**, **기존 250거래일 확정 이력**, 기존 R1 98% 검증 정책은 한 건도 덮거나 재계산하지 않는다. 새 전체시장 1년 이력은 반드시 별도 데이터 시리즈로 생산한다.

## R21 신규 1년 시계열 프리뷰

- `scripts/pc-writer/us-breadth-confirmed-history-r21.mjs`: 원장 검증을 통과한 **완료 거래일 251개**를 받아 새 전체시장 **250거래일 점**을 만든다. 날짜는 뉴욕 거래일 달력으로 연속해야 한다. 원장이나 한 날짜의 원자료 검증이 실패하면 일부 점을 기존 이력으로 보완하지 않고 전체 프리뷰를 중단한다.
- 점마다 `rising`, `falling`, `unchanged`, `imputedUnchangedCount`, `observedComparableCount`, `sourcePairCoverage` 및 상승/하락/보합 비율을 저장할 수 있는 **메모리 결과**를 반환한다. `publicationStage=PREVIEW_ONLY`; API/D1/PC 예약 실행과 연결하지 않았다.
- 기존 `public:market-breadth-r1:usa` 및 `public:market-breadth-r1:usa:YYYY-MM-DD`와 새로운 `public:market-breadth-confirmed-r2:usa:staging`은 읽거나 덮어쓰지 않는다. 새 1년 프리뷰는 아직 별도 D1 히스토리 키나 공개 페이지를 만들지 않는다.

## 남은 작업·실제 차단 조건

1. 운영 PC에 MarketParquet 전체 `stock_daily` 251거래일 원자료와 승인 원장이 있는지 **R18 읽기 전용 감사**. 없으면 무료 소스의 접근 범위 확인 및 사용자 승인된 수집 범위에서 별도 확보 경로 검토. 원자료를 확보하지 않고 1년 차트를 실제 검증했다고 주장할 수 없다.
2. 실제 250개 새 R2 시계열 수치와 이상치/보합 간주 비중 검산. 이후 사용자 요청대로 문제 심각할 때만 보합 규칙 개선 검토.
3. PC 운영 설치 및 실제 R2 확정 D1 저장·읽기, 전체시장 공개 API/UI 연결은 **별도 Gate**. 기존 확정치·250일 이력 보존과 잠정치 구분, 브랜치/PR·Cloudflare 배포 절차 준수.
