# 빈 응답과 불완전 공개본 방지

## 보호 범위
- 거시 전체·거시 신용·금리·신용·공급·자금흐름·BIS 입력은 필수 자료 검증 후 저장한다. 공급과 자금흐름에도 빈 배열 및 유효 숫자 없는 행 검사를 적용한다. 정상 숫자 0은 결측이 아니다.
- CNN·경제 지표·근원 PCE 공용 feed 저장소는 해당 입력/출력 계약을 검사한다. 실패 진단 기록은 별도로 허용한다.
- PC 시장 게시기는 수집 성공 여부와 무관하게 12개 필수 영역 READY, 유효 점수, 종합 READY, 비어 있지 않은 유효 종합 추이를 요구한다. 로컬 current/result 교체 전과 원격 게시 계획 생성 전에 검사한다.
- 기존 D1 batch의 lease 및 이전 세대 검사, 게시 후 readback을 유지한다. 원격 변경·응답 불명확 시 임의 재전송하지 않는다.
- 산식·비중·최소 산정 자료·TTL·기존 관측일을 변경하지 않는다. 실패 시 정상 자료의 시각을 갱신하지 않는다. 보존된 공개본도 기존 표시 유효기간이 지나면 API의 기존 STALE 처리를 따른다.

## 로컬 한글 경고
- 기존 collect-local / run-local / local-cycle에서 실행한다. 새 예약 작업·외부 발송·계정은 만들지 않는다.
- 수집 항목별 실패와 실제 게시 실패를 별도로 기록한다. 같은 항목의 지속 실패에는 새 알림을 만들지 않으며 해당 항목의 성공에만 해제한다. cached/deferred/skipped는 복구 증거가 아니다.
- `data-alert-state.json`: 현재 경고와 최근 200개 상태 전환. `data-alert-status.txt`: 한글 상태. `data-alert-delivery.json`: 창 실행 결과.
- Windows WScript 경고창은 확인할 때까지 남는다. 이미 경고창이 열려 있으면 추가 창 대신 상태 기록을 갱신한다. 소리는 Windows 경고음 설정에 따른다. 비대화형 세션 또는 WScript 정책 차단 시 화면 전달은 보장되지 않으며 파일 기록을 사용한다.
- 메시지에 원자료·키·URL·원문 예외는 포함하지 않는다. 테스트에서는 임시 경고 폴더와 주입된 알림 함수를 사용한다.

## 한계
- 다른 독립 테마·이란 전용 수집기의 스키마 및 권리 계약을 이 공용 feed 계약으로 대체하지 않는다.
- 외부 공급자 장애 자체를 제거하지 않는다. 본 보호는 실패 결과의 정상 자료 덮어쓰기와 불완전 시장 공개본 게시를 차단한다.
