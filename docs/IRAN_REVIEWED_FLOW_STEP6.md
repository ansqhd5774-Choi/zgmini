# 승인된 이란 참고 흐름 STEP6

2026-10-09 사용자 승인에 따라 로컬 비교한 기사 기반 참고 신호를 운영 PC 계산에 추가한다. 외교 30%, 휴전 25%, 군사 20%, 호르무즈 15%, 핵 10% 및 기준점 50을 유지한다. 공식 종전 판정·확률과 분리한다. UI 변경은 없다.

`reference-flow-reviewed-signals-step6` 로컬 checkpoint에 검토한 신호와 SHA-256 입력 해시를 저장한다. 원문 일치 검토 및 Ollama 후보 분석을 거친 신호이며, 별도로 검증한 실제 사건이라는 의미는 아니다. 기존 공식 기사 계산과 함께 재계산하므로 정기 게시 시 승인된 이력이 사라지지 않는다. 새로운 기사 전체에 이번 확장 규칙을 자동 적용하는 기능은 포함하지 않는다.

군사 태세·준비 보도는 실제 공격과 구분하여 작은 감점으로 반영한다. 검색 색인만 확인한 출처는 직접 본문 확인과 구분한다. 미확인 실제 사건일은 null이며 차트는 기사 게시일 기준이다. 같은 규칙의 당사자 발언은 기존 시험의 3일 간격 선택 결과를 저장한다.

공개 `events`는 기존 공식 출처 계약을 유지한다. 추가 신호는 원문 인용을 제외한 `reviewedSignals`에 제공하고 `reviewedMethod`로 계산 방식을 표시한다. 수집 실패는 마지막 정상 결과와 갱신 지연 상태를 유지한다. 14일 모두 변한 결과는 탐색 결과이며 정확성 검증을 뜻하지 않는다.
