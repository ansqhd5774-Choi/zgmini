- 목적: SEC 원자료를 PC에 유지한 채 연 1회 수동 실행된 `ZGMINI-FHS-R3` 재무건전성 잠정 등급을 기업 실적의 별점 열에 연결한다.
- 기존 20/15/25/40 산식과 R58.3 1,615개 등급 후보(★★★ 451 / ★★ 610 / ★ 554)는 변경하지 않는다.

- API 응답은 HTML-only 실적 표시이며, R59 배포 검증용 `x-zgmini-fhs-r3-reader: ZGMINI-FHS-R3` 헤더를 반환한다.
- PC 게시 도구는 기존 R58.3 비공개 파일을 로컬에서만 읽고 공개 D1 단일 키 `market-calendar:fhs-r3-annual`에 티커·별표·점수·평가기준일을 저장한다. SEC 원재무수치는 전송 금지.
- PC 실행 도구는 R58.3 결과 자동탐색, 미발견/중복 즉시 중단, D1 기존 결과 우선 보존, 원격 최신일/본문 검사, 저장 후 D1 재조회로 검증한다.
- 자동 갱신/예약 작업·Cloudflare Cron·신규 데이터 수집·원 DB 스키마/DNS 변경 없음.
