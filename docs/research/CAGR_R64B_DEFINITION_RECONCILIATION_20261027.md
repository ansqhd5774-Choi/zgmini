# ZGMINI R64B — 산업·테마 CAGR 보고서 세부시장 정의 2차 감사

- 점검일: 2026-10-27 KST / 범위: 21개 주제 × 공식 조사기관 3곳(총 63칸)
- 상태: `DEFINITION_RECONCILIATION_COMPLETED_FOR_CANDIDATE_TRIAGE` / `FINAL_TARGET_CAGR=UNCOMPUTED`
- 이전 단계: [R64 시장명 그룹 1차 감사](CAGR_R64_SCOPE_AUDIT_20261027.md).
- 본 차수는 공식 보고서 60개 URL을 웹 검색 서비스의 크롤링 열람·시장분할 찾기로 재교차확인했다. R64B에서 추가 직접 HTTP GET을 60회 수행했다는 뜻은 아니다. 최신 직접 수집 증거는 별도 R63 UTC/SHA 원장에 있다.
- 출처 원문에서 확인된 각 기관 CAGR(58건)은 변경하지 않는다. 원문 내부 편집 충돌, 비교 시장 범위의 차이, 전망 기간 모호함은 별도 플래그로 관리한다.

## 1. 결과 요약

- A `SEGMENT_COHERENCE_CANDIDATE`: 7개. 같은 세부시장에 대한 복수 매체 비교를 진행할 근거가 상대적으로 뚜렷함. **최종 집계 승인 아님**.
- B `DEFINITION_REVIEW_REQUIRED`: 11개. 범위 차이/포함 업종/가치 추정 차이를 해소해야 함.
- C `NO_COMPARABLE_MARKET_PAIR`: 3개. 정보기술·필수소비재·원전·SMR은 2개 이상의 동등한 시장 기준 부재.
- Precedence 추가 불일치: 첨단소재 6.21 vs 6.27 (주요 수치·규모는 6.21을 지지), 위성 시장 크기 비교시 14.79배, 핀테크 블록체인 106.81배. 규모 차이만으로 어느 기관을 거짓으로 확정하지 않으며 **집계 편입 보류 사유**로 기록한다.
- 출처 수치 검증 상태는 58/63 그대로다. 이 수치는 대상 주제의 평균 CAGR 확정률이 아니다.

### 판정 해석

- **A**: 보고서 제목뿐 아니라 대표 세부시장들이 중첩돼 비교할 자료가 있다는 의미. 서로 다른 예측치의 합리적 차이는 허용한다. 시장규모·수익범위·연도를 최종 확인해야 한다.
- **B**: 시장 범위·단위·상품 포함에 확인할 사유가 관측됨. 자료를 버리는 것이 아니라 동일 시장 그룹으로 묶을 때만 보류한다.
- **C**: 두 기관이 실제로 서로 다른 시장을 분석하거나 공식 대등 출처가 없다. 숫자가 없어서 0으로 처리하지 않는다.
- **중요:** GICS는 상장기업 활동별 분류체계다. 발행사의 세계 시장규모 성장률과 GICS 섹터의 투자 매력도·매출 성장률을 자동 동일시하지 않는다.

## 4. 다음 작업 R65에 넘길 검증 계약

1. A 7개는 **동일 시장의 기준연도 시장규모·수익 정의·포함 상품**까지 최종 대조한 뒤 평균 후보로 승격한다. 상충 수치·시장규모 3배 이상 차이는 `REVIEW`, 10배 이상은 `SCALE_ALERT`로 표시하되 기계적으로 진위 판정하지 않는다.
2. B 11개는 대표 하위시장 분류를 구체화해 가능하면 별도 공통시장 2곳 이상을 확보한다. 다른 표제 하위시장들을 무리하게 평균내지 않는다.
3. C 3개는 같은 모집단의 공식 보고서를 추가 탐색한다. 자료를 찾지 못하면 `MISSING/INSUFFICIENT_PUBLISHERS`로 유지한다.
4. CAGR 기준 기간이 다른 출처는 원문 기간을 보존하고, 기간을 무시한 단순 평균은 반드시 `MIXED_FORECAST_HORIZON_REFERENCE`로 따로 표시한다.
5. 검증된 직접 시장의 평균과 GICS 섹터/복합 테마 성장률 추정치를 다른 명칭으로 제공한다. 시장 합성·가중치·산식 편입은 별도 승인.
6. PC Ollama의 워밍업+3회 실측은 이 감사에서 미실행. 이후 PC에서 확인하더라도 공식 보고서 숫자를 모델이 새로 생성하거나 덮어쓸 수 없다.
