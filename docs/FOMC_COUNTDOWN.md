# 연준 금리 발표 카운트다운

- 웹(1024px 이상) 높이 30px, 모바일·태블릿 24px. 한 줄, 전체 바 기준 중앙 정렬. 미국 국기·이동 아이콘·링크 없음.
- 공식 인장은 연준 서면 허가가 필요하므로 사용하지 않는다. 독자적인 일반 중앙은행 아이콘 사용.
- 공식 예정일 스냅샷 확인: 2026-10-21. https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm
- 2026-10-28 14:00 Eastern은 https://www.federalreserve.gov/newsevents/2026-october.htm 에서 확인. 기자회견 14:30과 구분한다.
- 2026년 잔여 및 2027년 공식 예정일을 저장한다. 각 일정은 변경 가능하며 연준은 직전 회의 확인 전 잠정 일정으로 안내한다. 일정 수정 시 본 모듈의 저장 목록을 공식 원문과 대조해 갱신한다. 미확인 연도는 생성하지 않는다.
- America/New_York 시간대에서 오후 2시를 UTC로 변환하여 서머타임과 한국시간 날짜 변경을 처리한다.
- 브라우저 Date.now로 매초 남은 시간을 재계산한다. 숨김 탭 복귀 시 즉시 보정. Provider/API/DB/PC Writer 호출·변경 없음.
- 발표 예정 시각 도달 후 24시간은 ‘발표 시각 도달 · 결과 확인 중’. 실제 결과·인하 여부를 단정하지 않는다. 이후 다음 저장 일정으로 전환, 일정 소진 시 ‘다음 공식 일정 확인 필요’.
- 초 단위 스크린리더 반복 안내 금지(aria-live off), 동작 줄이기 설정에서는 플립 애니메이션 생략.
- 금융 산식·가중치·데이터·스케줄러·DNS 변경 없음.
