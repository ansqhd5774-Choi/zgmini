# 소비 R5 승인 계약

2026-10-10 사용자 승인: D 실제 소비 30%, Y 소득 기반 25%, L 고용 기반 15%, H 가계 금융 여력 20%, B 소비 증가 확산 10%.
세부 비중은 승인 대화의 D 40/35/25, Y 60/40, L 50/50, H 25/35/40, B 50/25/25를 유지한다.
정규화는 현재 관측을 제외한 이전 10년의 동일 주기 구간(월 120, 분기 40)에서 실제 발표된 유효 관측의 경험적 백분위다. 유효 관측 90% 미만은 보류하며 referenceCount/referenceExpected를 공개한다. 과거 미발표 월을 값으로 채우지 않는다. 실제 2025년 10월 EMRATIO/CPI 미발표가 참조 구간에 있어 모든 향후 월을 10년간 보류하는 오류를 방지하기 위해 현재 입력 결측과 참조 분포 결측을 구분한다. 동일값은 중간 순위를 사용한다. 부채 부담과 연체는 역방향이다. 확산은 증가 항목 비율을 그대로 사용한다.
완전한 기준 분포 또는 필수 항목이 없으면 PARTIAL/null. 결측 항목을 제외하고 비중을 재조정하지 않는다. 분기는 실제 공개일 이후만 반영하고 6개월 초과 관측은 보류한다.
원자료에는 observationDate와 availableDate를 구분해 저장한다. 추정 발표 지연을 실제 발표일로 위장하지 않는다. 현재 수정 자료로 산출한 역사에는 CURRENT_VINTAGE_ONLY/lookAheadSafe=false를 표시한다.
세부 소비 분류는 중복 없는 동일 단계, 계절조정 실질 월간 자료로 고정해야 한다. 자료 검증 전 임의로 상품·서비스 두 항목만을 확산 지표에 대입하지 않는다.
원값·단위·관측월·출처·변환 점수·총 비중을 펼침 화면에 표시한다. '미국 소비 전체 안정'을 입증하는 지수로 표현하지 않는다.
기존 R3/R4 이력을 보존하고 R5와 연결하지 않는다. 운영 전환은 원자료 수집/저장/검산과 13개월 공개 결과가 준비된 뒤 수행한다.
