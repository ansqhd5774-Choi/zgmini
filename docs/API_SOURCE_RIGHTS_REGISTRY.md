# ZGMINI 시장데이터 공급자 API 공개 이용권 조사 정본

- 최초 기록: **2026-11-07 (KST)**.
- 목적: 다른 기능 담당자가 이미 확인된 무료 API 권한을 반복 조사하거나, **수집 성공을 사이트 공개 게시 허가로 오인하는 일**을 방지한다.
- 적용 대상: 아래 **명시된 상품·피드·사용 방식**에 한정한다. 다른 공급자, 유료 계약, Alpaca SIP 지연 피드로 결론을 확대하지 않는다.
- 이 문서는 권한 조사 기록이다. 운영 수집·계산·게시의 실제 상태나 배포 승인 자체를 변경하지 않는다.

## 1. 무료 접근과 공개 게시 권한

| 구분 | Alpaca 무료 Basic **IEX** | MarketParquet **무료 일봉 / 무료 샘플** |
|---|---|---|
| 접근·수집 | Basic 계정으로 IEX 미국 주식·ETF 시세 접근 가능 | 무료 EOD/일봉 파일 시험 다운로드 가능 |
| 내부 수집·연구 | 개인·내부 분석 범위에서 가능. 계정 약관 준수 | 시험·검증 가능. 무료 파일은 정식 게시 라이선스가 없음 |
| 원자료 제3자 재배포 | 승인 근거 없음 / 약관상 제한 | 허용되지 않음 |
| ZGMINI 공개 **파생 점수·차트·등락 비율** | **무료 Basic IEX 범위에서 불허**: 공급자 지원 회신상 별도 서면 승인·계약 필요 | **무료 파일 범위에서 불허**: 공급자 서면 회신상 무료 파일에 게시 라이선스 없음 |
| 근거 수준 | **2026-10-23 지원 티켓 #380205**, AI 작성 안내. 공식 약관과 대조; 사람 담당자의 별도 최종 허가 아님 | **2026-11-05 공급자 직접 회신** 및 공식 무료 안내. 유료 라이선스 조항은 무료 파일에 적용되지 않음 |
| 문의 상태 | 별도 공개 허가 **미확보** | **기존 2026-11-05 문의: 답변 완료·확정** (무료 불허/아카이브 구매 시 허용). **2026-11-07 전체 시장 breadth 무료 예외 문의: 선택적 추가 제안, 답변 대기**. **기존 무료 게시 불허 확정에는 추가 답변이 필요하지 않으며, 기능 개발·권리 판정·유료 대안 검토의 선행 Gate가 아니다.** 회신이 오면 사용자가 전달할 예정 |

**해석상 주의**

1. HTTP 200, 무료 데이터 다운로드, API 키 발급, 로컬 원자료 저장 가능 여부는 **외부 방문자에게 수치·차트를 공개할 권리의 증거가 아니다**.
2. 원자료를 재구성할 수 없는 **파생 지수·비율**이어도, 무료 계약 자체에 공개 권한이 없으면 파생이라는 이유만으로 허가되지 않는다.
3. 해당 결론은 **Alpaca Basic IEX**와 **MarketParquet 무료 파일**에 관한 것이다. Alpaca **지연 SIP** 등 다른 피드의 세부 권리는 별도 약관·공급자 회신으로 확인한다.
4. 코드·manifest의 `derivedStatisticsAllowed: true`, `licensingRiskAcceptedByPublisher: true` 또는 내부 승인 표시는 **공급자가 부여한 권리의 증거가 아니다**.

## 2. 검증 근거와 원문 확인 경로

### Alpaca Basic IEX

- 공식 [Market Data API/무료 Basic 피드 안내](https://docs.alpaca.markets/us/docs/about-market-data-api): 무료 IEX 시세 제공 범위 확인.
- 공식 [Terms and Conditions PDF](https://files.alpaca.markets/disclosures/library/TermsAndConditions.pdf): 개인·비상업 목적, 제3자에 대한 표시·게시·배포 제약과 사전 서면 동의 조항 확인. 제3자 앱 관련 **통지**는 공개 재배포 **승인**과 다르다.
- **2026-10-23 티켓 #380205**: Basic IEX 데이터 기반 ETF 0~100 파생 점수·공개 차트 사용 가능 여부에 대하여 무료 플랜 불허 및 별도 계약 필요 안내. **AI 자동 답변**이라는 증거 수준을 유지하고, 서면 허가를 받은 것으로 표현하지 않는다.

### MarketParquet 무료 파일

- 공식 [무료 과거 시세 안내](https://marketparquet.com/guides/free-historical-stock-data): 무료 파일은 시험용이며 공개 라이선스 없음.
- 공식 [데이터 라이선스](https://marketparquet.com/license): **구매한** 아카이브의 비복원성 파생 통계 공개 권리를 설명한다. 이 조항만으로 **무료 파일**에 동일 권리가 생기지는 않는다.
- **기존 2026-11-05 직접 서면 회신(답변 완료)**: 공급자는 웹사이트의 무료 가이드와 라이선스 페이지 사이의 설명 불일치를 인정하고 무료 가이드를 수정했다. **계정 없이 받은 무료 파일과 무료 계정 다운로드 모두 라이선스가 없으며, 테스트 샘플이므로 게시용으로 사용할 수 없다고 명확히 답했다.**
- **유료 권리 범위(동일 회신에서 확정)**: **완전 아카이브 미화 79달러 일회성 구매 시** 구매일까지의 데이터에 대한 라이선스가 부여된다. 동일 일별 파일로 이미 계산한 점수도 포함된다. **기본 가격 차트를 재구성할 수 없는 파생 결과**는 광고가 있는 공개 웹사이트에 게시할 수 있으며, 직접 계산한 **0~100점 점수와 차트**도 포함된다. **저작자 표시·링크·등록·출처 표기 의무는 없다.** (공급자 답변 시점 가격; 변동 가능)
- **데이터 범위·조정(동일 회신에서 확정)**: 구매일까지 모든 날짜(질의했던 **2026-10-19·10-20 포함**) 제공. 일별 종가는 정규 거래 세션 종료 시 상장 거래소의 **최종 경매 가격**이며, **SPY를 포함한 ETF 가격은 주식 분할만 조정되고 배당 조정은 적용되지 않는다.**
- **추가 최신 일자**: 공급자는 구매 이후의 신규 일봉을 받는 **Keep Current 월 15달러** 상품을 별도로 안내했다. **아카이브 구매 없이 무료 파일만으로 공개할 수 있다는 뜻은 아니다.**
- **2026-11-07 선택적 예외 제안(답변 대기, 필수 아님)**: 원자료·OHLCV를 제공하지 않는 시장 전체 등락 비율과 breadth 지수에만 **새로운 무상 예외 서면 허가**를 줄 수 있는지 별도로 문의했다. 11월 5일 회신은 이미 **무료 파일 공개 불허를 명확히 확정**했으므로 **예외 답변은 필수 확인이나 게시 작업의 Gate가 아니다**. 예외 허가가 새로 오지 않는 한 기존 불허 판단을 유지한다.
- **구매·구독 결제는 사용자가 승인하지 않았으며, 이 문서는 결제를 지시하지 않는다.**

## 3. 재조사 방지와 운영 범위

1. 신규 공개 지표가 이 두 소스를 사용하려 하면 **이 정본을 먼저 확인**한다. **공급자 약관·상품·이용 방식이 바뀌었거나 최신 직접 회신이 도착한 경우**에만 관련 항목을 재검증·갱신한다.
2. 권리 검토에서 **로컬 수집·계산**, **외부 공개 파생 결과**, **원자료 재배포**를 별개의 권한으로 판정한다. **잠정치와 확정치**도 각각 실제 사용한 피드로 판단한다. 공개 불허를 수집기 자체의 기술 실패로 기록하지 않는다.
3. 현재 존재하는 ZGMINI 게시 결과의 상태를 이 문서만으로 **숨김·삭제·중단·롤백하지 않는다**. 기존 운영 조치는 해당 담당자와 사용자의 별도 승인 범위에서 결정한다. 권리 검토가 다른 독립 기능 개발의 전역 중단 사유도 아니다.
4. 별도 서면 권리가 확인되지 않은 **신규 공개 게시**를 무료 사용 허가로 간주하지 않는다. 유료 계약·구독·자동 결제는 **사용자 별도 명시 승인**이 필요하다.
5. 공급자 회신이 오면 **답변 날짜, 해당 상품·피드, 허용하는 공개 산출물, 기한·출처 표시·제약, 증거 수준**만 이 표에 갱신한다. 이메일 전문·개인정보·API 키·원자료는 GitHub에 저장하지 않는다.
