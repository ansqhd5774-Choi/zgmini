- 최초 기록: 2026-11-07 KST. **최종 회신 대조: 2026-11-08 KST.**
- 범위: ZGMINI 관련 Gmail에서 확인된 **10개 공급자의 API·데이터 권한 문의**(2026-10~11월 발신 및 후속 회신). 공급자·상품/피드·무료/유료 요금제·내부 분석/공개 파생 지표/원자료 재배포를 각각 구분한다.

## 2. 확정 답변의 세부 조건

### MarketParquet — 무료 사용 불허 / 구매한 날짜에 한한 유료 파생권

- **2026-11-05 사람 담당자 회신:** 무료 가이드에 ‘무료도 게시 가능’처럼 적힌 내용은 잘못되었고 수정했으며, 라이선스 페이지가 정확하다고 설명. 비회원 무료 다운로드와 무료 계정 파일 모두 **시험 샘플일 뿐 게시 라이선스 없음**. 공개 웹사이트의 비복원성 파생 지수·점수·차트도 무료로 게시할 수 없음.
- 같은 회신에서 안내된 **Complete Archive 미화 79달러 일회성** 구매: 구매일까지의 데이터(2026-10-19·20 포함)에 대한 라이선스가 부여되고, 그 파일로 미리 계산한 점수에도 적용. 원자료를 재구성할 수 없는 0~100점·차트의 광고 지원 공개 사이트 게시 가능. 별도의 출처 표시·링크·등록 의무 없다고 답변. **Keep Current 월 15달러**는 구매 이후 신규 날짜 데이터에 대한 별도 상품. 가격은 답변 당시 안내이며 최신 계약·대상 데이터에 따라 재확인 필요.
- 종가는 정규장 종료 시 상장 거래소의 closing auction 값이며 SPY 등 ETF는 **주식 분할만 조정**, 배당 조정은 아님.
- **2026-11-08 사람 담당자 최종 회신:** 무료 `stock_daily` 파일로 만드는 시장 전체 상승·하락 종목 수, 비율, 비복원성 breadth 지수에 대한 **특별 무상 예외도 허용 불가**. 디스플레이 광고 도입 여부가 결론을 바꾸지 않음. **선택적 예외 문의는 `CLOSED_DENIED`, 더 이상 `답변 대기`가 아님.**
- 공식 근거: [무료 샘플 가이드](https://marketparquet.com/guides/free-historical-stock-data), [구매 데이터 라이선스](https://marketparquet.com/license). **구매·월 구독은 승인되지 않았음.**

### Twelve Data — 사람 담당자 확정 거절

- **2026-10-21 사람 담당자 회신:** Free Basic·individual 플랜은 개인/내부 사용 전용. 가격을 직접 공개하지 않더라도 해당 데이터로 계산한 **비복원성 파생 점수·과거 차트를 공개 사이트에 표시하는 것은 external display**로 불허. 좁은 범위의 **무료 서면 예외도 없음**.
- 공급자 안내상 최소 공개 이용 상품은 **Venture 월 149달러부터**, 출처 표기 필요. 광고·후원·기부·구독이 추가되어도 공개 이용 권한이 무료로 전환되지 않음. 가격은 답변 당시 안내. 공식 [약관](https://twelvedata.com/terms), [사업자 플랜](https://twelvedata.com/pricing-business).
- 초기 AI 상담원 안내 뒤 **사람 담당자 Artemis가 직접 동일 결론을 확정**했으므로 단순 AI 답변 대기로 되돌리지 않는다.

### Alpaca Basic IEX — AI 답변임을 유지

- **2026-10-23 지원 티켓 #380205**는 AI 자동 생성으로 명시. Basic IEX의 사적 전략·백테스트·도구·일정 범위 개인용 저장은 가능하다고 안내했으나, 외부 방문자에게 공개하는 파생 점수·차트는 무료 이용권에 없고 별도 서면 승인·계약이 필요하다고 안내.
- 공식 [Market Data API/무료 피드 안내](https://docs.alpaca.markets/us/docs/about-market-data-api), [약관 PDF](https://files.alpaca.markets/disclosures/library/TermsAndConditions.pdf)와 대조. **IEX 결론을 지연 SIP 등 별도 피드에 자동 적용하지 않는다.**

### AxionQuant — 파생 결과 권리와 실제 데이터 상품 제공 범위 분리

- **2026-10-14 사람 담당자 회신:** Free 플랜에서 취득할 수 있는 데이터로 계산한 파생 지표를 공개/상업 사이트에 게시하는 원칙 자체는 허용, **원자료 API 데이터 재배포 금지**. 다만 문의한 `GET /earnings/:ticker/trend`의 **Earnings Trend는 유료 Starter** 제공 기능이므로 무료 호출 가능하다는 의미가 아니다.
- `epsTrend.30daysAgo`는 API에서 제공하는 30일 전 값이나 특정 회계 목표 기간에 대해 별도 복원한 PIT consensus snapshot 보증은 아님. S&P 500 전 종목 100% 커버리지 약속도 확인되지 않았고 다종목 단일 batch endpoint는 없다고 답변. 공식 [요금제](https://axionquant.com/pricing/).
- 구매하지 않은 Starter 데이터 접근·상업 공개 라이선스가 자동 확보됐다고 표현하지 않는다.

## 5. 재조사 방지·운영 원칙

1. 신규 데이터 소스 조사·공급자 권한 이메일 발송 **전에 이 대장과 같은 공급자의 기존 발신/수신 스레드를 함께 확인**한다. 정확히 같은 상품·플랜·이용 방식에 `DENIED` 또는 이미 답변된 상태라면 재문의하지 않는다. 새로운 요금제·별도 계약·사용 방식이 실질적으로 바뀔 때만 새로운 질문을 구성한다.
2. `AWAITING_REPLY`는 **기존 스레드 하나**로 추적한다. `DELIVERY_FAILED` 또는 `VERIFICATION_REQUIRED`를 단순 `AWAITING_REPLY`로 바꾸거나 같은 메일을 무제한 재발송하지 않는다.
3. 권리 검토에서 **로컬 수집·계산**, **외부 공개 파생 결과**, **원자료 재배포**를 별개로 판정한다. 무료 접근 가능/HTTP 200, 코드의 `derivedStatisticsAllowed`, `licensingRiskAcceptedByPublisher` 등 내부 표시는 공급자의 서면 라이선스가 아니다.
4. 이 문서는 **새로운 운영 승인·유료 결제·구독 승인**이 아니며, 기존 게시를 임의 숨기거나 삭제하거나 다른 피드까지 일괄 금지하는 명령도 아니다. 실제 공개 소스가 불허 무료 데이터인 경우 **운영 담당자가 별도 실제 데이터 출처·게시 증거와 승인 범위를 확인**해 조치한다.
5. 변경된 회신이 오면 **수신 날짜·상품·이용 목적·허용/불허 범위·조건·답변 주체(사람/AI/자동 회신)·증거 ID**만 갱신한다. 문의 전 단계의 초안·발송 실패·접수 인증은 답변으로 승격하지 않는다. 확정 회신을 '미확인'으로 되돌리지 않는다.
