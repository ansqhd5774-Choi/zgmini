## 2. 확정 답변의 세부 조건

### MarketParquet — 무료 사용 불허 / 구매한 날짜에 한한 유료 파생권

- **2026-11-05 사람 담당자 회신:** 무료 가이드에 ‘무료도 게시 가능’처럼 적힌 내용은 잘못되었고 수정했으며, 라이선스 페이지가 정확하다고 설명. 비회원 무료 다운로드와 무료 계정 파일 모두 **시험 샘플일 뿐 게시 라이선스 없음**. 공개 웹사이트의 비복원성 파생 지수·점수·차트도 무료로 게시할 수 없음.
- 같은 회신에서 안내된 **Complete Archive 미화 79달러 일회성** 구매: 구매일까지의 데이터(2026-10-19·20 포함)에 대한 라이선스가 부여되고, 그 파일로 미리 계산한 점수에도 적용. 원자료를 재구성할 수 없는 0~100점·차트의 광고 지원 공개 사이트 게시 가능. 별도의 출처 표시·링크·등록 의무 없다고 답변. **Keep Current 월 15달러**는 구매 이후 신규 날짜 데이터에 대한 별도 상품. 가격은 답변 당시 안내이며 최신 계약·대상 데이터에 따라 재확인 필요.
- 종가는 정규장 종료 시 상장 거래소의 closing auction 값이며 SPY 등 ETF는 **주식 분할만 조정**, 배당 조정은 아님.
- **2026-11-08 사람 담당자 최종 회신:** 무료 `stock_daily` 파일로 만드는 시장 전체 상승·하락 종목 수, 비율, 비복원성 breadth 지수에 대한 **특별 무상 예외도 허용 불가**. 디스플레이 광고 도입 여부가 결론을 바꾸지 않음. **선택적 예외 문의는 `CLOSED_DENIED`, 더 이상 `답변 대기`가 아님.**
- 공식 근거: [무료 샘플 가이드](https://marketparquet.com/guides/free-historical-stock-data), [구매 데이터 라이선스](https://marketparquet.com/license). **구매·월 구독은 승인되지 않았음.**

- **2026-10-21 사람 담당자 회신:** Free Basic·individual 플랜은 개인/내부 사용 전용. 가격을 직접 공개하지 않더라도 해당 데이터로 계산한 **비복원성 파생 점수·과거 차트를 공개 사이트에 표시하는 것은 external display**로 불허. 좁은 범위의 **무료 서면 예외도 없음**.

- **실행 원칙:** 공식 약관의 조건부 허용을 `publicationAuthorized=true`·`derivedLicenseVerified=true` 등의 자동 승격 근거로 단독 사용하지 않는다. 해당 게시물의 공급자 계보·무료/유료 플랜 조건·원가격 미노출·비복원성·다른 공급자 권리를 실제 검증한 뒤 승인된 Writer에서만 필요한 최소 D1 쓰기를 한다. 무료 MarketParquet/Twelve Data/Alpaca의 거절·미확인 상태는 그대로 유지한다.

### 2026-11-18 현행 약관 검증과 W03 실PC 증거의 분리

- **약관 버전:** 공개 [Terms §5·§6](https://getmarkethistory.com/docs/terms)는 2026-11-17 시행이다. 이전 대장의 2026-10-29 시행 표기는 과거 버전 근거로만 남기고 현행 권리 판단을 대체하지 않는다. 현행 §5는 정상 상태 계정에 데이터를 사용할 라이선스를 부여하면서 원자료를 대량 복원할 수 없는 파생물 배포를 허용한다. §6은 무료 샘플도 같은 데이터를 포함하고 같은 약관을 적용한다고 설명한다. [Partners](https://getmarkethistory.com/docs/partners/)는 파생물 공유와 원시 가격·시세 차트 표시/원자료 재배포를 구분한다. **익명·무계정 1h GET이 §5의 계정 정상 상태 요건을 충족하는지, 상위 거래소·공급자별 사용 제한을 포괄하는지는 이 조항만으로 확인되지 않는다.**
- **이번에 확보한 실제 계보:** 기존 [운영 PC #2166](https://github.com/ansqhd5774-Choi/zgmini-pc-control/issues/2166)의 GMH-only 14종·30 raw 페이지·679 거래일·7×252(1,764) 비공개 점수 SHA 결과 및 [PC #2185](https://github.com/ansqhd5774-Choi/zgmini-pc-control/issues/2185)의 실제 수집 요청시각 `2026-11-16T11:47:59.532Z`·14종/30페이지 원본 SHA 재검증·원격 JSON/TXT 2/2 PASS를 각각 재사용한다. 2026-11-13의 **관측일**, 2026-11-16의 **수집 요청시각** 및 미래 **게시 시각**을 구분한다. 이 증거는 **소스 계보·계산/원자료 무결성** 증거이며 운영자 라이선스 수락·계정 정상 상태·비복원성의 독립 증명·배포 승인·D1 CAS는 아니다.
- **현재 R178 공개 대상:** 신규 7테마×252 거래일의 비공개 projection은 개별 1h OHLCV/원가격·rawRows·volume을 표시하지 않고 0~100점/날짜·테마 ETF 명칭만 후보로 작성한다. 공개 Worker 역시 `theme`, `etfs`, `score`, `history.date/score`만 전송하도록 projection을 제한한다. **출력 필드 감사는 라이선스 전체·원가격의 대량 역추정 불가를 수학적으로 인증한 것이 아니다.** 기존 D1 R178 행에는 사용 중지된 MarketParquet 보조 계보가 남아 있으므로 해당 행의 권리가 GMH로 소급되지 않는다.
- **보호·다음 실제 조건:** `publicationAuthorized=false`, `upstreamCommercialRightsVerified=false`, `derivedLicenseVerified=false`, `sourcePriceReconciled=false` 유지. 실제 게시 전 GMH 라이선스 적용 범위와 비복원성/상위 공급자 권리의 운영자 승인, 기존 R178 D1 정확한 CAS·readback 및 독립 R32 비퇴행 확인이 필요하다. 승인되지 않은 유료 구매·추가 GET·TTL 완화·MarketParquet 재도입은 하지 않는다.

## 5. 재조사 방지·운영 원칙

1. 신규 데이터 소스 조사·공급자 권한 이메일 발송 **전에 이 대장과 같은 공급자의 기존 발신/수신 스레드를 함께 확인**한다. 정확히 같은 상품·플랜·이용 방식에 `DENIED` 또는 이미 답변된 상태라면 재문의하지 않는다. 새로운 요금제·별도 계약·사용 방식이 실질적으로 바뀔 때만 새로운 질문을 구성한다.
2. `AWAITING_REPLY`는 **기존 스레드 하나**로 추적한다. `DELIVERY_FAILED` 또는 `VERIFICATION_REQUIRED`를 단순 `AWAITING_REPLY`로 바꾸거나 같은 메일을 무제한 재발송하지 않는다.
3. 권리 검토에서 **로컬 수집·계산**, **외부 공개 파생 결과**, **원자료 재배포**를 별개로 판정한다. 무료 접근 가능/HTTP 200, 코드의 `derivedStatisticsAllowed`, `licensingRiskAcceptedByPublisher` 등 내부 표시는 공급자의 서면 라이선스가 아니다.
4. 이 문서는 **새로운 운영 승인·유료 결제·구독 승인**이 아니며, 기존 게시를 임의 숨기거나 삭제하거나 다른 피드까지 일괄 금지하는 명령도 아니다. 실제 공개 소스가 불허 무료 데이터인 경우 **운영 담당자가 별도 실제 데이터 출처·게시 증거와 승인 범위를 확인**해 조치한다.
5. 변경된 회신이 오면 **수신 날짜·상품·이용 목적·허용/불허 범위·조건·답변 주체(사람/AI/자동 회신)·증거 ID**만 갱신한다. 문의 전 단계의 초안·발송 실패·접수 인증은 답변으로 승격하지 않는다. 확정 회신을 '미확인'으로 되돌리지 않는다.
