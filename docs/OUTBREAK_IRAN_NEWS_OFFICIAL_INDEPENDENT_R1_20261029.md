# 이란 — 공식 자료 기반 독립 사실 브리핑 R1

기준일: 2026-10-29 / 작업 브랜치: `codex/ui-improvements`

## 승인 및 구분

사용자는 기사 원문 이용허락을 기다리는 방식 대신 **공식 자료 기반 독립 분석**을 선택했다. 이는 원래 R41 언론 기사 35건의 원문 이용권한을 부여하지 않는다. R41 기사 ID·제목·본문·URL을 사건 추출의 입력으로 쓰지 않으며, 언론사별 `SOURCE_RIGHTS_RESTRICTED` 35건을 `READY`로 바꾸지 않는다. 뉴스 카드에 기사별 해석처럼 붙이지 않는다.

이 브리핑은 사실관계 확인과 그 의미를 분리한다. 공식 발표는 발표 기관의 입장을 확인하는 1차 자료이며, 발표의 모든 주장이나 실제 군사·외교 상태를 독립 검증했다는 뜻이 아니다. 완화/악화 방향은 **문맥 참고용 분류**이며 전쟁 심리 R5 산식·가중치·차트 입력이 아니다.

## 계약 및 진행 경계

- 구조 검증: `lib/iran-progress/news-independent-official-r1.mjs`.
- 회귀 검사: `tests/iran-news-independent-official-r1.test.mjs`.
- 현재 데이터 상태는 `SOURCE_VERIFIED_CANDIDATE`; `publicationAuthorized=false`. **게시 승인이 아니라 검증 후보**다.
- 수집·Ollama·CMD·D1·스케줄러·GitHub main·Cloudflare 배포의 새 실행은 없다.
- 기존 공개 분석은 2026-10-29 확인 시 R41 40건 중 5건, 35건 권한 대기였다. 독립 브리핑 수를 기존 5/40의 분자에 합산하지 않는다.
- `risk_persistent`는 같은 위험이 지속된다는 발표이고 `risk_increase`는 새로운 확인 사건이다. 부정적인 성명 반복만으로 실제 악화했다고 계산하지 않는다.
- 10/27 사우디 내각 발표는 10/26 테헤란 고위급 회담을 언급하지만 직접 본문 조회가 제한돼 합의 성과를 추가하지 않았다. UN 10/27 핵사찰 논의도 기존 10/27 영·독 발언과 중복돼 별도 사건으로 세지 않았다. UN 자동 음성 전사는 공식 회의록이 아니므로 단독 확정 근거로 쓰지 않는다.
- 10/26 사우디 연합군의 작전 성과와 10/24–25 미사일 요격은 **당사국 공식 발표**로 사실관계를 한정한다. 해당 부대가 주장한 타격 결과를 제3자가 확인한 결과로 표현하지 않는다. 사우디 통신사 일부 원문은 동적 렌더링으로 페이지 본문 조회가 제한되므로, 검색 색인에 노출된 공식 발표문과 날짜를 대조한 후보이며 공개 전 직접 재확인 대상이다.
- 서로 다른 날짜의 고위급 통화·다자 방문·정책 제안은 각각 별도의 행위다. 단순 위협 발언과 실제 군사 작전은 신호를 구분하며, 국제기구의 경고를 같은 전투 사건으로 중복 계산하지 않는다.
- 기사별 뉴스 원문 요약/해석이라는 표현 금지. 공개할 경우 별도 `공식 자료 브리핑` 영역과 자체 출처를 표시한다.

## 남은 필수 작업

1. 추가 공식기관 자료를 사건 단위로 계속 조사하고, 날짜·발언 주체·실제로 확인된 사실·단순 요구/예상/평가를 분리한다. 권한 제한 언론 기사의 본문을 자료 검색 키나 AI 입력으로 재사용하지 않는다.
2. 확인 가능한 사건은 검증 후보 묶음에 추가하되 35건이라는 **언론 기사 수에 맞춰 가짜로 35개 사건을 생성하지 않는다**. 특히 사우디 통신사 페이지의 직접 본문 재확인, 10/26 테헤란 회담 결과의 독립된 정부 공개 자료 여부를 계속 점검한다.
3. 다중 공식원문 간 사실 일치/충돌 및 날짜·중복 사건 검토 후 사람이 공개할 후보와 문구를 승인한다. 현재 16건은 직접 운영 게시된 기사가 아니다.
4. 별도 공개 계약과 저장 키, reader, UI 영역은 별도 검증 후 최소 파일만 반영한다. 기존 R41, R26, R5 공개 계약과 정규 실행은 그대로 둔다.
5. 독립 브리핑 내용 확보와 공개 readback을 검증한 **이후** 사용자 목표대로 자동 수집·검증·갱신을 설계한다. 패키지·테스트 성공을 운영 성공으로 보고하지 않는다.

실행 방식은 기존 중앙 `codex/theme-fear-greed-integration-20261025:docs/CMD_EXECUTION_PLAYBOOK.md`를 참조한다. 이번 검증 묶음은 PC 실행이 필요 없어 신규 CMD/ZIP을 만들지 않는다.
