# 이란 보도 흐름 정기 연결

기존 MOFA·GOVUK 공식 기사 수집과 별도로 기존 검토 공급원 Tasnim의 공개 기사 메타데이터를 정기 수집한다. 단일 출처 보도이며 사건 독립 검증 또는 종전 확률이 아니다. 원문 전체를 공개하지 않는다.

- 홈페이지의 최근 14일 관련 URL을 발견하고 미처리 최신 기사부터 실행당 최대 12개 처리한다.
- 20초 요청 제한, 요청 사이 1초 간격, 실패 시 1시간 재시도 시각을 저장한다. 다음 정기 실행은 기존 6시간 주기를 사용한다.
- 기사별 저장 영수증과 해시를 검증하고 채택·제외·실패·대기를 분리한다. 처리 완료 기사는 중복 요청하지 않는다.
- 명시적인 호르무즈 선박 피해는 기존 MARITIME_DISRUPTION -20, 이란의 미국·이스라엘 상대 군사 경고는 기존 MILITARY_WARNING -3을 사용한다. 조건부·부인 제목과 일반 외교 접촉은 반영하지 않는다.
- 기존 5영역 비중과 최종 표시 민감도 3.5배를 유지한다. 같은 날짜·같은 규칙은 기존 계산기에서 1회 반영한다.
- 누적 신호는 차트 14일 범위 밖으로 나가도 보존한다. 차트 이동으로 기준점을 재설정하지 않는다.
- 공식 기사 또는 뉴스의 최근 저장 검증이 성공하면 계산한다. 모두 지연되면 마지막 정상 결과를 보존한다. 각각의 최신성은 collectionCoverage에 기록한다.
- 정기 run-reference-flow에서 공식 수집 → 뉴스 수집 → 저장 점수 계산·게시 순으로 실행한다. 일부 경로 실패는 종료 코드와 진단에 남긴다.
