# 공개 데이터 저장형 전환 R1

수집·저장·계산은 인증된 예약 작업에서만 수행한다. 페이지 요청은 저장된 응답만 조회한다.

- 기존 종합점수·한국 Revision 7은 기존 저장 테이블을 유지한다.
- CNN, 경제지표 상세, Core PCE 및 기존 KOSPI/FTSE/Nikkei 보조 API는 public_feed_snapshots_v1로 전환한다.
- kind=input은 계산 전 입력, kind=output은 공개 결과, kind=attempt는 호출 시도 기록이다. 일자별 이력과 current를 원자적으로 저장한다.
- CNN은 최소 15분 간격, 기타 피드는 최소 6시간 간격이다. 기존 5분 시장 예약 호출에서 도래한 피드만 수집한다. 실패해도 같은 간격 안에서는 재호출하지 않는다.
- 원자료 저장 성공 후 DB에서 다시 읽은 자료로 결과를 생성한다. 저장 실패·원천 실패는 기존 정상 결과를 덮어쓰지 않는다.
- 공개 응답 X-Data-Source=STORED, X-Data-Snapshot-At은 수집 결과 저장 시각이다. 원천 관측일은 기존 응답 필드를 유지한다.
- CNN 저장값 유효기간은 6시간, 나머지는 36시간이다. 결측·만료 시 503/null이며 방문자의 요청이 수집을 시작하지 않는다.
- /api/data-health는 저장 상태만 조회한다. 진단용 실제 API 호출은 기존 인증된 internal 경로로 분리한다.
- 사용자 로그인·즐겨찾기 CRUD, 정적 예시 데이터, 이미지 처리는 시장 API 수집 대상이 아니다. 예시를 실제 지표로 바꾸지 않는다.
- 산식·제공처·점수 방향·비중은 변경하지 않는다. 차트의 표시용 기간 선택·차이 계산은 기존 화면에서 수행한다.
- 영구 저장으로 전환해도 제공처 오류나 오래된 관측일 자체가 해결되는 것은 아니다. 배포 성공과 실제 저장 성공은 구분한다.

검증: 저장·조회·만료·0값·실패 보존·호출 간격과 기존 CNN/Core PCE/한국/종합점수 검사 24개 통과. 운영 저장 결과는 배포 후 별도로 기록한다.
