# 점수 갱신 표시

- 대시보드의 미국·한국 공포탐욕, 종합 점수, 12개 경제지표, 금리·이란 점수에 적용한다.
- 활성 화면은 저장된 공개 API를 60초마다 확인한다. 숨겨진 탭에서는 주기 조회를 중지하고 복귀 시 확인한다. 원천 수집·산식·게시 주기는 변경하지 않는다. 즉시 전송되는 스트리밍 데이터는 아니다.
- 상승 ▲는 위로, 하락 ▼는 아래로 계속 움직인다. 기존 `SCORE_ARROW_24H`의 표시 조건과 만료 기준은 유지한다. 지속 움직임은 새 데이터 도착이나 연결 성공의 증거가 아니다.
- 표시 점수가 바뀌면 숫자에 1.8초 강조 효과를 준다. 초기 로딩, 결측 복구, 같은 표시 값 재조회에는 효과를 주지 않는다. 후속 변화에는 효과를 다시 시작한다.
- 기기의 `prefers-reduced-motion` 설정에서는 이동·강조 애니메이션을 끈다. 점수와 방향 정보는 유지한다.
- 결측·수집 오류를 가짜 값으로 채우거나 실패를 성공으로 표시하지 않는다. 갱신 실패 시 기존 데이터 계약을 따른다.

검증은 고정 데이터 단위 검사와 로컬 합성 갱신 화면을 사용한다. 운영 점수를 변경해 효과를 만들지 않는다.
