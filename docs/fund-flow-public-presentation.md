# 자금흐름 표시 계약

- 점수는 기존 `buildFundFlowR53` 결과를 그대로 사용하며 종합 비중 8을 유지한다.
- 추이는 동일 산출 결과의 월별 score/shock 유효 행 중 현재 산출 관측일 이하만 공개한다. 현재 빈티지 이력이며 당시 발표 정보로 재구성한 PIT 이력이 아니다.
- 세부 34는 SEC Registered Fund Statistics, Table 3.2, All - Net의 등록펀드 전체 순유입 / 전월 순자산 비율이다. 0.16은 0.16%이며 100으로 나누지 않는다. 음수와 0을 보존하고 점수 게이지로 표시하지 않는다.
- 월별 데이터에 일별 보간이나 가상 일별 변화량을 추가하지 않는다. 짧은 기간에 관측이 하나면 실제 단일 관측만 표시한다.
- 세부 33 외국인 미국주식 순매수와 35 Total TIC는 별도 Treasury TIC producer 연결이 필요하다. 이번 SEC 표시 연결에 포함되지 않는다.
- 세부 36 위험자산 유입 비중은 총람의 분자/분모/음수 처리 산식 미확정 상태다. 임의 값을 생성하지 않는다.
- 누락된 33/35/36을 새 점수나 가짜 0으로 채우지 않으며 네 세부 지표 전체 구현으로 보고하지 않는다.

검증: fixture 기반 public handler 회귀 검사와 로컬 PC/모바일 렌더링은 실제 SEC Production Runtime 수집 검증과 구분한다.
