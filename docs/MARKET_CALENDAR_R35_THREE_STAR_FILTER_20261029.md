## 범위·기준

- 기존 경제지표 중요도 1/2/3 계약은 변경하지 않는다.
- 기업 실적: R30 기존 핵심 목록 `NVDA, AAPL, MSFT, GOOG, GOOGL, AMZN, META, TSLA, AVGO`는 3등급; 그 외 기존 `priority=true`는 2등급; 일반은 1등급으로 구분한다. 별은 ZGMINI의 예상 시장 영향도이며 투자등급·실제 주가 반응이 아니다.
- `GOOG`/`GOOGL`은 같은 Alphabet 실적 발표일에 한 항목으로 묶고 `(GOOG·GOOGL)`로 표시한다. 원본 두 거래 코드를 가진 PC 스냅샷의 `recordCount`와 D1 원자료는 변경하지 않는다.
- 동일 날짜에 장전/장후 시각이 서로 다른 경우는 `동일 날짜 정보 상충` 및 `시각 미정`을 그대로 적용한다. 날짜가 다르면 기계적으로 하나로 합치지 않고 `여러 날짜 중복 · 확인 필요`로 표시한다.
- 기존 D1에 저장된 R32 방식 ★★ HTML도 API 읽기 단계에서 ★★★로 업그레이드한다. 재수집·추가 EarningsAPI 호출·DB 재게시·새 일정 예약이 필요 없다.
- 상단 `중요도` 필터: 전체 / ★★★ / ★★ / ★, 단일 선택·정확한 등급 일치. 경제지표 목록과 기업 실적 HTML API에 같은 조건을 적용한다. 전체 기본값과 기존 유형·국가·기간·검색 필터는 유지한다.
- 새 API 매개변수 `importance=1|2|3`; 누락은 전체, 다른 값은 HTTP 400. 결과 HTML·일별 건수·선택일 건수가 함께 필터링된다.
