# 점수 화살표 24시간 표시

2026-10-15 사용자 확정: 점수 변동 발생 후 24시간 표시. 데이터 갱신은 별도다.

- 경제지표 12개, 8대 위험 지표, 미국·한국 공포·탐욕, 종합 점수, 금리 심리, 이란 참고 흐름에 적용한다. 탐색용 화살표는 대상이 아니다.
- 8대 위험 지표는 직전 실제 공개 점수를 `previousValue`로 보존하여 방향을 비교한다. 자산 버블·공급 충격은 화면과 동일한 상세 projection을 사용한다. 최초 등록은 방향과 변동 시각을 만들지 않으며 다음 실제 변동부터 표시한다.
- 점수·차이 수치·기존 비교 기준·산식·가중치·과거 차트·수집/화면 갱신 주기는 변경하지 않는다. 상승 초록·하락 빨강과 기존 화살표 크기를 유지한다.
- PC 게시기가 성공적으로 게시된 공개 점수만 읽어 별도의 표시 메타데이터를 기록한다. 소수 첫째 자리까지의 점수가 바뀌면 해당 공개 결과의 저장 시각을 changedAt으로 기록한다. 다시 수집/게시된 동일 점수는 changedAt을 보존한다. 결측·과거 세대·미래 시각은 갱신하지 않는다.
- 최초 기준 등록 또는 방법론 변경 시 변경 시각을 추정하지 않는다. changedAt=null로 시작하며 이후 확인된 변동부터 표시한다. 운영 도입 순간 기존 점수에 새 화살표를 만들지 않는다.
- 표시 조건은 현재 화면 점수와 메타데이터 점수가 같고 0≤현재시각−changedAt<86,400,000ms인 경우다. 정확히 24시간이 되면 화살표를 숨긴다. 변화량 숫자는 기존 비교값으로 유지한다.
- 브라우저 공통 만료 타이머는 데이터 조회와 독립적으로 동작한다. 중지된 탭의 focus/pageshow/visibilitychange에서도 확인한다. 재접속·새로고침으로 시작 시각을 만들지 않는다. 서버 메타데이터가 없으면 화살표를 표시하지 않는다.
- 기존 market_public_snapshots_v1에 public:score-arrow:core:v1 / public:score-arrow:iran:v1 두 키를 사용한다. Core와 이란 게시기를 분리하고 compare-and-swap 및 read-back으로 덮어쓰기를 방지한다. DB 스키마 변경은 없다.
- /api/score-arrow-state는 저장 결과만 읽는다. 원천 API 호출·점수 계산·DB 초기화/쓰기 없이 제공하며 캐시하지 않는다. 화면에서는 하나의 공통 조회만 사용한다.
- 24시간은 데이터의 신선도/공개 유지 기간과 무관하다. 최근 8일 연결 성공 기준과 기존 데이터 유효기간을 이 표시 규칙으로 대체하지 않는다.

검증은 고정 시계의 24시간 경계, 동일값 재게시·직렬화/재접속, 결측/0/과거 세대/방법론 변경, 탭 재개와 독립 만료 타이머, SQLite 게시/read-back·GET 전용 API를 포함한다. 실제 운영 점수를 조작해 화살표를 만들지 않는다.
