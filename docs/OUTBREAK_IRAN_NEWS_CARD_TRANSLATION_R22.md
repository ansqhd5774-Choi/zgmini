# 이란 주요 뉴스 카드 한국어 우선 표시 — R22

## 적용 대상

- 기존 `/outbreak/?event=iran` 카드 컴포넌트 `app/outbreak-news-r57.tsx`만 사용한다. 별도 화면을 만들지 않는다.
- 수집 주기, R3/R5 점수, D1 뉴스 키, 기존 카드의 `title`·`summary`는 변경하지 않는다.

## 표시 규칙

1. `titleKo`·`summaryKo`가 모두 검수돼 공개된 뉴스는 카드에 한국어를 기본 표시한다.
2. `titleEn`·`summaryEn`도 있으면 카드의 **원문** 버튼으로 영어 텍스트를 표시하고, **한국어** 버튼으로 되돌린다. 외부 링크는 GOV.UK 원문을 계속 연다.
3. 기존 한국어 검수 기사에서 영어 필드가 없다면 기존 한국어 표시를 보존한다.
4. 영문 뉴스에 검수된 한국어가 없으면 존재하지 않는 번역을 만들어 표시하지 않는다. 지원되는 데스크톱 크롬의 내장 번역 API를 이용할 수 있으면 브라우저에서 번역을 시도한다. 모델 최초 다운로드에는 사용자 클릭이 필요할 수 있다. 브라우저 번역은 영속 저장하지 않는다.
5. 모바일을 포함한 전 기기에서 한국어를 보장하려면 PC 게시 단계에서 검수된 한국어 쌍을 공개 데이터에 포함해야 한다. 현재 R21 실험 번역은 자동 검수 승인이 아니므로 무단 승격하지 않는다.

## 데이터 계약

- 기존 `title`, `summary`는 후방 호환성을 위해 유지한다.
- 선택 필드 `titleEn`, `summaryEn`는 동일 GOV.UK 기사에서 확인한 영어 원제목과 실제 발췌 문장이다.
- 선택 필드 `titleKo`, `summaryKo`는 두 필드가 함께 있어야 하며, `translationReviewed: true`를 동반하는 명시적 검수 번역만 저장·공개할 수 있다.
- 영어 발췌는 R12 기사별 출처·이용권 검증이 통과한 경우 R13 신규 수집 기사에 전달한다. 짧거나 적합한 문장을 확보할 수 없으면 영어 발췌를 임의로 생성하지 않는다.
- 과거에 게시된 기사는 이미 보존된 원장을 덮어쓰지 않는다. 과거 영어 발췌 보강과 한국어 검수 결과의 PC/D1 반영은 별도의 가드된 전환 작업이다.

## 검증·운영 구분

- 테스트: `node --test tests/iran-news-*.test.mjs`, `npm run typecheck`, `npm run build`.
- 코드 빌드 통과는 배포나 PC 번역/게시의 성공을 뜻하지 않는다.
- 실제 운영 반영은 GitHub 최신 `main`과 Cloudflare Git 연동·배포 상태를 확인한 다음 승인된 절차로 진행한다.
