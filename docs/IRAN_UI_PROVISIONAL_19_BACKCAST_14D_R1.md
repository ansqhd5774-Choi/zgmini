# 이란 화면 14일·잠정 19점 역산 보완 R1 — 2026-10-19

## 사용자 확정 표시 요구
- 2026-10-19의 **잠정 최종 기준 19점**에서 시작해 지난 14일 점수를 **보도 변화량 기준으로 역산**한다.
- 차트는 **14개 날짜(10/06~10/19)**를 빠짐없이 배치한다.
- 초기값 50을 과거 실제 점수로 표시하지 않는다.
- 18점 잠정 연구 시안은 당시 역사 기록으로 남기되 최신 19점 요구를 우선한다.

## 화면과 원자료의 경계
- PC/D1/공개 API에 저장된 R3_3 보도흐름 점수는 **38.7점/10개 사건**이며, R3의 승인된 가중치·산식·체크포인트·게시 이력을 바꾸지 않는다.
- 화면 표시 전용 `IRAN_PROVISIONAL_19_BACKCAST_14D_R1`으로 검증된 R3_3에서만 적용한다.
- **V58 교정:** 운영 R3_3은 뉴스 추가로 **38.7 → 37.9**로 갱신됐지만 화면은 이전 오프셋 때문에 18.2가 됐음. 19일 화면 종점은 원점수 값이 바뀌어도 **항상 19.0점**으로 재정렬한다. 19일 이후 날짜의 기사 변화량만 19에 가감하므로 이후 실제 변화는 표시된다. 14일 범위에서 앵커 날짜가 벗어난 경우 검증 시각의 고정 원 R3 기준점 **37.9**와 현재 원점수의 차이로 누적 표시를 이어간다.
- 매일의 R3 점수 `delta(date)`를 마지막 화면 종점에서 역방향 차감하며 14개 날짜를 계산한다. 종점은 앵커 날짜라면 정확히 19, 이후 날짜라면 **19+19일 후 날짜별 R3 보도 변화량**이다. 원천 변화는 기사 **발표일 기준**이며 독립 전황 관측이 아니다.
- 최초 기사보다 이른 구간은 근거가 없는 **역산 연장 점선 구간**이다. 변화량 기록 부재를 안전/전쟁 진정의 사실로 해석하지 않는다.
- 14개 표시점 모두 measured=false / estimated=true; calibrated=false, probability=false. R4 종전확률이나 14개 일별 독립 관측치로 표현 금지.
- 화면에 잠정 기준점·역산·원 R3 점수를 구분한다. 점수 화살표는 서로 다른 척도이므로 혼용하지 않는다.
- 위조·미검증 데이터 또는 이전 분류기 R3_2에는 보정을 적용하지 않고 fail-closed를 유지한다.
