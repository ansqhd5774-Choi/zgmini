# 금리 입력 수집 지연 방지

## 문제와 변경

기존 PC core는 public feed를 먼저 처리하고 market 작업을 순환한다. 작업 주기가 5분이어도 개별 금리 입력은 여러 시간 대기할 수 있다. 2026-10-15 KST 진단에서는 H.15 원천의 10월 13일 자료와 달리 저장 입력·공개 금리 심리가 10월 9일에 머물렀다.

기본 core 실행에서 금리 작업의 마지막 시도 후 60분이 지났으면 기존 한 작업 슬롯을 rates에 우선 배정한다. 별도 scheduler·추가 동시 작업·공급자·자동 retry는 생성하지 않는다. 실제 수집은 기존 pipeline/rates lease와 quota guard를 유지한다. 성공·실패 모두 마지막 시도 시각으로 cooldown을 적용하며, 나머지 슬롯은 기존 feed/market 경로를 사용한다. 명시 job과 Korea 실행은 그대로다. PC 중지·긴 실행·공급자 실패 상황에서 60분 내 성공을 보장하는 SLA는 아니다.

산식·비중·관측 만료 TTL·DB 구조·API 계약은 변경하지 않는다. 동일 기존 이력·산식에 최신 저장 입력을 넣어 계산·게시한다. 과거 이력을 다른 모델로 소급 변환하지 않는다.

## 해석

현재 금리 심리는 H.15 국채금리의 금리차 변화 50%, 2년물 RSI 반전 20%, 10년물 RSI 반전 20%, 변동성 백분위 반전 10%다. 60점대는 이 모델에서 50보다 우호적이라는 뜻이며 회의별 인하 확률이나 주식시장 전체의 강한 낙관 판정이 아니다.

사용자가 제공한 회의별 목표금리 확률 CSV는 별도 비교 자료다. 이를 기존 산식에 임의 혼합하거나 점수를 낮추기 위해 비중·방향을 변경하지 않는다. 해당 파일은 저장소·원격 DB에 업로드하지 않는다.
