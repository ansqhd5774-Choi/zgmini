## 검증과 운영 경계

격리된 Node 22 환경에서 V24 순수 모듈 **8/8 테스트 PASS** (기존 V21 오프라인 테스트 별도 **10/10 PASS**). GitHub 전체 회귀/PC 실원장 테스트, Production 정확성, 실시간 사이트 검증은 V24에서 실시하지 않았다.

**현재 R4 14일 점수: 0/14일 미산출(score=null).**

향후 필요한 검증은 (1) 공식 사건별 원문과 PC source receipt의 저장·재조회, (2) #156/#157 및 10/05 예멘 공세 중복·사건일 해소, (3) IRN_USA / IRN_ISR / YEMEN_HOUTHI 및 HORMUZ / RED_SEA 각 28일 관측 완전성, (4) 핵 N 및 외교/휴전 관련 입력 검증이다.

이 V24는 **연구용 Draft** 이며 DB/D1/Provider API/스케줄/산식·가중치/배포를 변경하지 않는다. 기존 승인 없는 R4 점수 생성, 병합, 생산 게시를 허용하지 않는다.
