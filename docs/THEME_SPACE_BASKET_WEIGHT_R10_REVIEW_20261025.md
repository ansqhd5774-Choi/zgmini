## 4. 제한 없는 N종 상대비중 — R4-A 구현안의 정량 검증

비공개 R4-A 산식 **변경 없음**. 해당 날짜에 점수가 실재하는 ETF 수 `k≥2`에 대해:

```text
N_i >= 40 (해당 날짜의 ETF-SPY 실제 공통 유효 관측일)
a_i = 0.30 + 0.20 * (min(N_i, 377) - 40) / 337
c_i = a_i / (1 - a_i)
w_i = c_i / sum(c_j)                 # ETF 수의 상한 없음
S_theme = sum(w_i * S_i)              # 각 S_i는 실제 R2/R188 산출
```

| ETF 수 | **가정 N 배열 (실제 ETF N 아님)** | R4-A 비중, 해당 순서 (%) |
| ---: | --- | --- |
| 2 | 700 / 40 | **70.00 / 30.00** (승인 R3 경계 유지) |
| 2 | 120 / 120 | 50.00 / 50.00 |
| 3 | 700 / 252 / 40 | 46.079 / 34.172 / 19.748 |
| 3 | 700 / 326 / 40 | 43.207 / 38.275 / 18.517 |
| 3 | 700 / 377 / 40 | 41.176 / 41.176 / 17.647 |
| 3 | 120 / 120 / 120 | 33.333 / 33.333 / 33.333 |
| 4 | 700 / 377 / 144 / 40 | **33.386 / 33.386 / 18.920 / 14.308** |
| 5 | 700 / 500 / 252 / 120 / 40 | **27.007 / 27.007 / 20.029 / 14.382 / 11.575** |
| 10 | 700 / 700 / 500 / 400 / 377 / 300 / 252 / 200 / 120 / 40 | **12.213 × 5 / 10.168 / 9.057 / 7.972 / 6.504 / 5.234** |
| 20 | 장기 N700 10개 + 단기 N40 10개 | **장기 각 7.00 × 10 / 단기 각 3.00 × 10** |

- 모두 합산 **100%**(표시 반올림 오차 제외), ETF 순서에 무관하고 같은 N이면 동일한 비중. `N<40`은 **점수 결측/혼합 거절**, 가짜 0점·과거 보간·100:0 자동 대체 금지.
- 수학적 제약: `3/7 ≤ c_i ≤ 1`이므로, `k`개 중 최단 N40 1개의 **최소 가능한 비중**은 다른 `k−1`개가 377일 이상일 때 `3/(7k−4)`. `k=3 → 17.647%`, `k=4 → 12.5%`, `k=5 → 9.677%`. 따라서 현 R4-A의 **3종에서는 50:40:10이 나오지 않음**. 사용자 50:40:10은 가능한 사례의 *예시*이지 R4-A의 필수 결과가 아님.
- 50:40:10까지 요구하려면 만기만의 상대강도 외에 **테마 순도·실제 품질·ETF 간 보유 중복/상관 등 추가 독립 신호**와 정량 검증이 필요하다. 3종 전용 지수/특수 분기나 승인 2종 70:30 파괴는 하지 않는다.
- **ETF 1종만 적격인 날의 테마 점수 처리**는 R4-A가 현재 `AT_LEAST_TWO`로 차단한다. 구성 가능 ETF 수가 1개라는 사실 자체를 부정하지 않지만, 단일 점수 공개/연결 정책은 별도 승인 필요.
