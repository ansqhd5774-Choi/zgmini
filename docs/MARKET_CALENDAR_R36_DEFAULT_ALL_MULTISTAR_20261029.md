# R36: 시장 캘린더 기본 전체 · 중요도 복수 선택

2026-10-29 사용자 요청에 따라 R35의 단일 선택 중요도 필터를 복수 선택으로 바꾸고, 일정 유형 기본값을 `경제지표`에서 `전체`로 변경한다.

## 사용자 동작

- 첫 진입 시 일정 유형 `전체`, 국가 `전체`, 중요도 `전체`가 활성화된다. 경제지표와 기업 실적을 함께 표시한다.
- 중요도 `★★★`, `★★`, `★`는 독립적으로 토글한다. `★★★ + ★★`, `★★★ + ★★ + ★` 등 복수 선택을 허용한다.
- 각 버튼은 자신의 선택 상태를 `aria-pressed`에 반영한다. `전체`는 모든 별 필터를 초기화하고, 마지막 선택 별을 해제해도 `전체`로 복귀한다.
- 경제지표 목록과 별도 기업 실적 HTML API에 동일한 선택 집합을 적용해 표시 항목·건수를 일치시킨다.

## API 계약

- 이전의 `importance=3` 단일 등급 요청을 계속 지원한다.
- 복수 등급은 기존 엔드포인트에서 `importance=3,2` 또는 `importance=3,2,1`처럼 쉼표로 전달한다. 누락은 전체를 의미한다.
- 비정상 값(허용 등급 외 숫자, 중복 등급, 빈 구간, 4개 이상)은 HTTP 400으로 거부한다.
- 기존 PC 예약 수집, EarningsAPI 호출 횟수, D1 저장 형태, GitHub/Cloudflare 자동배포 구성은 변경하지 않는다.

## 검증 및 반영

- R32/R35 회귀 테스트 유지, R36 단위 테스트에 기본값·선택 토글·복수 API 필터·건수·잘못된 입력을 추가한다.
- Cloudflare는 GitHub `main` 커밋을 통한 기존 자동배포를 사용한다. 사이트 UI의 최종 확인은 사용자가 수행한다.
