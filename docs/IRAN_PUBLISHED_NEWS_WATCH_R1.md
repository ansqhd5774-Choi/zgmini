# PC 게시 뉴스 감지 및 기존 35건 검토

## 실행 계약

- 공개 뉴스 API를 15초 간격으로 읽는다. 기존 R41 우선·R1 대체 선택은 페이지와 같다.
- 선택된 기사 목록의 hash가 마지막 **D1 및 공개 API 검증 성공** hash와 다르면 기사 수에 관계없이 기존 R5 wrapper를 한 번 호출한다. 2건·4건 등의 묶음은 한 번의 계산 입력이다.
- 동시 실행을 기다리며 재시도한다. 빈 응답·실패는 처리 완료로 표시하지 않고 이전 점수를 보존한다. 실패 재시도는 30초에서 최대 5분으로 늘린다. 경고창을 반복 표시하지 않는다.
- PC가 켜져 있고 사용자 로그인·네트워크·E:가 유지돼야 한다. 15초는 감지 간격이며, 네트워크와 계산·게시 검증 시간이 추가된다. 서버 push나 0초 반응을 뜻하지 않는다.
- 새 `ZGMINI-PC-Iran-Published-News-Watch-R1` 로그인 작업으로 숨김 실행한다. 기존 R13·R5 작업 및 6시간 안전 실행은 보존한다. 새 감지 작업만 `IgnoreNew`로 중복 실행을 막는다.
- 처리 상태 `published-news-watch-state-r1.json`, 건강 상태 `published-news-watch-health-r1.json`. DB·API 검증 실패 시 성공 hash를 전진시키지 않는다.

## 계산 변경

- 기존 5개 비중, 단계 가감점, 기준점13, 민감도21, R5_2 변환, 14일 표시 및 실제 게시 이력은 유지한다.
- 게시 뉴스 해석 보완 `IRAN_PUBLISHED_EVENT_RULES_R1`: 국가·중재자·관리들이 실제 평화안 마련을 진행 중이라는 명시적 보도는 기존 외교 의향 단계(+2)에 해당한다. 휴전 서명·호르무즈 개방·후티 철수의 **구상**을 이행으로 가산하지 않는다.
- 추측·질문·분석·요구만 있는 기사는 새 완료 사건으로 처리하지 않는다. 기존 R3 전용 수집기 분류는 바꾸지 않는다.
- 원문 제목 원장·출처·발표일은 보존하고 점수는 지금 관측·게시한 시각에 기록한다. 과거 게시 점수를 소급 생성하지 않는다.
