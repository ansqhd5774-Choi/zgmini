# 잠정치 우선 제공 R1

목표는 일부 수집 작업의 실패가 계산 가능한 다른 지수의 공개까지 막지 않게 하고, 실제 잠정 점수와 확정 이력을 명확하게 구분하는 것이다.

## 이번 변경

- 수집 프로세스 실패·quota 차단은 수집 상태로 기록한다. 게시 요청을 일괄 취소하지 않는다.
- 실패 후 게시에는 `--collection-degraded`를 전달한다. 저장 입력으로 정상 계산된 서로 다른 12개 READY 지수와 READY 종합 점수가 모두 유효한 경우에만 원격 게시 단계로 진행한다. 미충족 시 `STORED_MARKET_NOT_READY_AFTER_COLLECTION_FAILURE`로 중단한다.
- 공급자 호출 제한, 산식·고정 가중치·coverage·TTL, 소스 승인·기존 게시 lease·신세대 보존·read-back 검증은 유지한다. 수집 실패는 성공으로 바꾸지 않으며 `COMPLETE_WITH_COLLECTION_GAPS`로 구분한다.
- 섹터/테마의 공개 API가 제공한 실제 잠정 구간만 점선과 날짜로 표시한다.
- 실적 침체의 별도 잠정 API 결과와 EPS 표본 비율을 대시보드에 추가한다. 확정 위험 점수나 독립적인 경제지표 기업실적 점수에 합산하지 않는다.

## 남은 단계와 한계

이번 변경은 수집 도중의 즉시 게시 또는 모든 지수의 nowcast 구현을 의미하지 않는다. 현재 수집 프로세스가 종료된 뒤 계산하는 순서는 유지된다.

월·분기 동일기간 입력을 요구하는 스태그플레이션·공급충격·자산버블 등은 별도 잠정 모델 검증이 필요하다. 과거 값을 새로운 기간의 관측값으로 복사하거나 결측을 0/중립으로 채우지 않는다. 미발표 입력 예측은 별도 방법론·추정 비율·자료 기준일과 함께 공개하고 확정 이력과 분리해야 한다.

장중 자료가 없는 한국 공포·탐욕 및 외부 CNN 점수는 게시 조건을 변경하는 것만으로 새 잠정 점수가 생기지 않는다. 실제 사용 가능한 입력과 상업적 사용 권리가 선행되어야 한다.

## 운영 적용

GitHub 배포와 PC 실행 소스 적용은 별도다. PC 적용 전 승인된 현재 실행 SHA를 기준으로 필요한 PC 파일만 반영한 독립 릴리스를 준비하고, 격리 테스트·설정/실행기 백업·실행 잠금 확인 후 전환한다. 수집 실패를 강제로 일으키거나 공급자 API를 재호출하여 검증하지 않는다.
