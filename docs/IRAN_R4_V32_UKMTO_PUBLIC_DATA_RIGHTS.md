# ZGMINI Iran R4 V32 — UKMTO 공개자료 사용권·접근 경로 조사 (2026-10-19)

## 공식 근거

- [UKMTO 사이트 약관](https://www.ukmto.org/terms-and-conditions): 2016-08-18 개정 표시. 제20항에 사이트의 정보는 영국 Open Government Licence(OGL) 조건에 따라 재사용할 수 있다고 명시.
- [UK National Archives OGL v3](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/): 상업적·비상업적 재사용 허용, 정보 출처와 가능하면 라이선스 URL 명시, 공식기관 후원/승인으로 오인하지 않도록 제한. 로고·군사 표장·제3자 소유 콘텐츠·개인정보는 별도 예외 대상.
- UKMTO 약관 제22항은 외부 제3자 피드가 편집 또는 캐시 버전일 수 있으며, 최신 자료는 공식 사이트에 있다고 명시.
- [UKMTO 홈페이지](https://www.ukmto.org/): 보안 경보를 이메일로 받기 위한 구독 요청 창구는 존재. 구독 승인·자동 수집 API·재게시 권한과 동일하지 않으므로 실제 등록·결제·수집은 실시하지 않음.

## 연구 판정

1. **사이트 공개 정보의 일반적인 OGL 재사용 가능성: 공식 근거 있음.** 단, 실제 특정 문서·제3자 정보의 권리 확인이 별도로 필요.
2. **상업용 사이트 적용: OGL상 원칙적으로 가능**하지만, 표시할 출처명·라이선스 링크·무보증·공식기관 후원 아님을 UI에 반영하려면 법률 문안 별도 승인 필요.
3. **수집 자동화의 허가/가용성: 미확정.** 특정 사이트 경로가 접근되지 않는다고 제한을 우회하거나 신규 무료/유료 API를 호출하지 않음.
4. **2026-09~10 UKMTO 일별/주간 공식 보고서 원본 완전 확보: 미확정.** 검색 결과에서 과거 주간 PDF와 2026년 1월 PDF가 보이더라도 이를 9~10월 28일 관측으로 소급하지 않음.
5. **사건별 원문 출처 링크 제공과 R4 점수 계산은 별개.** 공개정보 재사용이 가능해도 주체·사건일·중복·완전 관측 입증이 필요.

## 기존 운영 상태

산식, DB/D1, 수집기, TTL, GitHub main, Cloudflare, 사용자 화면과 법률 문안 **변경 없음**. V32 연구 모듈은 42일×5 lane 간격의 **문서 후보**만 집계하고 실제 사건이나 관측 완료를 승격하지 않는다.
