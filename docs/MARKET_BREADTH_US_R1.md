# 미국 등락 지수 R1 — 저장 산식 연결

## 범위

- 미국 S&P 500 날짜별 저장 구성종목과 종목별 종가를 사용하는 상승·보합·하락 **종목 수**.
- 기존 공포·탐욕 B1 가중 지표, 한국 시장 수집·집계, 테마 산식은 변경하지 않는다.
- 전체 NYSE/NASDAQ 확대 및 클릭 시 펼치는 1년 등락 이력 차트는 다음 단계.

## 데이터 및 계산

1. PC `core.sqlite`의 기존 `market_score_breadth_b1_r3_universe_v1`, `...current_v1`, `...history_v1` 조회. 공급자 호출 금지.
2. 뉴욕 시간 기준 **최근 완료된 미국 정규장 거래일**의 저장 데이터만 후보.
3. 기존 R10 V9 소스감사로 구성종목 중복, 보정 종가 기준, 현재·이력 일치, 원본 증빙 검증. 98% 미만은 계산 결과 공개 불가.
4. 적격 종목의 당일 보정종가와 전 거래일 보정종가 비교. `>` 상승, `=` 보합, `<` 하락. 거래량·시가총액 가중 없음.
5. `ISSUE_DIRECTION_COUNTS_R1`로 합계 및 적격 커버리지 검증. 구성종목 이력을 공식 PIT라고 주장하지 않는다.

## 발행 및 조회

- PC 예약 게시기 `run-local.mjs --publish`가 성공한 미국 계산 결과만 D1 `market_public_snapshots_v1`에 게시.
- 키 `public:market-breadth-r1:usa`(현재)와 `public:market-breadth-r1:usa:YYYY-MM-DD`(확장 차트용 일자 보관).
- 종목별 원시 가격·구성종목 원본은 D1으로 복사하지 않는다.
- 원격 기록보다 오래된 결과는 덮어쓰지 않는다. 게시 후 2개 키 모두 다시 읽어 검증한다.
- `/api/market-breadth?market=usa`는 **읽기 전용**이며 최근 완료된 거래일 기록만 내보낸다. 부재·오류·지연 상태는 HTTP 503으로 표기하고 UI는 `연결 예정`을 유지한다.
- `market=korea`는 연결하지 않는다. 기존 한국 UI 대기 상태 유지.

## 배포 조건

- GitHub 메인 병합은 Cloudflare Git 빌드를 개시할 뿐, 사용자 Windows PC의 코드를 설치하거나 예약 작업을 변경하지 않는다.
- 실제 숫자가 나오는 운영 완료 조건: 최신 메인 버전 PC 설치 → PC에 해당 날짜 S&P 500 소스 확보 → 예약 `--publish` 성공 → D1 현재/일별 키 재조회 일치 → 공개 GET 확인.
- UI와 API 배포만 성공하고 PC 미설치 또는 소스 미수집이면 데이터는 대기 표시인 것이 정상.
