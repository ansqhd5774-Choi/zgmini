## 배포 경로 충돌 — 반드시 해결할 범위

2026-11-09 조회 시 기존 UI 브랜치는 최신 `main`과 분기돼 있었다(브랜치가 271커밋 앞섬/451커밋 뒤처짐, 비교 변경 파일 235개). **브랜치 전체 PR·무분별한 merge는 사용자 다른 작업을 섞을 위험이 있으므로 금지**한다. `main` 직접쓰기·강제 push·이력 재작성·미승인 신규 브랜치/직배포도 금지한다.

실화면 검증과 독립 코드 검사는 진행할 수 있다. PR/Production 단계에서는 사용자에게 **최신 main 기반의 목적 제한 배포 전용 브랜치 예외**를 확인하거나, 이미 승인된 안전한 목적 제한 경로가 실제 존재하는지 확인한 후 이번 8파일만 선별 적용한다. 해당 승인 또는 경로 확인 전까지 Production 완료로 보고하지 않는다.
