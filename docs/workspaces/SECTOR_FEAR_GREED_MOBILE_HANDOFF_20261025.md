## 목적과 범위

PC 버전은 현행 디자인을 보존하고, 모바일에서 섹터 순위표의 가독성을 개선한다. 변경 후보는 해당 페이지의 모바일 레이아웃 및 필요한 텍스트 명료화로 한정한다. 다른 페이지/테마·산식·가중치·API·DB·Provider·스케줄러·DNS는 변경 금지.

## 2026-10-25 실제 화면 관측

사용자 제공 모바일 화면(폭 약 510px)과 공개 URL의 PC 화면·접근성 트리를 확인했다. 당시 공개 페이지는 GICS 11개 섹터의 순위, 점수, 5구간 게이지, 1년 미니차트, 1개월 변동, 비교 차트 및 개별 차트를 표시했다. 에너지·소재·헬스케어 상위 3개 행이 비교 차트 ON 상태였다.

관찰된 문제:
1. 모바일 상단 내비게이션과 금리 발표 카운트다운이 지나치게 조밀하며 숫자가 겹쳐 보인다.
2. 비교 차트 OFF인 행의 섹터명·점수·선이 너무 어두워 읽기 어렵다.
3. 게이지가 가로 폭을 많이 점유해 미니차트가 매우 작다.
4. `+26.9p` 등의 변동폭이 모바일에서 '1개월 변화'임을 즉시 알기 어렵다.
5. 모바일 정보 계층이 약해 순위·섹터·점수·변동·추세를 빠르게 훑기 어렵다.

## 논의된 수정안 — 아직 구현 승인/수치 확정 아님

- 모바일에서 한 행의 첫 줄에 순위·섹터명·점수·1개월 변동을 정렬한다.
- 게이지와 미니차트 가로비는 약 60:40을 시작 시안으로 검토한다(확정 아님).
- 선택 여부는 배경 강조로 구분하되, 미선택 행 텍스트는 충분히 밝게 표시한다.
- 메뉴와 카운트다운을 모바일 너비에서 겹치지 않게 정리한다.
- 현재 선택/해제, 비교 차트 연동, 점수 및 1년 데이터, 5밴드 비율을 그대로 보존한다.
