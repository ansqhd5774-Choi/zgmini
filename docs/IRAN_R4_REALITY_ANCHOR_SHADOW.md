# ZGMINI 이란·지역전쟁 R4 — Reality Anchor Shadow V1

상태: **UNAPPROVED SHADOW / NO PRODUCTION**, 2026-10-18 KST. 이 문서는 R4의 검증 후보를 기록한다. 운영 R3, 기존 R1.3, 기존 D1 key/TTL/DB/scheduler/DNS, 기존 점수·이력은 변경하지 않는다.

## 목표

실제 미국–이란, 이란–이스라엘, 예멘 후티 전선을 포함한 분쟁 상황에서 10·50·80점이 사건 사실에 부합하도록 **단계-점수 구간의 대응성**을 우선 검증한다. 종전 확률을 주장하지 않는다. 뉴스 건수로 점수를 직접 가감하지 않는다. 검증된 사실 입력이 부족하면 `SHADOW_PENDING / score:null`; 최종값을 추측하거나 50으로 대체하지 않는다. 과거 유효 공개값이 있다고 그 값이 당일 정세와 일치한다고 주장하지 않는다.

## 1. 평가 범위

- `IRN_USA` — 미국·이란의 직접 교전·합의.
- `IRN_ISR` — 이란·이스라엘의 직접 교전·합의.
- `YEMEN_HOUTHI` — 예멘 후티·예멘 정부군, 직접 참전 사우디 등. **이 전선을 이란의 직접 공격으로 자동 분류하지 않는다.**
- `H` — 호르무즈와 홍해/바브엘만데브를 별도 평가한 해상 공격·공식 항행 상태. **AIS API, AIS 통항량, hormuz.now 완전 배제**.
- `N` — 검증된 핵 협상·사찰·합의 이행.

제3국의 **지원 의사 표시**와 **실제 참전**은 다른 사건이다. 기사 목록에 없다는 사실은 교전 0건의 근거가 아니다.

## 2. 선행 상태 판단: 구간 후보

| 검증된 전선 현재 단계 | 허용 종합 구간 |
| --- | ---: |
| 중대한 동시 확전 `CRITICAL_ESCALATION` | 0–9 |
| 전면전 `FULL_SCALE_WAR` | 10–24 |
| 교전 지속 `ACTIVE_COMBAT` | 25–39 |
| 실제 군사 강도 감소 `VERIFIED_DEESCALATION` | 40–49 |
| 취약한 공격 중단·휴전 전환 `FRAGILE_TRUCE` | 50–59 |
| 휴전 발효 초기 `CEASEFIRE_EARLY` | 60–74 |
| 14일 이상 검증된 휴전 `CEASEFIRE_SUSTAINED` | 75–89 |
| 30일 이상 휴전 및 실질적인 최종합의 이행 `PEACE_IMPLEMENTATION` | 90–99 |
| 공식 종전·이행 확인 `ENDED` | 100 |

세 전선의 단계 가운데 **가장 불안정한 단계를 종합 단계로 채택**한다. 전선의 중요도·범위를 반영한 가중 평균은 추후 사용자 승인 사안이며 이 V1에는 없다. 이 구간 자체도 정답이라고 미리 가정하지 않는다. 아래 사건 리플레이로 교정한다.

## 3. 구간 내 세부 계산 — 후보

```
D = MIN(전선별 검증된 외교 단계 × 20)
C = MIN(전선별 검증된 휴전 이행 단계 점수)
M_front = 100 × exp(-(0.7×(최근7일 심각도합/7)
                     + 0.3×(이전21일 심각도합/21))/3)
M = MIN(M_front)
H_해역 = MIN(0.6 × 검증된 선박 사고 안전 점수 + 0.4 × 공식 항행 제한 점수, 사고별 상한)
H = MIN(H_호르무즈, H_홍해/바브엘만데브)  (AIS 미사용)
N = 독립 검증된 핵 이행 점수 (0–100)
Q = (0.20D + 0.35C + 0.25M + 0.10H + 0.10N)/100
score_shadow = round2(구간최저 + (구간최고-구간최저)×Q)
```

세 전선 모두 `ENDED` 상태가 독립 검증되면 100. 숫자 20/35/25/10/10, 0.7/0.3, 지수분모 3, 구간은 모두 **후보값**. 증거 수준보다 정밀한 소수점 수치를 과학적 확률로 해석할 수 없다.

R3의 각 영역 50점 임시 시작점과 고정 기사 가감점은 신규 R4에 전혀 사용하지 않는다. R3의 39.1점을 R4 이력에 연결하지 않는다.

### 해상안전 H의 실제 Shadow 계산 계약

`lib/iran-progress/maritime-official-r4.mjs`가 자체 계산하며 임의의 H 점수를 외부에서 입력할 수 없다. 두 해역 모두 **실제 28일 사건 관측 완전성·중복 제거·공식 항행 제한 확인**이 필요하다. 중대한 최근 선박 공격은 25점, 기타 최근 공격은 50점으로 H 상한을 제한하는 후보 규칙을 적용한다. 제한이 없다는 기사 부재만으로 정상 운항 100점 처리 금지. 정상 운항 100은 공식 제한 해제와 정상운항 확인 모두 요구한다.

사고 데이터는 보도된 사건일 기준이다. 공식 경보는 위험 경고일 뿐 **실제 전면 통항 중단을 증명하지 않는다**. 이 식의 60/40 및 상한 값도 사용자 최종 승인·실데이터 교정 전까지 연구용이다.

## 4. 입력·결측·실패 정책

- 단계·시점·근거는 사전 검증된 **로컬 사건 원장**에서 온다. Ollama·GDELT 후보의 단독 추론은 금지.
- 군사 강도 7일/21일은 **중복 제거한 확인 사건** 및 28일 실제 완전 관측 근거가 있어야 한다.
- 각 전선 단계 검증은 최근 72시간, 전선 및 군사 coverage는 최근 24시간, 해상 72시간, 핵 상태 확인 30일 이내를 **Shadow V1 가정**으로 적용. 월간·이벤트 기반 자료에 대한 실제 운영 TTL 승인과 혼동하지 않는다.
- 미래 날짜, 검증되지 않은 원문, 단계와 공격강도 모순, 휴전 검증일과 단계 모순, 핵·해상 입력 결측이 있으면 `SHADOW_PENDING`.
- 데이터가 `SHADOW_PENDING`이면 **시뮬레이션 점수도 산출하지 않는다**. 현행 R3 서비스 중단·재계산·삭제를 의미하지 않는다.
- 전선별 사건일·검증일·원장 저장일·게시일을 구분한다.
- 실제 합의 발효 전이라도 전투 지속이면 `ACTIVE_COMBAT`와 교전 근거를 우선한다.
- 전체 사건 완전성 증거를 갖추기 전의 0건은 **무관측**이며 안전지표 100점으로 환산하지 않는다.
- 관련 소스의 무료 상업 사용 가능성은 실제 데이터 수집 도입 전 확인한다. R4 V1은 외부 수집 추가 없음.

## 6. 실제 산식 검증 목표

- A. 50점 테스트: 주요 전선의 현재 검증 교전 지속 → 불합격.
- B. 80점 테스트: 한 전선이라도 검증된 전면전 → 불합격.
- C. 80점 테스트: 관련 전선 모두 14일 이상 휴전·연속 관측, 중대한 위반 없음 → 후보 구간 적합.
- D. 10점 테스트: 심각한 실제 확전이 없고 각 전선이 평온할 때 → 불합격.
- E. 한 기사 20회 재인용/보도 → 사건 한 건으로 처리.
- F. 공격을 한 번도 수집하지 못한 7일 → 실제 무교전이 아닌 `PENDING`.
- G. 유엔 발표 9일 지난 현재 → 신선도 근거 없으면 `PENDING`.
- H. 연속 휴전 중 확인된 새 공격 → 높은 휴전 구간 불허.
- I. R3와 R4가 숫자가 비슷하더라도 R3 결과를 정답으로 사용하는 검증 금지.
- J. 소스 수정 후 shadow에서 지난 사건을 다시 계산하되 기존 공개 history 변경 금지.
