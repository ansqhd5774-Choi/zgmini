# 정상 입력과 공개본 보호

## 2026-10-26 장애

경제 지표 수집은 BLS HTTP 200 응답의 CPI·실업률 2025-10 값을 숫자 오류로 처리했다. 원천 값은 `-`이며 공식 footnote는 2025년 예산 공백으로 자료가 제공되지 않았음을 명시했다. 현재 계산에 필요한 최근 월·직전 월·전년 같은 월은 별도로 존재했다. 이 과거 미발표 한 행 때문에 정상 계열 전체가 제거되면서 필수 입력 검증이 게시를 막았다.

공식 미발표 표식은 관측값 없이 `NOT_PUBLISHED` 메타데이터로 보존한다. 설명 없는 표식·잘못된 숫자·날짜는 계속 오류다. 주 공급원은 현재 계산에 필요한 실제 월들을 검증한다. 필요한 전년 같은 월이 없으면 계산을 차단한다. 보간·0 채움·대체 공급원 강제 전환은 하지 않는다.

## 저장과 계산의 경계

- 공용 입력 7종은 기존 계열·관측 계약으로 검증한 뒤 저장한다. 빈 응답이나 불완전 입력은 기존 정상 본문·수집 시각을 교체하지 않는다.
- 읽기는 기존 일별 이력에서 최근 10개 중 정상 입력만 선택한다. 복구한 행의 원래 시각과 기존 TTL을 유지한다. 정상 행이 없거나 만료되면 입력을 사용할 수 없다.
- 공개 시장 점수는 고유한 12개 READY 영역, 유한한 0~100 점수, 정상 종합 점수와 추이를 모두 요구한다. 현재·날짜별 점수·유동성 이력은 한 batch로 저장하여 중간 실패 시 함께 롤백한다.
- 부분 수집·건너뜀·미확인 상태는 COMPLETE로 승격하지 않는다. 정상 독립 출력은 각각 검증·게시하고, 실패가 있으면 전체 보고는 부분 실패와 비정상 종료를 유지한다.

산식·가중치·방법론·TTL·DB 스키마·공급원 선정·작업 주기는 변경하지 않는다. 외부 공급원의 장애를 없앤다는 보장은 하지 않는다. 공급원 장애 중에는 정상본의 유효기간 안에서만 서비스하며, 만료를 숨기지 않는다.
