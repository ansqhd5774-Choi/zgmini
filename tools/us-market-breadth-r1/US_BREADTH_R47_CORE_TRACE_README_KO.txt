ZGMINI 미국 등락 지수 R47 읽기 전용 Core 실행 경로 점검

1. ZIP 전체를 Windows 다운로드 폴더의 별도 폴더에 압축 해제합니다.
2. 압축을 해제한 폴더의 US_BREADTH_R47_CORE_TRACE_READONLY.cmd를 실행합니다.
3. 생성된 US_BREADTH_R47_CORE_TRACE_숫자_숫자.txt를 대화에 첨부합니다.
   TXT는 CMD와 같은 폴더에 저장됩니다. 작업 종료 시 탐색기에서 파일이 선택됩니다.
4. TXT를 찾으려고 E: 드라이브나 TEMP 폴더를 검색할 필요가 없습니다.

실행 범위: Windows schtasks /Query /XML, 등록된 VBS/CMD 내용 읽기,
승인된 PC config의 최소 필드 및 실제 Git SHA/clean 상태의 읽기 전용 확인.

수집 원자료, 가격, 토큰, 설정 원문, 작업 XML, 절대 경로, 실행 명령은
TXT에 출력하지 않습니다. E:에 어떤 파일도 생성하지 않으며 D1/공급자
호출, Core 예약 작업 변경, 잠금 해제, PID 종료를 실행하지 않습니다.

R47은 정적 코드 추적 결과입니다. R38 보조 VBS나 동적 명령이 확인되면
실행 완료라고 간주하지 않고 후속 증거가 필요한 상태로 보고합니다.
기존 15분 잠정치 또는 확정치 데이터와 250거래일 이력은 변경되지 않습니다.
