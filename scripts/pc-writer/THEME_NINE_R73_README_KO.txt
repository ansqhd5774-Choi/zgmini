1. ZIP 압축을 해제합니다. 폴더 안의 파일을 모두 함께 둡니다.
2. THEME_NINE_R73_INSTALL_AND_RUN.cmd를 한 번 실행합니다.
3. 별도 RESUME 입력이나 15분 기다리기 없이 기존 비공개 R48 수집을 진행합니다.
4. 기존 11:30 KST 비공개 예약 작업의 실행 경로만 예약 전용 R73 래퍼로 변경합니다.
   예약 실행은 수동 실행용 시간 중복 차단을 적용하지 않고 11:20~12:15에만 시작합니다.
   기존 R48 실행기, 9개 테마 산식, 63 ETF, D1, 공개 R54 작업은 변경하지 않습니다.
5. HTTP 502만 최대 2회 추가 자동 재시도합니다. 재시도 간 최소 60초 간격을 둡니다.
   429, 다른 오류, 파일 무결성 실패는 자동 해제하지 않습니다.
6. THEME_NINE_R73_INSTALL_RUN_*.txt 파일을 보내주세요.
