THEME NINE R73 FIX2 (기존 브랜치/기존 예약 작업 유지)

이번 실PC 로그: THEME_NINE_R73_SCHEDULED_25439_19016.txt
- 오후 시간에 R73 예약 전용 래퍼가 실행됨.
- 구버전은 11:20~12:15 KST 이외 시간을 자동 차단하여 attempts=0으로 종료.
- 실제 ETF 수집, 원시 데이터 갱신, 공개 D1 쓰기는 시작되지 않음.

이 FIX2는 예약 작업의 실행 파일을 임의 시간에 직접 실행해도
기존 R71의 동시 실행/13:30 공개 일정 충돌 검사와 lock 확인을 통과하면
실제 비공개 R48 수집을 진행하게 고칩니다. 11:30 예약 시간은 유지합니다.

실행:
1. 이 ZIP 전체를 새 폴더에 압축 해제합니다.
2. THEME_NINE_R73_FIX2_APPLY_AND_RUN.cmd를 오른쪽 클릭해
   '관리자 권한으로 실행'합니다(Windows 권한 요청은 사용자가 승인).
3. 같은 폴더에 생성되는 THEME_NINE_R73_FIX2_*.txt 한 개를 전달합니다.

주의:
- THEME_NINE_R73_SCHEDULED_PRIVATE.cmd는 직접 실행하지 않습니다.
- 기존 R73 모듈의 SHA가 두 가지 승인값 외라면 변경하지 않습니다.
- 구 R73 모듈은 .bak로 보관하고 내용 검증 뒤 교체합니다.
- Windows 작업 이름/트리거/사용자/설정은 보존하고, 등록된 명령만
  기존 R48에서 R73 예약 래퍼로 변경할 수 있습니다.
- 사용자 PC 결과가 나오기 전까지 예약 작업 설치 성공·64슬롯 수집 완료·
  D1 반영·실제 공개 API 최신화는 완료로 판정하지 않습니다.
