R33 - IAEA MANUAL HTML INSPECTION (NO NETWORK OR INSTALL)

Purpose:
  Inspect two user-saved official IAEA historical article HTML files.
  This never proves automated article collection or publishing rights.

Steps on the SAME Windows PC:
  1. Extract the entire R33 ZIP into a NEW folder.
  2. In Chrome, open these original IAEA article URLs:
     https://www.iaea.org/newscenter/news/restoring-iaea-inspections-in-iran-would-create-promising-ground-for-wider-progress-says-director-general-grossi
     https://www.iaea.org/newscenter/statements/iaea-director-general-grossis-statement-to-unsc-on-situation-in-iran-22-june-2025
  3. Turn browser translation OFF for these pages, if enabled.
  4. Save each page using Ctrl+S, type "Webpage, HTML Only".
     Save the first as IAEA_NEWS.html and the second as IAEA_STATEMENT.html.
     Place both files NEXT TO IRAN_NEWS_R33_MANUAL_IAEA_VERIFY.cmd.
  5. Run IRAN_NEWS_R33_MANUAL_IAEA_VERIFY.cmd ONCE.
  6. Share only IRAN_NEWS_R33_MANUAL_IAEA_RESULT.txt.

Safety:
  No article GET, download, proxy, login, browser session extraction,
  scheduler operation, PC source installation, D1, score, or public-cache write.
  Saved HTML is user-provided evidence only; publisher origin is not
  independently authenticated. No article body is written to the result log.
  The 2025 articles remain outside the 30-day automatic retention window.
  If verification fails, preserve the result and do not rerun automatically.
